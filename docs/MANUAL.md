# duocad の使い方 — 制作用と開発用

duocad は2つあります。**作品を作るときは「制作用」、duocad 自体を直すときは「開発用」** を使います。
制作用は開発の途中の状態に影響されません。

## 2つの duocad

| | 制作用(安定版) | 開発用(開発版) |
|---|---|---|
| 使うとき | 作品を作る | duocad を直す・機能を足す |
| 場所 | `C:\Users\tm976\duocad-stable` | `C:\Users\tm976\mf\duocad` |
| 起動 | Win キー → `duocad` → Enter | 今までどおり(README 1章) |
| 画面 | 独立した窓(タブやアドレスバーが無い) | ブラウザのタブ。**左上にピンクの「開発版」** |
| ファイルの置き場 | `C:\Users\tm976\duocad-data\models`(書き出しは `export`) | `mf\duocad\models`(書き出しは `export`) |
| アドレス | `http://127.0.0.1:8776/` | `http://127.0.0.1:8766/` |

**見分け方は「開発版」の札だけ覚えれば足ります。** 札が出ている窓では制作しないでください。

## 制作する

1. **Win キー → `duocad` → Enter** で起動します。初めの1回はサーバの準備に十数秒かかります。
2. 保存は自動です(操作のたびに書かれます)。ファイル一覧には `duocad-data\models` の中身だけが出ます。
3. 終わったら**窓を閉じるだけ**でかまいません。裏でサーバが残るので、次はすぐ開きます。

**AI に操作させるとき**
- 画面右の AI パネルはそのまま使えます。
- Claude Code から操作させるときは、**`C:\Users\tm976\duocad-stable` フォルダで Claude Code を開きます**。
  このフォルダで開いたときだけ制作用につながります(`mf\duocad` で開くと開発用につながります)。

## 更新する

新しい版があると、**画面左上に「更新 1」のようなボタン**が出ます(数字は変更の数)。
カーソルを載せると、何が変わるかの一覧が出ます。

1. 押すと「更新中…」と表示され、数秒〜数分で**自動で画面が読み直されます**。
2. 下に「更新した」と出れば完了です。開いていたファイルはそのまま残っています。
3. 失敗したときは**自動で元の版に戻ります**。下に理由が出るので、開発側で直します。

- 更新が届くのは **main に入った変更だけ**です。開発用で直しただけでは届きません(下の「開発する」)。
- 今の制作用は main ではなく **2026-10-04 時点の develop** から始めてあります。そのため**次に develop を main へマージするまで更新ボタンは出ません**。
- 「更新できない」という札が出たら、制作用のフォルダが書き換えられています。カーソルを載せると理由が出ます。

## 開発する

- 作業場所は今までどおり `mf\duocad`(develop)です。
- 開発用の画面には「開発版」の札が出て、タブ名も `[開発版] duocad` になります。
- 制作用と同時に開いてかまいません(ポートが違うのでぶつかりません)。
- **制作用のファイルで不具合を試したいときは、`duocad-data\models` から `mf\duocad\models` へコピーして**開きます。
  制作用のファイルを開発用で直接開くと、保存形式の違いで制作用で開けなくなることがあります。
- 直したものを制作用に届けるには、**develop を main へマージ**します(GitHub の PR)。届いたら制作用に更新ボタンが出ます。

## 困ったとき

| 症状 | 対処 |
|---|---|
| 「ポート 8776 で別の duocad が動いている」と出る | 開発用のサーバが制作用の番号で動いています。それを止めてから起動し直します |
| 「サーバが立たなかった」と出る | `duocad-data\logs\server.log` の最後を見ます |
| 更新に失敗した | 下に出たログ(`duocad-data\logs\update-日時.log`)を見ます。制作用は元の版のまま使えます |
| 更新前の版に戻したい | 下の「前の版に戻す」 |
| 制作用のサーバを完全に止めたい | 下の「サーバを止める」 |

**サーバを止める**(PowerShell):

```powershell
Get-CimInstance Win32_Process | Where-Object CommandLine -like '*--channel stable*' | ForEach-Object { Stop-Process -Id $_.ProcessId }
```

**前の版に戻す**(PowerShell。直前の更新の前に戻り、自動で起動し直します):

```powershell
& "$env:USERPROFILE\duocad-stable\tools\stable\update.ps1" -RepoRoot "$env:USERPROFILE\duocad-stable" -LogDir "$env:USERPROFILE\duocad-data\logs" -DataDir "$env:USERPROFILE\duocad-data" -Rollback
```

## 気をつけること

- **`duocad-stable` の中のファイルを手で書き換えないでください。** 更新が止まります(「更新できない」の札)。
- **作品は `duocad-data` にあります。** リポジトリの外なのでバックアップは別に取ってください。
- 開発用の `models` にあった `untitled-*.json`(310個)は制作用へ写していません。必要なものがあれば `duocad-data\models` へコピーしてください。

仕組みと再セットアップの手順は [STABLE.md](STABLE.md) にあります。
