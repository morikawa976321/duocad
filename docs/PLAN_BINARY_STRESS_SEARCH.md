# 二値モデル・応力制約による体積削減ループへの移行計画

作成日: 2026-09-17。状態: **実装済み。§1〜§9は現行仕様の記述**(コードと一致することは
`tests/test_doc_code_agreement.py`等で確認済み)。段階7(通し検証)でhangerの実機検証が一度失敗し、
原因は`FIX_BINARY_SEARCH_INITIALIZATION.md`で直した(§10)。
調査基準: `codex/pre-smoothing-checks` の `bd49a9b`。設計空間導出は完了しており、検査実装は
`TOPOPT_PRE_SMOOTHING_CHECKS.md` に記載。

## 1. 目的・範囲・固定する判断

目的は「6条件を満たす二値モデルのうち、探索で発見した最小体積のものを返す」こと。
大域的最小性、任意の入力での解の存在・発見、平滑化後の強度は保証しない。
速度より、合格モデル以外を成功として返さないこと、失敗の原因が追跡できることを優先する。

- セルは材料あり／なしのbool。体積は材料セル数×セル体積。
- 候補生成は全材料からの削除だけ(段階4の `peel`。§11・§12)。採否は実際の応力と6条件で決める。
- **初版ではコンプライアンスを候補順位にも使用しない**。補助指標としての再導入は別の判断とする。
- SIMP・OC・MMA・連続密度・材料量の二分／Illinois探索は削除する。旧方式への切替・フォールバックは残さない。
- 固定済みの設計空間、格子、アンカー、荷重、材料物性は実行中に変更しない。
- 安全率は現行のvon Mises応力99.5パーセンタイルと許容応力から計算する。最大応力も併記する。
  最大応力基準への変更や印刷材料モデルの変更は本計画で混ぜない。
- 最小部材幅の新たな保証は導入しない。密度フィルタ半径を別の意味の「幅」として流用しない。
- メッシュ化・平滑化・最終ブーリアンのアルゴリズム改良は範囲外。
  ただし採用マスクを既存の後段へ渡す配線と、旧SIMP依存の除去は範囲内。

## 2. 合格モデルの契約

検査対象は候補に対して島除去を終えた、平滑化前の材料マスク。以下を全て通す。

1. 境界が閉じ、角・辺だけの接触による非多様体境界がなく、殻が1つ(閉じた空洞がない。§12.9)。
2. 6近傍で単一の材料成分。空集合は不合格。
3. 各保持CADとの共通体積が数値許容差を超える。
4. 各除外CADに材料で埋まっていない正の体積がある。
5. 元の各荷重・拘束面のアンカー節点が材料に接し、荷重の欠落・再配分がない。
6. そのマスクでFEMを再構築し、残差検算を通過した安全率が目標以上。

設計空間外に材料を追加しない。保持セル(`SearchConditions.keep_cells` = `DesignSpace.keep`)は探索で
空にしない(2026-09-21 本人決定。理由と実測は `TOPOPT_PRESERVE.md`): 探索が作る全候補で `keep ⊆ mask`
とし、`peel` は保持セルを削らず、島の除去は全保持セルを含む成分だけを残す。
(3)は1セルも掴めない保持ボディの受け皿として残す。合格判定の後で保持を塗り直して形を変えることはしない(§4.4)。
設計空間自体が既に除外セルを除去していることは維持する。(4)だけを理由に設計空間を拡張しない。
幾何検査で失敗した候補はFEMを省略してよい。省略と計算失敗を安全率不足へ変換しない。
形状を修正したら既存の合格判定を無効にし、修正後のマスクで検査し直す。

## 3. 単一の製品経路

```text
条件文書
 → 固定設計空間を1回導出
 → 全材料をキャッシュなしで1回検査(島処理・幾何条件検査・FEM応力評価)。不合格なら落ちた検査を返して終わる(§4.2)
 → ひずみエネルギーの低い材料を削った候補ごとに検査し、合格するたびに最良合格モデルを更新(§11・§12)
 → 最良合格モデルの保持・除外を前計算なしで再検査
 → boolマスク・格子・検査結果・探索終了理由を確定保存
 → 製品では、その後だけ既存のメッシュ化・平滑化・ブーリアンへ渡す
```

候補ごとのメッシュ生成・STL出力は廃止する。探索の入口はCADの追加も行わない。
後段へ渡す必要がある場合だけboolを0/1配列へ変換し、表示上の閾値0.5をアダプター内で固定する。
この変換は連続密度探索の復活ではない。

## 4. 探索状態と候補生成

### 4.1 状態

- `best_feasible`: 発見した最小体積の6条件合格モデル。上書きは小体積の合格候補だけ。
- `history`: 全試行の親、操作、除去前後の体積、6条件、FEM成否、採否理由。

返却は必ず `best_feasible` から行う。安全率不足・計算失敗で最良モデルを失わない。
評価条件の識別子は格子・固定空間・荷重拘束・物性・応力規則・検査許容差を含める。
形状ハッシュだけで、違う入力の合格判定を再利用しない。

### 4.2 最初の合格モデル

最初の合格モデルは設計空間の全材料マスクそのもの。入口検査(§4.6 の入口の状態)のあと、条件に触れない成分を除去し、
6条件を**1回だけ**検査する。最大成分だけを残して条件を失う候補を、成功として通さない。
この評価は bbox キャッシュも保持・除外の前計算も使わない(§3。段階4が戻り先にする合格形状なので)。

**全材料が合格しなければ、別の形を探さず `no_feasible_found` を返す**(2026-09-21 本人指示。理由と失ったものは §13)。
段階4は材料を減らすだけで、合格形状からしか始められない。落ちた検査の名前と数値
(`diagnostics['full_material']`)を画面に出し、入力(荷重・目標安全率・保持・除外・条件面・解像度)の見直しを促す。
入力矛盾の確定(`input_contradiction`)と、全材料の不合格(`full_material_infeasible`)と、計算失敗(`evaluation_error`)を区別する。

### 4.3 操作と順序

材料を減らす操作は段階4の `peel` だけ(§11・§12)。材料を足す操作・置き換える操作は無い。

### 4.4 島除去

最大成分だけを選ぶ既存処理を探索の正として使わない。
各連結成分を残した場合の条件成立を調べ、全荷重・拘束と各保持との重なりを満たし、全保持セルを含む成分を候補にする。
複数候補があれば別々に評価する。成立する成分がなければ候補は不合格。
除去した島のセル数・体積・含まれていた条件を記録する。
最後に保持を塗り直して島を復活させたり、空洞を埋めて黙って別形状にしたりしない。

### 4.5 応力評価

材料セルだけで剛性を組み、空セルの微小剛性で橋渡ししない。
材料に接しない節点だけを自由度から外し、浮いた材料への人工拘束は追加しない。
元の荷重をNで保存・適用し、相反する荷重の相殺で脱落を隠さない。
既存の変位ソルバー、残差検算、von Mises・単位換算を再利用する。
解法変更による再試行は有限の規則にし、同じマスク・条件であることを記録する
(実装では再試行しない: CG が収束しなければ内部で直接解法まで解くので、替えても同じ計算になる。issue #37)。
計算失敗は `unknown` であり、応力不足や体積の下限の証拠にはしない。

### 4.6 終了と中断

終了理由は `initial_feasible_found`(段階3だけを呼んだとき)、`converged`(段階4、§11)、`evaluation_limit`、`cancelled`、
`full_material_infeasible`(全材料が形として不合格)、`evaluation_error`、入口の `resolution_insufficient` /
`boundary_mapping_failed` / `input_contradiction`。形状の合否とは別の欄にする。
「指定した近傍で改善なし」を大域収束・最小性証明と表示しない。
合格候補ありで予算終了なら、最良候補を最終再検査して返せる。
中断時は合格チェックポイントを記録するが、製品文書へ勝手に結果を追加しない。
最終再検査が失敗したら成功を返さず、候補と診断を残す。

## 9. 検証と完成条件

- 各6条件を単独で破る反例を用意し、合格に化けないことを検証する。複数保持・複数荷重・相反荷重・
  複数拘束、格子未満のCAD、境界接触、内部空洞を含む。孤立成分が条件を持つ例、全材料でも応力不足の例、
  計算失敗、初期合格未発見も。
- 安全率再評価が削除・島除去後のマスクを使うことを、マスクハッシュと解への入力で確認する。
- 最良モデルは合格を維持し体積が増えない(探索用候補の体積増加と混同しない)。合格発見後の全試行失敗、
  予算終了、中断、最終再検査失敗で返却状態が正しい。
- 記録から候補と採否を再現でき、失敗候補を含めFEM回数・時間・体積履歴が追える。
- 微小格子では許可マスクの全列挙を検査専用の正解として使い、評価・最良候補選択を照合する。
  **通常探索が常に大域最小を発見するというassertにはしない。**
- hangerは保存済みの同一入力・同一物性・目標・要素サイズを基準にする。採用マスクで6条件全合格、
  最終再検査一致、導出1回、候補中メッシュ化0回を必須とする。**初期合格だけで止まって軽量化できない
  場合は、その事実と終了理由を記載し、体積削減機能の完成と扱わない。**
- **速度の合否閾値は設けず**、実時間・候補数・FEM回数・削減体積を報告する。
- 既存後段の小型製品保存・undo/redo・元ボディ不変・中断を確認する。hangerの後段に残る平滑化問題を、
  新ループの合格や未解決事項から隠さない。

各項目に対応するテストは**テスト自身の docstring が正**(名前が変わるたびに腐る対応表は持たない)。
**まだ無いもの**: 「複数荷重」「相反荷重」「複数拘束面」を**同時に**持つ単一のテスト
(単体の反例と、2保持体・単一拘束面・単一荷重面の組み合わせはある)。

## 10. 段階7: 通し検証・監査(2026-09-17)

hangerでの実機検証は当初失敗した: 全材料マスクでも荷重面31のアンカー節点の10〜32%がどの材料セルにも
接しておらず、条件検査が恒常的に不合格になり候補が積み上がって `MemoryError` になった。設計空間の導出
自体は正常(接続性剪定が削除したセルは4.8mm・2.4mmとも0)で、被覆が失われるのは除外マスクを引く段階
だった。原因は「候補は設計空間の部分集合なので、候補に接する節点は設計空間に接する節点の部分集合」
という関係を無視し、全材料マスクの被覆漏れを幾何不良や応力不足と同列に扱って候補生成を続けていたこと
(小型題材では候補数が少なく顕在化しなかった)。
直し方・実測・残した契約は [FIX_BINARY_SEARCH_INITIALIZATION.md](FIX_BINARY_SEARCH_INITIALIZATION.md)。

修正後、hanger 4.8mm / 2.4mmとも初期全材料マスクが実FEMを含む6条件に全合格した(安全率164.7 / 163.1)。
この時点では体積削減の完成とは扱わなかった —— 予算60で `evaluation_limit` に達し、評価の8割が
`no_component`(拘束面が節点2個で、大きいブロックの削除がその足場を落とす)だった。段階4をひずみ
エネルギー順の削減へ置き換えたのが §11 で、そこで初めて削減が進むようになった。

## 11. 段階4の置き換え: ひずみエネルギーの順位で削る(2026-09-18)

段階4(`binary_search._reduce_volume`)を、FEMの結果を削る位置へ使う方式(旧SIMPのコンプライアンス
感度の考え方を、二値形状と6条件の合否判定のまま取り入れたもの)に置き換えた。

### 11.1 方式

合格形状を1つだけ持ち、その6条件検査で解いた変位から要素ごとの `u_eᵀ k₀ u_e` を取り
(`acceptance.inspect(fields=)`、追加の求解なし)、自身と26近傍の材料で平均して順位にする
(`ranked_cells`。近傍の一辺は `ENERGY_FILTER_SIZE` = 3セル)。

**現在も使う式**(§12のpeelもこのまま):

- 1回に削るセル数 `k = max(1, ⌊r × m × 材料セル数⌋)`。削減割合 `r = min(r_max, 1 − (T/S)^θ)`
  (S: 現在の安全率、T: 目標。θ は「安全率が体積に比例するなら次の形の安全率をSとTの間のどこへ置くか」
  を対数で表す係数、m は後退倍率、初期値1)。
- 合格したら採用してエネルギーを更新し `m ← min(1, 2m)`。不合格・計算失敗なら形状を変えず、
  k > 1 なら `m ← m/2`。

**選び方(`select_removal`)と修復(`restore_irregular`)は§12のpeelに置き換わった**: 順位表の先頭k個を
盲目的に選ぶ方式は、関節セル(抜くと形が割れるセル)が1つあるだけでkが1まで落ちるまで失敗し続け、
hanger 4.8mmの試行の39%(299件中116件)が「修復で全部戻った選択」になっていた(§12.1)。

### 11.2 削減割合の決め方(hanger 4.8mm)

**既定は θ=0.5・上限0.2**(`DEFAULT_STEP_EXPONENT` / `DEFAULT_MAX_STEP_RATIO`)。hanger 4.8mm・目標
安全率2で複数の規則(固定割合0.1/0.2、θ=1.0上限0.2、θ=0.5上限0.2/0.5)を比較した結果、θによる歩幅
調整は安全率の余裕が大きいとほとんど差が出ないが、余裕が小さいと効く(目標140では固定0.2が安全率
不合格にFEMを17回使ったのに対しθ=0.5は1回)。既定の1本は5,142,330→53,130 mm³(1.03%)・安全率2.224
まで進み、段階4のFEM184回・評価369回で`converged`(`safety_at_single_cell`)した。題材はhanger 1つだけ。

## 12. 段階4の候補生成の置き換え: peel(2026-09-19)

§11.1の「選び方」と「修復」を、`binary_search.peel`(順位表を1回歩き、局所の不変条件で判定しながら
削る)に置き換えた。順位の付け方・削る割合r・後退倍率m・6条件・採用と収束の規則は§11のまま。

### 12.1 置き換えた理由(§11.2の基準実行の分析)

基準実行の`no_component` 184件は全て「削ったら2成分以上に割れた」もので、幾何由来(保持・節点)の
失敗は0件。原因は選び方の構造 —— 順位表の先頭k個を盲目的に選び、幾何検査で落ちたらkを半減する
方式だと、順位の低い位置に関節セルが1つあるだけでk=1に落ちるまで失敗し続ける。「修復で全部戻った
選択の永久除外」(309セル)も、境界の多様体条件の不正が単調でない(隣が抜ければ解消する)ので誤りだった。

### 12.2 方式

`peel(mask, order, count, anchor_ids, *, surface_only)` は順位(`ranked_cells`)を先頭から**1回だけ**
歩き、各セルを**その時点の(削り途中の)マスク**で判定して、通ったらその場で消す。判定は全て局所で、
次の順に見て最初に落ちた理由で数える: **支え**(条件節点に接する材料の最後の1セルは抜かない)→
**表面**(`surface_only=True`のときだけ。空の6近傍を持たないセルは抜かない。内部に空洞を作らないための
条件)→**多様体**(抜いた後の8頂点が全て正則)→**連結**(抜いた3×3×3の窓で材料6近傍が6連結なら通す。
通らなければマスク全体を`ndimage.label`し、条件節点を支えるセルが全て同じ1成分にあるときだけ通して
他の成分を一緒に消す。ループを1本切る削除もこの経路で通る)。構成上、候補は常に「6連結1成分・
不正頂点0・全条件節点に支えあり」になる(`resolve_islands`は検算になる)。

安全率で不合格ならm←m/2。順位から削ったセルが1つのときは、不合格の理由によらずそのセルを
**この形状の間だけ**順位から外して次のセルを試す(§12.7で確定する規則の原型)。同じ形から既に
不合格と分かっている候補が再び出たときは、解き直さずmを半減する。診断キー(`diagnostics['reduction']`
の内訳)は`binary_search.py`のdocstringが正。

### 12.3〜12.6 `surface_only` の比較実験(2026-09-19。結論は§12.9)

hanger 4.8mmで、内部も削る経路(A、`surface_only=False`)と表面だけ削る経路(B、`True`)を比較した:
段階4のFEMは基準(§11.3)の184回に対しA 33回・B 45回、最終体積はA 71,421 mm³(基準比+34%)・
B 63,256 mm³(+19%)。幾何での不合格はA・Bとも0件、最終の再検査は合格・ハッシュ一致。最終体積が
小さく段階4のFEMも同数以下の方を既定にする基準では両者が食い違い(Bは体積が小さいがFEMは多い)、
既定は一旦False(A)にした。§12.8で2.4mm・2.0mmでも同じ比較をした結果、Bは2.4mmで基準より小さい
体積にFEM 85回(基準の42%)で到達し、2.0mmではFEM 44回(基準の10%)で基準より9.5%大きい体積に
とどまった(内部を削って中空化した形は同じ体積で強度が低い)。この結果が§12.9の判断を支えた。

### 12.7 収束の規則: 1セルの安全率不合格でそのセルを外して次の順位へ(2026-09-19)

**規則**: 削ったセルが1つで安全率が落ちても止めず、そのセルを順位から外して次の順位のセルを試す
(計算失敗・保持の重なりの不合格は数えない)。安全率で外したセルが**採用を挟まず** `single_cell_patience`
個に達したら `safety_at_single_cell` で `converged`。順位を歩いて1セルも抜けなくなれば `no_removable_cell`。
`single_cell_patience=1` は変更前と同じ規則。**外したセルは採用をまたいで外したまま**(§12.13。2026-09-24 までは
採用で順位を作り直すときに戻していた)。

**既定は 8**(`DEFAULT_SINGLE_CELL_PATIENCE`。§12.13 の本人判断。以下の 16 は外したセルを採用で戻す旧規則での測定)。hanger 4.8mm・目標安全率2でpatience={1, 4, 16, 無制限}
を比較した: 最終体積は71,421(1)→64,127(4)→**51,715(16、無制限と同値)** mm³。**16と無制限は予算
1000回の範囲で完全に同じ試行列になった**(採用を挟まず単セルの安全率で落ちた最長が7回で、16に
達しなかったため)。既定の決め方(測る前に決めた基準)は①最終体積が最も小さいもの→②差が僅かなら
段階4のFEMが少ないもの→③それでも並んだら小さいpatienceで、16と無制限が同点だったので小さい16を
採った。この既定は段階4のFEMを基準(184回)の5.4倍(999回、予算1000をほぼ使い切る)にする値になって
いる(体積を優先し、FEM回数は同点のときだけ見る基準のため)。題材はhanger 4.8mm 1つ。

### 12.8 解像度を上げて再測定(hanger 2.4mm・2.0mm。2026-09-19)

§12.3の比較を2.4mm・2.0mmでも実施した(収束規則は§12.7より前の「1セルで安全率が落ちたら止まる」)。
基準は解像度を上げるほど体積は減るが段階4のFEMも184→204→453回に増え、`no_component`も184→162→365件
に増える(残り90%の試行での採用1回あたりの削減セルは9→115→57で、終盤の1セル刻みは解像度で消えない)。
結果はA・Bとも§12.3と同じ傾向(§12.3〜12.6に記載)で、AはB・基準より常に体積が大きく止まり、Bは
2.4mmで基準を上回る効率、2.0mmでは停止位置の差(§12.7で解消する部分)により基準よりやや大きい体積で
止まった。

### 12.9 中空構造を許容しない(2026-09-19)

**制約**(本人決定 2026-09-19): 「duocadの形状最適化では中空構造を一切許容しない」。実測ではなく
製品制約で、以下の既定変更の根拠はこの制約である。§12.3・§12.8の実測は「その制約の下でも探索は
基準に並ぶ」ことを示すだけ。定義・既知の限界・除外領域の扱いは`docs/TOPOPT.md`「設計上の決定」の同名の項。

**中空構造** = 材料マスクの補集合(空)の連結成分のうち、格子の外へつながらないもの
(`acceptance.void_components`)。貫通穴は空洞ではない。細い通路で外へつながる袋は定義上空洞ではない
ので通る(既知の限界。通路幅の下限は未対応)。

**検査の置き場**: 6条件の1番目(`watertight`)を「頂点が全て正則、かつ殻が1つ」に広げ、
`irregular_vertices == 0 and void_components == 1` で合格とした。`find_initial_feasible`の入口で、
全設計空間のマスクに閉じた空洞があれば`input_contradiction`(除外領域が塊に完全に包まれている入力。
2026-09-20本人承認)。`surface_only=True`の`peel`は構成上空洞を作らない(抜くセルは常に空の6近傍を
持つので、既存の空の成分に属する)。段階3の削除候補も材料の表面(空の6近傍)に接するブロックだけに
した(全部材料に囲まれたブロックを空にすると必ず空洞ができ評価を浪費するため)。

**既定**: `DEFAULT_SURFACE_ONLY = True`。`DEFAULT_SINGLE_CELL_PATIENCE`(16)は変えていない。

### 12.10 内部を削る経路を削除(2026-09-20)

本人指示で、段階4のpeelから内部のセルを抜く経路(A、`surface_only=False`)を削除した。`peel`は常に
表面のセル(空の6近傍を持つ)しか抜かない。`DEFAULT_SURFACE_ONLY`・`surface_only`引数・関連スクリプトは
無くなった(§12.3・§12.8のAの測定は削除前のコードでしか再現できない)。除外領域が塊に完全に包まれて
いる入力を入口で`input_contradiction`にする扱い(§12.9)も本人が承認した。

### 12.11 最小幅つきpeelがm厚の柱を削れないこと(2026-09-20)

**最小幅(`min_width_cells`=m>1)のとき、1セルずつ却下するpeelは断面がちょうどm×mの柱から1セルも
抜けない**(自由端からも)。実測: m=3・3×3×12は108→108セル、m=2・2×2×12は48→48。1セル抜くと
同じ層の残りのセルがm立方に属せなくなるため。現在の`peel`は、そのセルと被覆を失うセル(巻き添え)を
同じ一手で抜く(`docs/TOPOPT.md`「最小幅の保証」)ので、層ごと抜ける。

### 12.12 収束の規則を足す: 安全率が目標の許容内に入ったら止める(2026-09-22)

**規則**: 合格形状の安全率Sが`目標T × (1 + target_tolerance)`以下なら、候補を作らずに`converged`
(`stop_reason='within_target_tolerance'`)。出発形状にも採用のたびにも当てはめ、予算切れ・中断より
先に見る。既定は`DEFAULT_TARGET_TOLERANCE = 0.01`、`None`は見ない。`single_cell_patience`・
`no_removable_cell`はそのまま残る(粗い格子では1セルで安全率が許容の幅より大きく動き、この規則に
掛からず止まる場面があるため)。止まった形状は常に合格形状なので、早く止めて失うのは体積だけである。

**きっかけ**(本人、2026-09-22): 「形状最適化の収束間際の最後の1セルを詰める段階で時間をたくさん
使っているので、終了条件を追加したい」。

**根拠**: 製品経路の実行記録(要素1.875mm・最小幅7.5mm・目標2.0)で、評価18〜98(81回)のうち合格28・
不合格53、合格形状の最小は評価17から体積0.27%しか減っておらず、CGの累計時間の72%(4,266秒)を
この終盤の区間が使っていた。`target_tolerance`ごとに試行列を切ると、0.005〜0.02のどれでも時間は
ほぼ同じで体積差は2ポイント以内。値そのもの(0.01)は対話セッションのAIが提案し本人が採った
(「1%で実装して」)。割合にした理由は`step_ratio`がT/Sだけで決まり、探索時の目標係数を掛けても
意味が変わらないこと。

**限界**: 実測は1題材・1本。安全率は局所量(材料要素の応力の99.5%点)なので、荷重経路に乗らない
材料は安全率をほとんど変えずに削れるが、削る順がエネルギー低い順のためそういう材料は安全率が高い
うちに先に無くなり、許容の幅に入った時点で残っていることは起こりにくい。残りうる未実測の懸念は、
出発形状の安全率が最初から許容内にある場合(全材料のまま止まる)と、許容内に入った採用が軽く荷重を
受けた部材を切った手で、切られた残りが片持ちの突起として最終形状に残る場合。

### 12.13 外したセルと不合格の形を採用をまたいで覚える(2026-09-24)

**規則**: (1) 安全率で落ちた1セル(`poison`)は採用で順位を作り直しても入れない。外したときの合格形状の安全率と不足分
`目標 − 候補の安全率` を覚え、その後の合格形状の安全率が不足分以上に上がったセルだけ戻す(代表応力が 99.5 パーセンタイル
なので、削るほど合格形状の安全率が上がることがある。不足分が取れないセルは戻さない)。(2) 不合格の形の内容ハッシュ
`rejected` も採用で空にしない(同じ形は同じ答え)。(3) `DEFAULT_SINGLE_CELL_PATIENCE` を 16 から 8 にする。

**きっかけ**(issue #22、実測は `docs/TOPOPT_STOP_RULE.md`): hanger 1.875mm・m=4 の終盤で、採用のたびに倍率が戻って
応力集中に届く大きい手が毎回落ち(終盤の評価の半分以上)、不合格の 16 回中 3 回は直前に落ちた形の解き直しだった。
単セル不合格の除外が採用で解除されるため、同じ毒セルを何度も特定し直していた。

**本人の言葉**(2026-09-24):

> 推奨案(毒の記憶)+rejectedの持ち超しを実装せよ。加えて、単セル不合格を16回から8回に減らそうと思う。これも安全側で
> ある程度の効果が見込める。4や1まで減らすことも考えてもいいかもしれない。

除外の記憶が「形が変わっても不足の符号が変わらない」に依存することを本人が指摘し、AIが不足分で戻す条件を提案した。
記憶は候補の生成を絞るだけで候補は全て FEM で検査するので、外れても材料が残る側にしか外れない。

**効果**(`docs/TOPOPT_STOP_RULE.md` §8): hanger 1000 N・1.875mm・m=4 は 229 評価・200 分 → **64 評価・83 分**(最終 41,483 → 41,467 要素、
どちらも `within_target_tolerance`)。合成 1.485mm・m=4 は 689 → 121 評価(15,052 → 15,206 要素)、2.0mm・m=4 は 66 → 29 評価
(6,172 → 6,152)。忍耐 4 は 8 と同じ試行列、1 はほふくの入口で止まり材料が 7% 多い。

## 13. 段階3の探索を削除: 全材料の1回の評価だけにする(2026-09-21)

本人指示(2026-09-21)で、段階3(`find_initial_feasible`)から「全材料が不合格のとき、ブロックの削除・
追加・置換で別の形を探す」機構を削除した。段階3は入口検査と全材料の1回の評価だけになり、不合格
なら落ちた検査を返す(§4.2)。

**無くなったもの**: 候補生成(`block_sizes` / `candidate_descriptors` / `_materialize` ほか)、
`_Frontier` / `_Budget` / `_pull`、引数 `frontier_capacity` / `max_consecutive_adds` / `max_candidates`、
終了理由 `neighbourhood_exhausted` / `frontier_truncated` / `generation_limit`(と段階3の
`evaluation_limit`)、`diagnostics['frontier']` / `['candidates']`、`min_width.cover_additions` /
`CoreConnectivity.child_keeps` / `lost_coverage` の `refill`、`topopt_checks/measure_stage3_min_width.py`。
旧§4.2「満杯の候補が不合格だから全て不可能と結論しない」の原則はここで取り下げた。§4.3の旧追記
(frontier 48・連続追加2・走査予算の決め方)、`docs/FIX_BINARY_SEARCH_INITIALIZATION.md`修正C、
`docs/TOPOPT_THICKNESS.md`節L・節Mの段階3の部分は`0a9ddc7`以前のコードでしか再現できない。

**判断の材料**(調査2026-09-20〜21): `output/`の探索記録19件(全てhanger)で、全材料は毎回1評価目に
6条件へ合格し、frontierは一度も使われていなかった(`peak_retained=0`・`scanned=0`。hanger以外の
モデルの記録は無い)。入口検査を通った全材料が落ちうる経路は4つで、探索が原理上直せるのはそのうち
2つ(非多様体の頂点、除外ソリッドとの重なり)だけ: 安全率不足は材料を減らす操作では実質直らず、
FEMの計算失敗(`unknown`)は親として積まれない(結果として`neighbourhood_exhausted`が誤表示されて
いた)。段階4は合格形状から合格形状へしか動けない(不合格の候補は捨てて戻る。`peel`の不変条件は
保つものであって確立するものではない)ので、段階3が直さなかったものを段階4が直すことはない。

**確かめたこと**: 関連するテスト264本が通る。hanger 4.8mm・予算4で、全材料の安全率164.74と段階4の
最初の3手(安全率164.74→142.09→124.24→106.47)が変更前の記録と一致した。全材料を2回解いていた
(通常の検査+キャッシュ無しの最終再検査)のが1回になった(全材料のFEMは2.4mmで約135秒、2.0mmで約210秒)。

**測っていないもの**: hanger以外のモデルで全材料が合格するか。非多様体・除外重なりの経路が実物の
設計空間で起きるか。起きた場合は`full_material_infeasible`で止まり、落ちた検査と位置が画面に出る。
直すなら段階3の探索ではなく`design_space.derive`の側で設計空間を正す。
