# 固定凸包による設計空間導出への移行計画

作成日：2026-09-16。状態：**2026-09-16 実装済み**（ブランチ `claude/fixed-design-space-impl-e48f98`）。実装の仕様・hanger の実測・削除一覧は [TOPOPT.md](TOPOPT.md)「固定凸包による設計空間(2026-09-16)」が正で、本文書は計画時の記録として残す。

## 1. 採用する案と到達点

採用するのは、比較画像で「元の新案」と呼んだ、**部品群の外接箱から作った凸包の各面を、全体寸法に比例する広い余白で外へ押し出す案**。
(実装後の 2026-09-16 本人判断で、膨張は面の押し出しから**凸包からの距離 `m` 以内(球とのミンコフスキー和)**へ変えた。角・稜が丸くなるぶん面オフセットより小さい。)

部品ごとに10.8 mmの余白を付ける縮小案は採用しない。

設計空間の責務は、材料を配置できる広い領域を決めること。最適化形状を先読みして細く絞らない。
材料量によらず、1回の最適化実行を通して同じ格子・設計マスク・保持マスク・条件面対応を使用する。
効率や速度の追求は今回の完成条件にしない。

完成条件は以下とする。

- 膨張外接直方体より小さく、保持・荷重・拘束の必要領域と、それらの間の配置余地を含む。
- 設計空間導出にSIMP・応力評価・材料量探索を使用しない。
- 全条件の存在・接続を確認でき、取りこぼしや分断を名前付きで報告できる。
- 旧導出方式、旧設定、旧方式専用の検査・補助スクリプトを削除し、製品経路を1本にする。

「後段に十分な空間」の幾何的な確認と、構造性能の確認は区別する。凸包だから最適解を必ず含む、という保証は置かない。
最終形状の合格条件である水密性・単一ソリッドは、引き続き平滑化・ブーリアン後の責務とする。

## 3. 導出アルゴリズムの確定仕様

### 3.1 入力と境界

入力は保持CAD、除外CAD、荷重・拘束面の対応、格子設定、全体余白比率。
材料量、安全率、参照密度、要素順位、最適化結果を導出の入力にしない。

保持ボディと、荷重・拘束面が属するボディを重複排除し、**ボディごとの外接箱**を得る。
外接箱全体を使うことは、今回可視化して採用した案の仕様である。選択面の凸包や、全ボディを一つにまとめた外接箱へ置き換えない。
除外だけに指定されたボディ、無関係なボディ、以前のoptimizedボディを凸包の点群へ混ぜない。

`optimize_run.build_conditions` でボディ単位の情報を確保し、`Conditions` に内部データとして渡す。
境界データには条件種別・ボディIDまたは診断名・外接箱を含める。
直接 `Conditions` を作る検査・CLIも同じ入力契約へ移行する。旧入力を推測して補う互換分岐は残さない。
外接箱の取得は既存のCAD用処理を共用し、過去の表示用三角形分割の有無で値が変わらないことを検証する。

### 3.2 凸包と余白

各外接箱の8頂点を集め、重複点を除き、`scipy.spatial.ConvexHull` で凸包を求める。
全頂点群の軸平行外接箱の最長辺を `L` とし、余白 `m = 0.20 × L` とする。
実装上は既存の `DEFAULT_MARGIN_RATIO` を共用し、値を 0.25 から **0.20** に下げる(2026-09-16 本人判断。下記 §2 の予備計測は 0.25 で取ったもので、0.20 での再計測を併記する)。

凸包の面を単位法線 `nᵢ` と定数 `bᵢ` の式 `nᵢ·x + bᵢ ≤ 0` で表す。
計画時の余白付き領域は、各面について `nᵢ·x + bᵢ ≤ m` を満たす領域(**凸包の各支持平面のオフセット**)だった。
**2026-09-16 本人判断で、余白付き領域は「凸包から距離 `m` 以内」(凸包と半径 `m` の球のミンコフスキー和)に変えた。**
面の正面では平面オフセットと同じで、稜・頂点のまわりは丸くなる。平面オフセットの多面体は距離の判定を絞る外側の当たりと診断に残す。

格子の外枠には、同じ点群の外接箱を各軸に `m` 広げた箱を使う。
各セル中心について、外枠に入り、かつ凸包から距離 `m` 以内(2026-09-16 変更。計画時はオフセットした全平面を満たすこと)である場合に候補セルとする。
格子原点・実spacing・セル中心規約・要素数上限の仕組みは既存処理を利用する。
凸包の外接範囲で格子を再縮小したり、材料量ごとに再格子化したりしない。

点群の階数不足、非有限値、不正な箱、凸包計算失敗は診断付きの失敗とする。
ランダム摂動や、黙って外接直方体方式へ戻る代替経路は設けない。
平面状の条件でも部品に有限の厚みがあれば処理できることを検査する。

### 3.3 除外・保持・接続

1. 既存のボクセル化で除外マスクを得て、候補空間から除外する。
2. 各保持ボディの占有領域と、各荷重・拘束面のアンカーを同じ格子で確認する。
3. **6近傍**で成分を分け、全保持部品・全荷重面・全拘束面が、同じ成分に接続可能であることを個別に確認する。
4. 条件を含まない成分だけを削除する。必要な条件が複数成分に分かれる場合、最大成分を選んで成功にしない。
5. 確定マスクで `VoxelModel` を一度組み立て、`DesignSpace` として返す。

保持・除外のボクセル上の衝突は記録する。最終ブーリアンは除外優先であるため、格子上で除外を保持によって黙って埋め戻さない。
必要な保持や条件面が除外によって失われるケースは、入力矛盾・解像度不足を区別できる診断にする。
最終CADとの差の厳密な体積検査を、設計空間の合否へ復活させない。

現在の `assert_faces_connected` は荷重・拘束をそれぞれ和集合にして判定するため、単独では不十分。
旧回廊処理に含まれていた「全条件を個別に確認する責務」を新しい幾何検査へ移す。
ただし、旧方式の順位探索・侵食幅の二分探索は引き継がない。6近傍の接続を、部材幅や剛性の保証と表記しない。

### 3.4 確定する出力

`DesignSpace` に格子、設計マスク、保持マスク、面対応・アンカー表、条件情報を保持する。
最適化側がマスクを変更しない契約にし、候補間の同一性をハッシュと検査で確認する。
共有可能な幾何情報と、各候補で変化する密度・変位・FEM作業状態を区別し、候補間の状態混入を防ぐ。

診断には導出方式名、点群・箱、凸包の平面式、余白、格子、各段階のセル数、
削除成分数、条件ごとの占有・所属成分、最終マスクのハッシュを保存する。

## 4. 材料量探索との接続

製品経路を次の形にする。

```text
条件文書
  → design_space.derive：固定空間を1回導出
  → 入力・アンカー・接続の検査
  → safety_loop.solve_for_safety_factor(space, ...)
       → 各候補で同じspaceを使ってSIMP・応力評価
  → 採用密度の平滑化
  → 保持union・除外cut
  → 水密・単一ソリッド検査・CAD保存
```

- `optimize_run` が一度作った `space` を探索に渡す。探索内で同じ導出を重ねて呼ばない。
- `safety_loop._run_once` は `derive_from_reference` を呼ばず、渡された空間で `run_topopt` を呼ぶ。
- 材料量の上下限は固定空間の保持量・容量から計算する。旧外接箱の容量を混ぜない。
- `MATERIAL_MAX_RATIO` 等の運用比率は今回むやみに最適化しない。ただし `k_mat` に依存する説明・制約は除去し、固定空間での容量制約として検証する。
- 探索の二分・Illinois提案、停止基準、SIMP更新則、応力評価基準は今回変更しない。
- 密度フィルタの実半径は明示的に引き渡す。参照計算を削除して既定値へ落ちる事故を検査する。
- デバッグ表示の最初と最後に異なる設計空間を出さない。密度の途中表示は維持する。
- 所要時間見積もりから参照SIMP分を除去する。`seconds_reference` の利用箇所を更新し、不要ならキーごと削除する。
- 途中記録のイベントを `derive` 中心に整理し、予備計算・候補ごとの導出イベントが新規実行に出ないようにする。

## 6. 実装の順序

### 段階A：基準を固定

1. 対象inputと格子、採用案のマスク、点群・平面式・余白を、検査用に小さく切り出す。
2. 読み込むCADの対応とマスクハッシュを記録し、522,424セル(余白 0.25・面オフセット)を再現することを確認する。余白 0.20 では 389,213セル、さらに距離の膨張にした現在の基準値は 367,390セル。
3. 既存の作業変更を確認し、今回の変更対象を区別する。過去の解析データは上書きしない。

個人の巨大な実行フォルダがなくても単体検査を走らせられるよう、合成形状と小型fixtureを使う。
hangerの実CADを用いた検査は、保存済み入力を明示して実行する統合検査にする。

### 段階B：固定空間の実装と単独検証

1. 条件ボディの外接箱の受け渡しを追加。
2. 凸包・面オフセット・セル中心判定・除外適用を実装。
3. 全条件を個別に確認する接続検査と不要成分除去を実装。
4. 途中記録と可視化を追加し、採用画像・基準マスクと照合。

`design_space.py` は現在1,500行超なので、数値幾何部分を必要なら小さな専用モジュールに置く。
同じ導出を複数実装せず、旧コード削除後に責務単位で配置を整理する。

### 段階C：製品経路を切替

1. `optimize_run` → `safety_loop` 間を固定 `space` の受け渡しへ変更。
2. 全候補が同じ空間を使うこと、候補状態を持ち越さないことを検査。
3. 容量・材料量上下限・フィルタ半径・所要時間表示・進捗を更新。
4. 小型モデルでSIMPから最終CAD保存まで通す。中断・失敗で文書が変わらないことも確認。

### 段階D：旧実装を完全削除

段階5の一覧に従い、参照計算・候補空間生成・関連設定・不要fixture・旧補助コードを削除する。
一時的に新旧が共存する実装途中の状態を、完成として扱わない。

### 段階E：検証・文書・削除監査

新しい検査、残す既存検査、小型製品経路、hangerの導出・描画確認を実行する。
参照切れ・古い設定説明・実行不能な計測CLIをなくしてから完了とする。

## 7. 検証項目

| 分類 | 確認事項 |
|---|---|
| 幾何 | 単純な箱・離れた保持部品・斜め配置で凸包と余白が期待どおり。保持やアンカーとは無関係のボディを追加しても空間が変わらない |
| 入力 | 複数保持、保持以外のボディ上の条件面、条件重複、空条件面、退化形状を扱える |
| 座標 | ワールド座標とセル中心の対応、平行移動での整合。回転では軸平行外接箱が変わるため完全な回転不変性は要求しない |
| 条件の保持 | 全保持領域と全条件面を個別確認。一部条件だけがつながる反例を失敗にする |
| 接続 | 角・辺だけの接触を6近傍の接続として扱わない。必要な条件を含む分離成分を黙って捨てない |
| 除外 | 通路を塞ぐ除外で失敗し、無関係の成分だけは削除できる |
| 固定性 | 小・中・大の材料量を評価しても格子・マスク・面対応のハッシュが不変。導出が1回、参照SIMPが0回 |
| 後段配線 | フィルタ半径・荷重・拘束の値が変わらない。容量不足の候補を適切に扱う |
| 記録 | 新方式の入力・途中マスク・最終マスクを再現可能。失敗理由も保存 |
| 製品 | 新たなCAD追加、元ボディ不変、undo/redo・文書再生・中断・失敗の契約が維持される |

hangerでは余白 0.25・面オフセットで522,424セル(余白 0.20・面オフセットで389,213セル、現在の既定=余白 0.20・距離で367,390セル)、保持欠損0、必要条件の単一連結成分、前回採用密度の取りこぼし0を確認する。
セル数が異なる場合は格子・箱・境界判定の差を説明し、理由なく期待値を更新しない。

後段に十分な範囲かの追加評価は、材料量とSIMP設定を固定して、採用案と広い基準空間を一度比較する。
比較対象は収束履歴、コンプライアンス、応力評価、外周付近の材料配置とする。
両方が反復上限で止まった場合は「空間の十分性を確定した」とは扱わない。
この構造性能比較は導出の単体検査と分けて記録し、今回既に残っている平滑化・ブーリアン問題を空間導出の不合格と混同しない。
