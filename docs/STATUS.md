前提になる本人の基準: 「初期設定でプリントできることが重要である」([THREAD.md](THREAD.md)「山形の調査」の末尾)。

計画(親の案に astra の反論を入れたもの。経緯は decisions.md):

1. 評価方法を作る: 山形の族([tools/thread_sim/profiles.py](../tools/thread_sim/profiles.py))、Centauri Carbon の既定プロファイルでの印刷の模擬(層の断面・XY の法線での張り出しと支持・垂れ・ビードの形)、螺旋位相の包絡による嵌合の十分条件+直接の干渉計算、軸対称 FEA(2物体・摩擦なし接触)による強度の比較。
2. 方法を検証する: 数値の検算(解析解)、既知の観測(本人の経験・公開された隙間の値)との突き合わせ、未知の係数の感度解析。
3. 反復: 外形(ナット外径・はめあい長)を固定して、族ごとに最適化。最小径・隙間の窓の幅・強度で比べる。
4. 本人の試し刷り1回分(STL と結果を返すページ)を用意する。

本人に残りそうな判断: 試し刷り(身体が要る)。OrcaSlicer の追加ダウンロードは使わずに進めた(自前の模擬で代えた)。

### どこまで来たか(2026-10-18)

- **評価方法の初版ができ、本人なしでできる検証は終わった**([THREAD_SIM.md](THREAD_SIM.md)、道具は [tools/thread_sim/](../tools/thread_sim/))。
  残るのは実物との突き合わせ(試し刷り TP1。本人待ちのカード1件、decisions.md「本人待ち」)。
- 検証したこと(計算の中): FEA は解析解の全項目に合格、強度のリング模型は 3D の周期模型と ±10%(芯の引張の3設計)、
  Codex のレビューの重い指摘3件とメッシュの発散を直して全 study を回し直した(結論は変わらず。変化は D10 P4 の法線方向の3設計だけ)、
  手元とクラウドで計算が一致(study3・4・6・7)、試し刷り一式は今のコードで作り直してもバイト単位で同じ。
- 結果(THREAD_SIM.md 5章、すべて直した後の値):
  - 小径の限界を決めるのは誤差を吸収できる幅 W。40〜50° の台形が上位で、**W ≈ 山の高さ − 0.2mm**(5.1・5.3)。
  - 基準の係数で W ≥ 0.2 が残る最小の径は D2.5。非対称の斜面・山頂の取り分は W を変えない(5.4)。
  - **隙間は穴の側に持たせる**と W を変えずに強い(D3 +12〜30%、D8 +2〜8%。5.5)。
  - **隙間を固定して係数の不確かさを入れると、40〜50° は W が 0.1 減るだけ、ISO・30°・半円は 0.2〜0.35 減る**(D8 の ISO は 0.07。5.6)。
- まだ確かめていないこと: 実物の嵌合(TP1)、実物の強さ(TP1 は嵌合だけ)、初期設定でスライスした実際の経路(ElegooSlicer の CLI が落ちるので自前の模擬で代えた)、
  完成部品(頭・入口の面取り・座面)での成立、強さの絶対値(層間強度が未較正)。W ≥ 0.2 は仮置き。
- 結果の生データは `output/thread_sim/`(git 管理外)。直す前の結果は `output/thread_sim/pre_review_fix/`。
