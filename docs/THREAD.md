# ねじ verb の設計（3Dプリント前提）

**状態: 設計だけ。未実装**（2026-10-16）。実装に入るときと、ねじ山の形・寸法を疑うときに読む。

本人の依頼（原文）:

> ネジを手早く作成するverbがほしい。3dpすることを前提にしたものであってほしい。

## 結論

- **verb `thread`（画面の名前「ねじ」）を1つ足す。** 選んだ**全周の円筒面にねじ山を実体で刻む**。
  外向きの面（軸）なら雄ねじ、内向きの面（穴）なら雌ねじ。どちらになるかは面の向きで決まり、引数は無い。
- 手順は **「ねじ」→ 円筒面をクリック（同じ直径なら複数可）→ 幽霊を見て Enter**。ピッチと隙間は空欄のままで規格どおりに埋まる。
- **3Dプリント前提で決めたのは4つ**: 面の直径を呼び径とみなす／隙間を一級の引数にする／相手が入ってくる端だけ自動で面取りする／
  尖りの無い ISO 基準山形を使う（下の「3Dプリント前提で決めること」）。
- **形は集合演算を使わずに面から直接組む**（下の「形の作り方」）。螺旋の歯を芯の円柱に足す素直な作り方は、
  `BRepCheck` が真のまま芯が消える（M5×0.8 で体積 −84%）ので採らない。

## 何を作り、何を作らないか

| | 判断 | 理由 |
|---|---|---|
| 円筒面へのねじ山（雄・雌） | **作る** | 既存の verb（円を描く→押し出し／穴を切る）の続きに1手で載る。ボルト・ナット・ねじ込みの蓋・部品に切ったねじ穴が全部これで済む |
| ボルト・ナットを丸ごと生む verb | 作らない | 粒度が粗すぎる（[DESIGN_DECISIONS.md](DESIGN_DECISIONS.md)「verb ＝ undo1回・ログ1行・MCP1呼び出し」）。AI なら「円→押し出し→ねじ」の3〜4呼び出しで組める |
| 六角の頭・ナットの凹み | このverbでは扱わない | 遅いのはねじ山ではなく六角形を線6本で描くところ。正多角形のスケッチ図形が別に要る |
| 金属ねじ用の穴（下穴・インサート穴・ナット凹み） | このverbでは扱わない | ねじ山を作らない別物。3Dプリントで金属ねじを使う部品では最も頻度が高いかもしれないので、別の verb として検討する |
| 左ねじ・ねじ部の長さ指定・別の山形（台形・45度） | 後から足せる | 下の作り方は「軸方向の断面が r=f(z) の折れ線で書ける山形」なら何でも受ける。足すのは引数と山形の表だけ |

## 3Dプリント前提で決めること

### 1. 面の直径を呼び径とみなす（雄も雌も）

**M8 のボルトも M8 のナットも「直径8mmの円柱／穴」を描いてねじを掛ける。** 下穴径（タップ径・谷径）を覚えなくてよい。
Fusion360 の「穴は下穴径で描く」流儀は採らない。印刷すると穴が痩せる分は次の隙間が受け持つ。

- 呼び径が ISO 261 の並目の表（M1.6〜M64）に**±0.05mm で当たれば**、ピッチの空欄はその並目で埋まる（±0.05mm は AI の仮置き）。
- 表に無い直径（ねじ込みの蓋など）はピッチの入力を必須にする（空欄なら断る）。

### 2. 隙間（クリアランス）を一級の引数にする

- **定義: このねじの山形を半径方向に片側いくら動かすか**（雄は内へ、雌は外へ）。スライサーの「X-Y 穴補正」と同じ片側の流儀。
  スライサー側でも補正しているなら**二重にかかる**。
- 印刷どうしの組では両方の隙間が足される。金属ねじと組む印刷側は1つで全部を持つ。だから**ねじ1回ごとの入力**にする
  （外注の造形方式でも値が変わる）。
- 60度山なので、半径方向の隙間 c の組（雄 c₁・雌 c₂）の斜面どうしの法線方向のすき間は (c₁+c₂)·sin30° = (c₁+c₂)/2（計算値）。
- **既定値は本人の試し刷り（隙間を振ったボルトとナットの組）で決める。** それまでの仮置きは 0.15mm で、**AI が置いた値であって実測ではない**。

### 3. 相手が入ってくる端だけ、自動で面取りする

象の足（1層目のはみ出し）と食いつきのため。**引数にはしない**（印刷物で要らない場面がほぼ無い）。

- **雄**: 隣の面が「内側の平面」（先端の円板）の端。45度、深さ = 山の高さ + 0.1P（0.1P は AI の仮置き）。
- **雌**: 隣の面が「外側へ広がる平面」（部品の表面）の端。45度、深さ = 山の高さ。貫通穴は両端、止まり穴は口だけ、両端が先端のスタッドも両端。
- 隣が平面でない（利用者が面取り・フィレット済み）端には何もしない。

### 4. 尖りの無い ISO 基準山形

- 60度、山頂の平坦 P/8、谷の平坦 P/4（ISO 68-1 の基準山形）。**金属のねじ・ナットとそのまま組める**のが他の山形に勝つ点。
- 山の高さは 0.541P（計算値）: M3 0.27 / M4 0.38 / M5 0.43 / M6 0.54 / M8 0.68 / M10 0.81 / M12 0.95 mm。
  0.4mm ノズルなら M4 以下は山の高さが線幅（0.4mm 以上）を下回る。印刷で使える下限は試し刷りで決める（verb は断らない）。
- 軸を鉛直にして刷ると、下向きの斜面は水平から30度（計算値）。軸を鉛直にしたボルトは層の向きが引張に弱い
  （FDM の層間は XY の 40〜60%。[TOPOPT.md](TOPOPT.md)）。横置きにして平らに削る作り方はこの verb の外。

## verb の形（verb → target → how）

| | 中身 |
|---|---|
| target | 全周の円筒面（`kernel.classify_face` の `cylinder_full`）を1つ以上。**直径がすべて同じ**こと。別のボディにまたがってよい |
| how | `pitch`（mm、省略可＝並目）、`clearance`（mm、省略可＝既定）。どちらも `dimension=True` |
| 返り値 | `changed_bodies` |
| 宣言 | `category="feature"`・`previewable=True`・`resets_selection=True`・`ws="table"` |
| 操作ログ | 空欄から決まった値も**解決後の数値で残す**（表を直しても古い文書の再生が変わらない）。面の参照は `fillet` と同じ形で残す |
| Enter | 要る（how の数値欄があるので `needsEnter` が真）。幽霊を見てから確定する |

**断るもの**（トースト）: 円筒面でない・全周でない／メッシュボディ（`meshbody.reject`）／面の端が軸に垂直な円でない／
選んだ面の直径が揃っていない／表に無い直径でピッチが空欄／山の谷が軸に届く（ピッチが直径に比べて大きすぎる）／
**雄ねじの先が既に細くなっている**（面取り済みの先端の上にねじを切ると、先が山より太い段になってナットに入らない。
面取りはねじが入れるので、面取りの前にねじを切る）。

MCP の説明文の案: 「選択した全周の円筒面にねじ山を刻むときに呼ぶ。外向きの面（軸）は雄ねじ、内向きの面（穴）は雌ねじになる。
面の直径を呼び径として扱う（M8 なら直径8mmの円柱・穴に掛ける）。」

## 形の作り方（実測で選んだ）

再現は `tools/thread_prototype.py`（採らなかった方式は `--rejected`）。数値はすべて 2026-10-16、OCP 7.9.3、このPC。
期待体積は解析式（折れ線山形の断面積）か、面取りぶんを含めた (θ, z) 格子の数値積分。体積は `VolumeProperties_s` の Eps=1e-7 で測った。

### 採らない: 螺旋の歯 ∪ 芯の円柱

歯（山形を螺旋に掃いた立体）を作って芯の円柱と `BRepAlgoAPI_Fuse` する作り方。3〜4秒かかり、**`BRepCheck` が真のまま結果が壊れる**:

| | 体積の誤差 |
|---|---|
| M3×0.5 | +3.5e-07 |
| M5×0.8 | **−8.4e-01**（芯が消えて歯だけ残る） |
| M8×1.25 | +6.9e-09 |

歯の谷を芯の内側へ食い込ませても、谷を芯の円筒面に一致させても、`SetGlue` / `SetFuzzyValue` を変えても M5 は直らなかった。
寸法によって当たり外れが出るので、検査を付けても「この寸法は作れない」が残る。

### 採る: 面から直接組む

ねじの側面は `r = f((z − kθ) mod P)`（k = P/2π、f は1ピッチ分の折れ線の山形）と書ける。

1. 山形の折れ線の各区間は、**θ を引数とする2本のヘリックスの間の線織面に厳密に一致する**（同じ θ の2点を結ぶ線分がその区間の母線）。
   ヘリックスを θ で補間した3次 B-spline（1周64点）にし、2本の極を並べた (3,1) 次の B-spline 面を作る。
2. 端の平面 z=0 / z=L の切り口は、各帯の (θ, t) 引数空間で**直線**になる。2D直線の pcurve で縁取るので、平面と螺旋面の交線計算が要らない。
3. 帯だけを先に縫い、残った2本の開いた縁から平面の蓋を作って縫い直す（**蓋と帯で辺を共有させて一度に縫うと、縫い合わせが端の辺を縮退扱いにして殻にならない**）。

ボディへ掛けるときに集合演算が触るのは、**同一平面どうし・同軸同径の円筒どうし**と、雄の先端の面取りで**切り離した軸だけ**に掛ける円錐だけになる:

- **雄**: 軸を作る → 先端の面取りの回転体と共通部分（軸だけで）→ ボディから円柱域（半径 R+0.01）を切る → 軸を足す
- **雌**: 穴の入口の円の辺を**先に**面取りする（既存の `kernel.chamfer_edges`）→ 残った円筒面の範囲で穴を埋める円柱を足す → 雌側の寸法の軸を引く

| 場面（M3×0.5 / M5×0.8 / M8×1.25 / M20×2.5 / M60×4 の5寸法） | 時間 | 体積の誤差 | STL（0.01mm）の三角形 |
|---|---|---|---|
| 軸だけ | 0.03〜0.07秒 | 2.4e-07 以下 | 7,758〜35,368 |
| 箱の頭の上面に立てたボルト | 0.03〜0.10秒 | 1.2e-07 以下 | 7,774〜35,384 |
| 板の上の円柱に雄ねじ＋先端の面取り | 0.50〜1.21秒 | 1.7e-07 以下 | 7,406〜34,218 |
| 入口を面取りした穴に雌ねじ | 0.37〜1.42秒 | 3.0e-08 以下 | 8,030〜15,802 |

5寸法×4場面すべて `BRepCheck` 真・1ソリッド・三角形の取れない面なし。

**雌ねじの皿取りを後から円錐で引くと悪くなる**（ねじを切った本体から円錐を引く順）: 1〜7秒・体積の誤差 7.7e-04〜1.5e-03、
M60×4 は STL の三角形分割で2面が取れず13秒かかった。だから**円錐を当てるのは、螺旋の面がまだ無い段（雌）か、切り離した軸（雄）に限る**。

### 体積の既定積分はねじ山で狂う

`kernel.volume`（`VolumeProperties_s` の既定積分。Eps 無し）は、何周も巻いた B-spline の面で誤差が出る:
採らない方式の歯だけで −1.9e-01（M5×0.8）、採る方式の軸だけで最大 1.5e-03、ボルト・ナットの形で最大 3.5e-04。
`describe_document` が AI に見せる体積はこの値なので、AI の指示文の「体積差 0.1% 以内を指示どおりとみなす」（issue #134）に
軸だけのときは掛かりうる。帯を1周ごとの面に割ると直るかは未測定（割ると面の数が周回数倍になり、画面で選ぶ単位も増える）。

## 合否の門と検査

- **kernel の門**（フィレットの4つと同じ考え方。[../README.md](../README.md)「実測で判明している技術的な地雷」）:
  `IsDone()` / 空でない / `BRepCheck` 真 / **体積の増減が期待値と合う**。期待値は解析式（面取りぶんは数値積分）、体積は Eps 付きで測る。
  許容は「ねじ部の体積の 1%」（AI の仮置き。採らない方式の壊れ方 −84% を確実に弾き、Eps 付きの最悪 2.2e-04（L=60 の軸）で誤って落とさない幅）。
- **pytest**（`tests/test_thread.py`）: 上の5寸法で雄・雌・貫通・止まり・複数面・別ボディ／断るもの全部／undo・redo・ログからの再生で同じ形／
  STL の接続検査（`mesh_geometry` の境界の接続）／雄 c と雌 c の組が干渉しない（同じ山形を半径方向に 2c ずらしただけなので、同軸・同じ位相で重ねた共通部分の体積が0）。
- 幽霊とコアの確定結果の一致は `tests/test_ghost_agreement.py` の枠に載せる。
- **はまるかどうかは試し刷りでしか決まらない。** 隙間を振ったボルト・ナットの組を本人が刷って、既定値と小径の下限を決める。
