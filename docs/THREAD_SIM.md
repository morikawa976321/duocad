# 3Dプリントねじの山形を計算機の中で評価する方法

**状態: 評価方法の初版を作り、検証中**(2026-10-17)。山形の比較・改良をするときと、試し刷りの結果を読むときに読む。
進め方の判断は [decisions.md](decisions.md) の `[ねじ]` の節、現在地は [STATUS.md](STATUS.md)。

本人の依頼(原文):

> 調査はここで打ち切って、コンピューター内でのシミュレションを行いたい。あなたがさまざまなモデルを作成し、プリントのしやすさと壊れにくさをシミュレーションしてほしい。これを何度も反復してで改良と試作を重ねてより良い形状を模索する作業をしてほしい。まずはプリントのしやすさと壊れにくさの評価を行う方法を確立する必要がある。その作業を行ってほしい

前提の基準(本人の原文、[THREAD.md](THREAD.md)「山形の調査」): 「スライサー設定を詰めるのもやりたくない。初期設定でプリントできることが重要である。」

道具は [tools/thread_sim/](../tools/thread_sim/)(duocad 本体からは import しない)。結果は `output/thread_sim/`(git 管理外)。

## 1. 何を評価するか

| 軸 | 指標 | 意味 |
|---|---|---|
| 刷りやすさ | 張り出しの欠け(外壁が前の層に乗らない割合。Orca の 1/4〜4/4 と同じ量)、垂れの最大 | 下向きの面がきれいに刷れるか |
| | 山の高さの保持、平均の山形と設計の差の RMS | 尖った山頂・谷がどれだけ丸まるか |
| 嵌合 | **必要な隙間 c_geo**(雌雄の和・半径) | この隙間より小さいと、印刷後の段と垂れが当たって回らない |
| | 掛かり代(印刷後の平均の山どうしの半径方向の重なり) | 隙間を足した後に残る、荷重を受ける山の高さ |
| 壊れにくさ | 破断荷重 F と破壊の場所(芯の層間・雄の山・雌の山) | 軸方向に引いたとき |
| 総合 | 寸法誤差 e(山形によらない半径の誤差)を見込んだ隙間 c = c_geo + e での F | 誤差が大きい機械ほど、掛かり代の少ない山形から先に使えなくなる |

最初の版は**軸鉛直に刷った雄と雌、軸方向の静的な引張**に絞った。ねじ込みのトルク、締め付けのねじり、反復着脱による緩み、
摩耗は評価の軸の表に載せたまま後の段にした(astra の指摘。decisions.md)。

## 2. 印刷の模擬(`printer.py`・`printsim.py`)

スライサーの初期設定は、ElegooSlicer の system プロファイル(Centauri Carbon 0.4 ノズル・「0.20mm Standard」・Elegoo PLA)の
継承をベンダー Elegoo の中で解いた値: 層 0.2・初層 0.2・外壁 0.42・内壁 0.45・壁2周・classic・seam aligned・壁順 inner→outer・
XY 補正 0・張り出しの減速 2/4=50・3/4=30・4/4=10 mm/s・最小層時間 4 秒。`printer.check_against_installed()` が食い違いを報告する。

ElegooSlicer の CLI は落ちて使えないので(decisions.md)、スライスは自前で模擬する。1層ごとに:

1. 層の中央の高さで断面を取る。ねじの断面は原点まわりの星形の曲線 R(θ)。
2. 外壁のビードは幅 w の円板を断面の内側で転がした跡なので、印刷される外形は半径 w/2 の開放演算(雌は穴から見て閉包)。
   円板の包絡を極座標のまま厳密に計算する。
3. **支持**: 今の層の外形の各点から前の層の外形までの、XY 平面での符号付き距離 d。支持率 φ = clip(1 − d/w, 0, 1)。
   同じ θ の半径差ではなく XY の法線で測る(粗いピッチ・小径では断面が θ 方向に急に変わり、両者がずれる。astra の指摘)。
4. **垂れ**: φ < φ_ok の点で、張り出した部分が δ = h·a·((φ_ok − φ)/φ_ok)^n だけ下へ垂れる。既定 a=1・φ_ok=0.5・n=1.5 は
   **AI の仮置き**で、PLA・0.4 ノズル・層 0.2 で垂れの量を角度ごとに測った資料は見つからなかった(調査の報告)。感度解析で振る。
5. **ビードの側面**: 半径 h/2 の半円(係数 `bead_round` で 0=角の立った矩形〜1=半円)。高さ z での外形は、層の外形を
   XY の法線方向へ (h/2)(1 − √(1 − ((z − z_c)/(h/2))²)) だけ縮めたもの。
6. **寸法誤差**: 雄の外形の太り、雌の穴の痩せ、層ごとのばらつき、継ぎ目の膨らみ(seam aligned なので毎層同じ角度)。
   どれも必要な隙間に**そのまま足し算で効く**(実測: 外形 +0.05 → +0.050、穴 −0.08 → +0.080、継ぎ目 0.1 → +0.184〈雄と雌の両方に出る〉、
   ばらつき σ0.02 → +0.098)。だから必要な隙間は「山形で決まる c_geo」と「山形によらない誤差 e」に分けて扱う。

検算(解析解との比較):

| 場面 | 模擬 | 解析 |
|---|---|---|
| 円柱(ねじ無し) | 張り出し 0、外形 = 半径 | 同じ |
| 対称台形 β=45°・P4・深さ1・d12 の下向きの面の1層の張り出し | 0.199 mm、φ 0.526 | h/tanβ = 0.200、0.524 |
| 同 β=30° | 0.340 | 0.346(差は XY 法線と半径方向の違い) |
| 同 β=60° | 0.115 | 0.115 |
| 半径3の円の円板 0.2 による侵食・膨張 | 2.8 / 3.2 | 同じ |

## 3. 嵌合の判定(`fit.py`)

雄と雌は同じピッチの螺旋運動で相対的に動くので、雄の位相 s = (z − kθ) mod P の点は、ねじ込むあいだに雌の同じ位相の点とすべて出会う。
だから位相ごとの包絡(雄の最大半径 E_b(s)、雌の最小半径 E_n(s))を比べ、軸方向の遊び δ を許して
∀s: E_b(s) ≤ E_n(s + δ) となる δ があれば、剛体としてはまる。**これは十分条件**(実際には出会わない欠陥の組まで重ねる)。

- 必要な隙間は、雌を半径方向に Δc 動かすと余りも Δc だけ動くことを使って1回の模擬で出す(隙間 0/0.2/0.4 で c_req が ±0.001mm で一致。実測)。
  法線方向の隙間は線形でないので二分法で出す。
- **保守性の確認**: 回転角と挿入量を保ち、各位置で軸方向の浮き δ を最良に選ぶ直接の干渉計算(`direct_interference`)と比べた。
  最悪の位置で要る隙間は包絡とほぼ同じだった(ISO M6 0.399 対 0.382、45° 台形 0.102 対 0.087、半円 0.442 対 0.441。差は直接計算の格子が粗い分)。
  層の段の当たりは、ある挿入位置で雄と雌の層の位相の差が全周で揃うときに起き(位相の差は位置によらず一様)、そこでは全周の段が同時に当たるので、
  包絡は保守的すぎない。最良の位置では ISO で 0.307 まで下がる(回すと周期的にきつくなる)。
- **段の鼻の高さ**: ビードの側面が半円なら、段の角が理想の斜面から半径方向に飛び出す量は1部品あたり (h/2)·max_t[t/tanβ − 1 + √(1−t²)]
  = ISO(30°) で 0.100 mm、45° で 0.041 mm(計算)。雌雄で倍。

## 4. 強さの評価(`mesh.py`・`fea.py`・`strength.py`)

- 軸対称 2D の線形弾性 FEA(6節点三角形、横等方〈層の法線 = 軸〉、2物体の摩擦なし一方向接触を接触自由度へ縮約した LCP)。
  実装は Codex、検証は解析解: 一様引張 1e-13、Lamé の厚肉円筒 σ_r 0.19%・σ_θ 0.05%、U 字切欠きの丸棒の Kt(Noda–Takase の式)と 0.6〜2.0%、
  Hertz の接触半径 0.2%・最大圧 3.1%、接触のパッチテスト 1e-13、横等方の E_z 1e-14(`verify_fea.py --case all`)。
- 山は、印刷の模擬から取った**位相ごとの平均の山形**(θ で平均)をリングの山として使う。層の段をそのまま軸対称に持ち込むと
  全周につながる切欠きになるので使わない(astra の指摘)。
- ナットは外径 1.8d・はめあい長 1d に固定して比べる(外形で強さを稼げないように)。座面は下面の外側の円環で u_z=0、ボルトは下端を引き下げる。
  ボルトの山の**下向きの面**(頭を下にして刷ると張り出しになる面)が荷重を受ける。
- 判定を4つ並べる: 正味断面の **芯の層間引張**・**雄の山の付け根のせん断**・**雌の山の付け根のせん断**(荷重は全山で一様と仮定)と、
  FEA の応力を臨界距離理論(TCD の面積法: 半径 1.32L の円内で応力テンソルを平均)で評価した異方性の破壊指数。
  どれか1つを正解とせず、食い違う設計は「順位未確定」とする。平均化しない接触圧は局所降伏の目安としてだけ出す。
- メッシュの粗さ(表面 0.045〜0.02 mm)で破断荷重は 1 N も変わらなかった(ISO M6・45° 台形)。1設計 6〜10 秒。

材料(PLA、軸鉛直に刷ったもの。`strength.PrintedPLA`)は文献の幅の中ほどに置いた**仮の値**で、比べるときは感度で振る:

| 量 | 置いた値 | 文献の幅(調査の報告) |
|---|---|---|
| 層間の引張 Z_t | 30 MPa(感度 15〜35) | 面内の 0.09〜0.63 倍。Hanon 2021(DOI 10.3311/PPme.13683)35.6、Prusament の層間接着 17±3 |
| 層間せん断 S | 25 MPa(感度 10〜25) | Gonabadi 2020(DOI 10.1007/s00170-020-06138-4)の upright で約 18 |
| 面内の引張 | 50 MPa | 49〜57(Hanon 2021) |
| 臨界距離 L | 0.5 mm(感度 0.25〜1.0) | Ahmed & Susmel 2018(DOI 10.1111/ffe.12746)4.6 mm、2019(DOI 10.1111/ffe.12958)2.4 mm。どちらも平置きの試験片で、軸鉛直の値は無い |

**印刷 PLA は切欠きにほとんど鈍感**(L が山の深さより長い。R2 mm の切欠きで静的強度の低下が約1.5%: Seifollahi 2025, DOI 10.3390/polym18010001)。
だから強さは局所の応力集中より正味断面(芯の太さ・山の付け根の長さ)と荷重分担で決まり、TCD と正味断面の値は近い(M6 相当で 529 対 491 N)。
