## 1. 評価の組み立て

```
山形の折れ線 f(s) ──► 印刷の模擬(層ごと) ──► 印刷後の表面 F[θ, z] ──┬─► 嵌合: 必要な隙間 c_geo、掛かり代、誤差を吸収できる幅 W
 (profiles.py)        (printsim.py)                                  └─► 強さ: θ で平均した山形 → 軸対称 FEA + 正味断面(strength.py)
```

| 軸 | 指標 | 意味 |
|---|---|---|
| 刷りやすさ | 張り出しの欠け(外壁が前の層に乗らない割合。Orca の張り出しの区分と同じ量)、垂れの最大 | 下向きの面がきれいに刷れるか |
| | 山の高さの保持、平均の山形と設計の差の RMS | 尖った山頂・谷がどれだけ丸まるか |
| 嵌合 | **必要な隙間 c_geo**(雌雄の和・半径) | これより小さいと、印刷後の層の段と垂れが当たって回らない |
| | **誤差を吸収できる幅 W** | 印刷の寸法の狂い(外形の太り・穴の痩せ)がこの幅の中なら、はまり、かつ掛かりが残る。**山形の頑健さの主な指標** |
| 壊れにくさ | 引張で保持できる荷重(下限〜上限)、締め付けで芯がねじ切れる軸力、乗り越えの目安 | 窓の中心(狂いが見込みどおり)と緩い端(掛かりが下限)で |

外形は**ナット外径 1.8d・はめあい長 1d に固定**して比べる(外形で強さを稼げないように。astra の指摘)。造形の向きは雄雌とも軸鉛直、
ボルトは頭を下、ナットは座面を下(バットレスだけボルトを逆さ)。

### 誤差を吸収できる幅 W

印刷の寸法誤差 ε(雌雄の和・半径。+ で雄が太り穴が痩せる)は、外形と穴の半径を一様にずらす。
だから、はまる余り(包絡の余り)は ε だけ減り、掛かり代は ε だけ増える(模擬の中で確かめた: 外形 +0.05 → 必要な隙間 +0.050、穴 −0.08 → +0.080)。
設計の隙間を c に決めたとき、使える ε の範囲は [掛かりの下限 − 掛かり代(c), 余り(c)] で、その幅

> **W = 余り(c) + 掛かり代(c) − 掛かりの下限**

は誤差なしの模擬1回で出る。半径方向の隙間なら W は c によらず一定(余りと掛かり代が逆向きに同じだけ動く)。
法線方向の隙間なら c で変わるので、窓の中心が ε=0 に来る c を選ぶ。掛かりの下限は**暫定で 0.1mm**(AI の置いた値。W を全設計で同じだけずらすので順位は変わらない)。

これは astra の指摘で組み直した。最初の版は「設計の隙間 = c_geo + 誤差」で強さを測っていたが、それは「余分な隙間を足して誤差なしで刷った」強さで、
実際に太った雄と痩せた雌の強さではなかった。

## 2. 印刷の模擬(`printer.py`・`printsim.py`)

スライサーの初期設定は、ElegooSlicer の system プロファイル(Centauri Carbon 0.4 ノズル・「0.20mm Standard」・Elegoo PLA)の
継承をベンダー Elegoo の中で解いた値: 層 0.2・初層 0.2・外壁 0.42・内壁 0.45・**壁2周**・classic・seam aligned・壁順 inner→outer・
XY 補正 0・充填 15% zig-zag・張り出しの減速 2/4=50・3/4=30・4/4=10 mm/s・最小層時間 4 秒。継承元の名前はベンダーごとに中身が違う
(Custom の `fdm_process_common` は壁3周・外壁100%)ので、同じベンダーを先に引く。`printer.check_against_installed()` が食い違いを報告する。

ElegooSlicer 1.3.0.11 の CLI は既定プロファイルを読んだ後に毎回落ちる(14通り試した。decisions.md)ので、スライスは自前で模擬する。1層ごとに:

1. 層の中央の高さで断面を取る。ねじの断面は原点まわりの星形の曲線 R(θ) = f(z − kθ)。
2. 外壁のビードは幅 w の円板を断面の内側で転がした跡なので、印刷される外形は半径 w/2 の開放演算(雌は穴から見て閉包)。
   円板の包絡を極座標のまま厳密に計算する。
3. **支持**: 今の層の外形の各点から前の層の外形までの、XY 平面での符号付き距離 d。支持率 φ = clip(1 − d/w, 0, 1)。
   同じ θ の半径差ではなく XY の法線で測る(粗いピッチ・小径では断面が θ 方向に急に変わる。astra の指摘)。
   螺旋では、軸を含む断面で水平な「天井」も、XY では前の層を Δθ = 2πh/P だけ回した形になるので、弧 R·Δθ の幅は支えがある。
4. **垂れ**: φ < φ_ok の点で、張り出した部分が δ = h·a·((φ_ok − φ)/φ_ok)^n だけ下へ垂れる。既定 a=1・φ_ok=0.5・n=1.5 は
   **AI の仮置き**。PLA・0.4 ノズル・層 0.2 で垂れの量を角度ごとに測った資料は見つからなかった。平らな斜面で φ=0.5 になるのは水平から 43.6°
   なので、「45° で垂れゼロ」はこの閾値をまたいだ結果でもある(astra の指摘)。感度解析で振る。
5. **ビードの側面**: 半径 h/2 の半円(係数 `bead_round` で 0=角の立った矩形〜1=半円)。高さ z での外形は、層の外形を円板で
   (h/2)(1 − √(1 − ((z − z_c)/(h/2))²)) だけ侵食したもの。
6. **寸法誤差**: 雄の外形の太り、雌の穴の痩せ、層ごとのばらつき、継ぎ目の膨らみ(seam aligned なので毎層同じ角度)。
   どれも模擬の中では必要な隙間に足し算で効く(外形 +0.05 → +0.050、穴 −0.08 → +0.080、継ぎ目 0.1 → +0.184〈雄と雌の両方に出る〉、
   ばらつき σ0.02 → +0.098)。**これは模擬の中の数値実験で、実機で確かめたことではない**(astra の指摘)。

検算(解析解との比較):

| 場面 | 模擬 | 解析 |
|---|---|---|
| 円柱(ねじ無し) | 張り出し 0、外形 = 半径 | 同じ |
| 対称台形 β=45°・P4・深さ1・d12 の下向きの面の1層の張り出し | 0.199 mm、φ 0.526 | h/tanβ = 0.200、0.524 |
| 同 β=30° | 0.340 | 0.346(差は XY 法線と半径方向の違い) |

## 3. 嵌合の判定(`fit.py`)

雄と雌は同じピッチの螺旋運動で相対的に動くので、雄の位相 s = (z − kθ) mod P の点は、ねじ込むあいだに雌の同じ位相の点とすべて出会う。
だから位相ごとの包絡(雄の最大半径 E_b(s)、雌の最小半径 E_n(s))を比べ、軸方向の遊び δ を許して
∀s: E_b(s) ≤ E_n(s + δ) となる δ があれば、剛体としてはまる。**これは十分条件**(実際には出会わない欠陥の組まで重ねる)。

- 必要な隙間は、雌を半径方向に Δc 動かすと余りも Δc だけ動くことを使って1回の模擬で出す(隙間 0/0.2/0.4 で c_req が ±0.001mm で一致)。
  法線方向の隙間は線形でないので二分法で出す。
- **保守性の確認**: 回転角と挿入量を保ち、各位置で軸方向の浮き δ を最良に選ぶ直接の干渉計算(`direct_interference`)と比べた。
  最悪の位置で要る隙間は包絡とほぼ同じ(ISO M6 0.399 対 0.382、45° 台形 0.102 対 0.087、半円 0.442 対 0.441。差は直接計算の格子が粗い分)。
  層の段の当たりは、ある挿入位置で雄と雌の層の位相の差が全周で揃うときに起き(位相の差は位置によらず一様)、そこでは全周の段が同時に当たる。
  最良の位置では ISO で 0.307 まで下がる(回すと周期的にきつくなる)。
- **段の鼻**: ビードの側面が半円なら、段の角が理想の斜面から半径方向に飛び出す量は1部品あたり (h/2)·max_t[t/tanβ − 1 + √(1−t²)]
  = ISO(30°) で 0.100 mm、45° で 0.041 mm(計算)。雌雄で倍。
- **剛体のままの判定である**。PLA の段の鼻(0.1mm 級)はねじ込みで潰れたり削れたりしうる。フォーラムに「Fusion の標準のモデル化ねじ(半径の和で 0.1 前後)の
  M12・M14 がよく回った」という報告が1件あり、模型の ISO の c_geo 0.38 と食い違う。条件(層高・材質・初回か馴染ませた後か)が不明なので、
  模型の棄却にも無視にも使わず、試し刷りで「予測より十分小さい隙間でも回るか」を確かめる。

## 4. 強さの評価(`mesh.py`・`fea.py`・`strength.py`)

- 軸対称 2D の線形弾性 FEA(6節点三角形、横等方〈層の法線 = 軸〉、要素ごとの材料、2物体の摩擦なし一方向接触を接触自由度へ縮約した LCP)。
  実装は Codex、検証は解析解: 一様引張 1e-13、Lamé の厚肉円筒 σ_r 0.19%・σ_θ 0.05%、U 字切欠きの丸棒の Kt(Noda–Takase の式)と 0.6〜2.0%、
  Hertz の接触半径 0.2%・最大圧 3.1%、接触のパッチテスト 1e-13、横等方の E_z 1e-14(`verify_fea.py --case all`)。
  接触の候補で、射影が辺の外へはみ出して端点に丸められた組は辺の法線で測ると符号が逆になる(重なり0で g=−0.4mm を実測)ので捨てる。
- 山は、印刷の模擬から取った**位相ごとの平均の山形**(θ で平均)をリングの山として使う。層の段をそのまま軸対称に持ち込むと
  全周につながる切欠きになるので使わない(astra の指摘)。
- 座面は下面の外側の円環で u_z=0、ボルトは下端を引き下げる。ボルトの山の**下向きの面**(頭を下にして刷ると張り出しになる面)が荷重を受ける。
- **既定の印刷の構造**: 表面から t_wall = 0.83mm(外壁 0.42 + 内壁 0.45 − 重なり h(1−π/4))は中実の壁、その内側は 15% の zig-zag 充填。
  zig-zag は層ごとに向きが変わり、層間は線の交点でしか接しないので、充填の剛性は中実の 6%、層間の強さは 3% と置いた(AI の仮置き、感度で振る)。
  径 6 以上のボルトの芯は大半が充填なので、**層間の引張とねじりはほぼ壁の帯が受ける**。壁の帯は層ごとに山形に沿って半径方向にジグザグし、
  全層をまっすぐ貫く壁は山の深さが壁の厚さより浅いときしか残らない。
- 判定:
  - **引張で保持できる荷重の下限**: リング模型の FEA の応力を、壁の中だけで臨界距離の円(TCD の面積法、半径 1.32L)で平均した異方性の破壊指数
    (層間 (σ_z/Z_t)² + (τ/S)²、ビード間、周方向、圧潰)と、雄雌の山の付け根のせん断(正味断面、全山で一様と仮定)の小さい方。
    リング模型は全周が同時に谷になる断面を作るので、深さの不利を過大に見る(astra の指摘)。
  - **上限**: 螺旋の水平断面(どの高さでも同じ形が回るだけ)の壁の帯の面積 π(⟨f²⟩ − ⟨(f − t_wall)²⟩) で一様な応力とみた芯の強さ。
    真の値は下限と上限の間。3D の周期模型(1ピッチを周期境界で解く)で、どちらに寄るかを確かめる(作業中)。
  - **締め付け**: 手でナットを締め上げたとき芯がねじ切れる軸力。ねじ山の摩擦トルク T = F·r₂·(tanλ + μ/cosβ)(β は接触力で重みを付けた実効の斜面角)
    によるねじりと引張を、壁の帯の薄肉閉断面(Bredt)で層間の (σ/Z_t)² + (τ/S)² = 1 に組み合わせる。**斜面を立てるほど摩擦トルクが増えて不利**。
  - **乗り越えの目安**: 破断荷重での接触点の雄雌の半径方向の相対変位 ÷ 掛かり代(線形小変形なので警報止まり)。
- メッシュの粗さ(表面 0.045〜0.02 mm)で破断荷重は 1 N も変わらなかった(ISO M6・45° 台形)。ただし採った値が正味断面の式なら、
  これは接触の評価の収束を保証しない(astra の指摘)。1設計 6〜10 秒。

材料(PLA、軸鉛直に刷ったもの。`strength.PrintedPLA`)は文献の幅の中ほどに置いた**仮の値**で、比べるときは感度で振る:

| 量 | 置いた値 | 文献の幅(調査の報告) |
|---|---|---|
| 層間の引張 Z_t | 30 MPa(感度 15〜35) | 面内の 0.09〜0.63 倍。Hanon 2021(DOI 10.3311/PPme.13683)35.6、Prusament の層間接着 17±3 |
| 層間せん断 S | 25 MPa(感度 10〜25) | Gonabadi 2020(DOI 10.1007/s00170-020-06138-4)の upright で約 18 |

## 5. 結果

**すべて模擬の中の数値で、実物とはまだ突き合わせていない**(試し刷りが最初の突き合わせになる)。材料・垂れは仮の係数。

> レビューの指摘(法線方向の窓の中心・強度の走査の起点・片方向の接触圧)を直した(2026-10-17。decisions.md「レビューの重い指摘3件」)。
> **5.1 は直した後の値**(全 168 設計を回し直した。変わったのは D10 P4 の法線方向の3設計だけで、窓の中心の隙間 0.52→0.72mm、W −0.02、保持 −6〜−7%。
> ほかは W ±0.01・保持 ±3% の中)。**5.3 も直した後のコードで全 436 設計を回し直して確かめた**(W はすべて一致、保持 −2.1〜+0.9%、強さの計算の失敗 0 件。表はそのまま)。
> **5.2 は直す前の値**で、回し直しが届きしだい置き換える。半径方向の隙間の W は修正の影響を受けない。
>
> 強さはどの表も、**隙間を雌雄に半々に分けたとき**の値。穴の側に持たせると小径ほど強い(5.5)。

  「はまる」と「掛かりが残る」が両立しない)。D6 で 0.14、D8 で 0.33 になり、D8 以上では ISO 並目に法線方向の隙間を付けたものが条件を満たす中で最も強い(ただし隙間を固定して係数の不確かさを入れると D8 の W は 0.07 で、目安に届かない。5.6)。
  実践者の「印刷ねじの下限は M6 以上」と矛盾しない(この通説に係数を合わせたわけではない)。
- **W を最も大きく左右するのはピッチと深さ(粗く深く)と、隙間の付け方(法線方向が有利)。斜面の角はその次。** 本人の「粗くて緩いネジ」の見立てと合う。
- **半円は粗くしても小径で W が小さい**(D3 で 0.03、45° 台形は 0.27)。付け根が軸に直角な面なので、層の段と垂れが当たる。
  本人の「半円が凹凸していた形状もミスなくプリントできた要因」とは食い違うので、試し刷りで直接比べる。
- **30° と 40〜50° の差は、法線方向の隙間なら小さいが、30° は垂れの係数に強く依存する**(試し刷りの予測の幅: 30° は 0.21〜0.54、45° は 0.09〜0.18)。
  垂れが仮置きより大きければ 30° は不利になり、小さければ差は縮む。45° は垂れの係数に依らない分、予測が頑健。
- **W と強さはピッチ・深さを通して引き換え**(D6 の 45°: P2.4 で W 0.78・225N、P1.5 で W 0.41・304N)。小径の破断はほぼ「芯の層間」。
  強さの模型(リング)が 3D の螺旋模型と ±10% で合うことを確かめたのは、芯の引張の3設計(4章)に限る。
  締め付けで芯がねじ切れる軸力は保持の 75〜85% で、山形による差は小さい。
- バットレス(荷重面を棚にしてボルトを逆さに刷る)は W が最大級だが、ボルトの頭を上にして刷る必要があり、荷重は片方向だけ。

## 6. 試し刷り(本人の身体が要る、1回)

目的は係数の真値を決めることではなく、評価方法を初めて実物に突き合わせ、「この印刷条件で軽く回り、掛かりを保つ隙間」を山形ごとに取ること
(astra の指摘)。この1回で山形・ピッチ・隙間の既定まで決まるとは限らない(系列ごとのピッチは1種類だけ)。
`python -m tools.thread_sim.testprint` が `output/thread_sim/testprint/` に、ベッドに並べ終えた `plate.stl`(30部品: ボルト6・ナット20・
ねじ無しのピン2・穴の板2、奥行き 107mm)、部品ごとの STL、結果を返すページ `index.html`、`manifest.json`(試験版 TP1)を作る。
`predictions.json` は事前の予測(下の表。`testprint.predict()` が一式と一緒に書く)。

| 系列(頭とナットの形) | 山形 | ナットの隙間(雌雄の和・半径。ボルトは呼び寸法。ナット1が最も緩い) | **事前の予測**: はまる最小の隙間(誤差なし・剛体) | 予測の幅(垂れ 0〜2倍・垂れ始め φ0.3〜0.7・ビードの丸み 0〜1) |
|---|---|---|---|---|
| A(六角) | ISO M6×1 | 0.6 / 0.45 / 0.3 / 0.15 | 0.38 | 0.20〜0.50 |
| B(四角) | 45° 台形 D6 P1.5 深さ0.6 | 0.45 / 0.3 / 0.15 / 0.05 | 0.09 | 0.09〜0.18(垂れに依らない) |
| K(五角) | 30° 台形 D6 P1.5 深さ0.6(B と同じ P・深さ) | 0.6 / 0.4 / 0.2 | 0.38 | 0.20〜0.54 |
| C(八角) | 半円 D6 P2 ρ0.6(法線の隙間) | 0.4 / 0.27 / 0.15 | 0.24 | 0.14〜0.33 |
| D(四角・小) | 45° 台形 D3 P1.2 深さ0.48(study4 の D3 の上位) | 0.35 / 0.2 / 0.05 | 0.09 | 0.09〜0.18 |
| F(八角・小) | 半円 D3 P1.2 ρ0.4(法線の隙間) | 0.2 / 0.14 / 0.08 | 0.15 | 0.12〜0.20 |
| G・H | ねじ無しのピン D6・D3 と穴の板(直径 +0〜+0.6 を 0.1 刻み) | — | 山形によらない寸法誤差 | |

- 実物の境目は「予測 + 寸法誤差 e」に来るはず。ナット1つの予測は「誤差なしの余り ≥ e ならはまる」(`calibrate.py`)。
  ゲージから出す e は区間(穴は直径 0.1 刻み = 半径の和 0.05 刻み)で、ねじと同じ誤差とは限らないので補助としてだけ使う。
- 隙間の列は、予測 + e(0〜0.3)を覆い、予測より小さい側も1つ入れた。半円は法線の隙間で谷が重なるまで(2(ρ+c) ≤ P)しか広げられないので、
  F は上端が 0.2 で、e が大きいと全部回らない(それ自体が「半円は小径で寸法の狂いに弱い」という予測の確かめになる)。
- **判定の決まり**(ページの先頭に書いた): 冷めてから、工具・潤滑・削りなしで、初回のねじ込みで判定。固くなったら無理に進めず外し、往復しない。
  ナットが頭に当たるまで進めば「全長」。緩い順に試し、「入らない」「途中で止まる」が出たらその系列は打ち切ってよい(残りは不合格と推定しない)。
  **「手で軽く回る」だけを、初期設定で軽く使える合格とする**。「全長回るが固い」は別に数え、剛体の模型と実物の違い(段の鼻の潰れなど)を読む材料にする。
- **模型を反証しうる予測は山形の間の差**: 45° は ISO・30° より少ない隙間で回る(差 0.12〜0.45)。ISO・30° が予測より 0.2mm 以上小さい隙間で軽く回るなら、
  段の鼻は潰れて通る(剛体の判定が厳しすぎる)ことになり、45° の優位は縮む。半円が 45° より小さい隙間で回るなら、半円の不利の見積もりが誤り。
- ナットの両端は山の高さだけ面取りしてあるので、ねじが掛かる長さはナットの高さより短い(D3 で高さ 3mm に対し約 2mm)。今回は嵌合だけの確かめで、強さは測らない。

## 8. この版でやっていないこと

- 摩擦のある接触、大変形、塑性(段の鼻の潰れ・山の圧潰)、摩耗、反復着脱、長期の緩み。
- 寝かせて刷るボルト(層が軸に平行)。印刷の模擬が軸鉛直を前提にしている。
- スライサーの実際の経路(CLI が落ちるため)。壁の消失・合流・隙間充填は、ねじの断面が太い円板・円環なので起きにくいと見ている。
- 多数を1枚に並べて刷ると層時間が延びて単体より刷りやすくなりうる(astra の指摘)。試し刷りはその条件での結果になる。
