# 「仕事をしていない材料」を減らす方法の再検討

2026-09-28。対象: duocad、調査時 HEAD `1166ef7`。

依頼: [引き継ぎ文書](TOPOPT_HANDOFF_2026-09-28.md)の2原因について、既存案に限らずゼロベースで解決方法を検討する。
既存の実測、現行実装、保存済みの応力・変位場の追加集計、一次文献を照合した。新しい探索方式での最適化は未実施。
本書は方式の比較と推奨であり、製品への採用決定ではない。

## 1. 結論

**本命は「材料総量で薄まらない局所的な応力評価」と「削除・追加・巻き戻しのできる探索」の組み合わせ。**
保持部の一律除外と削減上限5%への変更だけでは、それぞれの問題が残る。

推奨する順序は次のとおり。

1. **応力評価を直す。** 保持部・接続部・一般部を区別して検査し、遠方の低応力材料を増やしても合否が改善しない評価にする。保持部も評価対象に残す。境界条件の特異点は、実際の取付条件や局所解析で扱う。
2. **大きな性能劣化を見て巻き戻す。** 安全率に余裕がある間も、コンプライアンスや変位の急変を監視する。まず既存の二値探索に、適応的な歩幅と過去形状への復帰を加える。
3. **材料の再配置を可能にする。** 同程度の体積で部材を追加・削除する段階を設け、その後に体積を減らす。失われた長い斜材は、直近の空セルへの追加だけでなく、過去形状や別の初期形状から復元する。
4. **終了条件を体積改善にも結び付ける。** 安全率が目標付近になっただけでは、軽量化が尽きたとは判定しない。ただし終盤の微小改善を無制限には追わない。
5. **同じ評価基準で比較する。** 最終形状の応力・変位、保持部の状態、最小幅を共通にして、軽量化と計算費用を比較する。

抜本改修をするなら、応力感度を用いた局所応力制約付き最適化が最も目的に整合する。ただし、現在の二値FEMの省メモリ性と幾何制約を失う可能性があるため、最初から全置換するより、上記の改修を比較基準として段階的に評価するのがよい。

## 2. 原因の捉え直し

### 2.1 原因1は「保持部を含めたこと」より「母数で合否が変わること」

現行は `stress.representative_stress` の材料セル全体の99.5%点である。
概略、目標応力を超えるセル数を H、材料セル数を N とすると、合格には `H ≲ 0.005 N` が必要になる。
H がほぼ一定なら、**力学的に役立たない材料でも、N を増やすだけで合否を改善できる**。
この不整合は、集中が保持部以外にあっても起きる。

母数問題は一般のFEMでも指摘されている。COMSOLの技術解説は、構造全体の体積を基準にしたパーセンタイルでは低応力材料の追加で評価を下げられること、基準体積を局所に関連付ける必要があること、さらに応力を狭い領域へ集める抜け道が残ることを説明している。[S1](https://www.comsol.com/blogs/how-should-i-evaluate-singular-stress-fields)

### 2.2 原因2は「20%が大きい」より「経路を選び直せないこと」

現在の許容形状は、採用のたびに前の形の部分集合になる。失った斜材は、以後のどの候補にも現れない。
5%にすれば誤った削除を小分けにできるが、失った経路を戻せない性質は同じである。

さらに現行の削除順位は、近傍平均した `u_eᵀ K_e u_e` による。
これは剛性への寄与を推定する情報であり、局所応力制約の改善方向そのものではない。
最小幅処理で巻き添えセルも削るため、「先頭セルの順位」と「実際に消える部材全体の重要性」も一致しない。

### 2.3 既存文書の結論で限定すべき点

| 読み取り | 今回の判断 |
|---|---|
| 保持形状は固定だから、その応力も変えられない | 一般には成立しない。周囲の接続位置・剛性・荷重分担が変わると保持部の応力も変わる。今回の「高応力セル数がほぼ一定」は、その形状・荷重での実測 |
| 保持部の集中はすべて数値上の特異点 | 未確認。実際の応力集中、拘束の理想化、階段状境界、粗い要素の誤差を分ける必要がある |
| 除外版は安全率2.73〜3.73なので実際の目標2.0を満たす | 粗い格子の99.5%点の比較としてのみ成立。最終形状の安全性を検証したことにはならない |
| 2.0 mmと2.2 mmの差は格子だけの差 | w5は実幅も約9.99 mmと11.00 mmに変わる。格子依存の定量評価では幅をmmで固定する必要がある。ただし、移植したトラスが2.0 mmの同一条件で優越した実測は有効 |
| 安全率が目標の1%以内なら最適化は収束した | これは制約境界への到達。体積の局所最小や、別の骨組みへの改善余地がないことを示さない |

探索目標係数2.4は、細い部材の曲げ・ねじりを粗い格子で過小評価する問題への対処として採用されている。
保持部を除外した結果だけで、この余裕を消費してよいとは言えない。また評価式を変更したら、2.4の妥当性も同じままとは限らない。[既存の根拠](TOPOPT_TARGET_FACTOR.md)

## 4. 解く問題を明確にする

目標は、指定された荷重・拘束・材料・製造条件の下で、必要な性能を満たす最小体積の形状である。

概念的には次を解く。

```text
最小化: 設計可能領域の材料体積
制約:   各荷重ケース・各評価部位の応力が、要求安全率に対応する限度以下
        必要なら変位・座屈・疲労など、用途で必要な性能
        保持、除外、荷重の伝達、連結、最小幅、製造条件
```

保持体積は固定なので、総体積を最小化しても設計領域体積を最小化しても順位は同じ。
一方、保持部の**応力**を制約から外してよいことにはならない。

「仕事をしていない」は色の薄い応力図だけでは判定できない。低応力材料でも、最小幅、座屈、別方向の荷重、支持点間の連結に必要な場合がある。
実用上は、最小幅を満たすまとまりを除去・置換し、FEMを解き直して、同じ必要性能を保てるかで判定する。
現行の線形静解析の範囲外の性能を、今回の2原因の証拠として持ち込むことはしない。

## 5. 原因1への選択肢

### 5.1 評価式の比較

| 方法 | 母数問題への効果 | 主な欠点・用途 | 判断 |
|---|---|---|---|
| 保持部と周囲を一律に除外 | 主な集中を外せるが、残った材料の母数依存は残る | 保持部・接続部の実際の破損を見落としうる。除外幅も格子依存 | 原因分離の実験として有用。単独の製品解にはしない |
| 保持部と一般部で別々の99.5%点 | 遠方の設計材料で保持部を薄める問題は減る | 一般部や各領域内に可変母数が残る | 部位別報告には有用。集約式も直す必要あり |
| 上位の固定セル数を捨てる | 同じ格子では希釈を解消 | 細分で捨てる実体積が変わる。高応力を少数セルに集中させられる | 固定セル数は採らない |
| 上位の固定**物理体積**に対応する順位・平均 | 材料総量による希釈を解消 | 体積の根拠が必要。順位だけでは極端なピークを無視。平均にも局所破損を隠す余地 | 暫定評価・方式比較の候補。局所ごとに定義し検証 |
| 限度を超える体積・超過量の積分 | 低応力材料の追加で改善しない | 少量の深刻な超過を許す可能性。全体で合算すると危険を別の部位に移せる | 局所制約と併用する探索指標に向く |
| p平均・平均化したKS | なめらかな指標にできる | 現在の材料数で割れば同じ希釈が起こりうる | 式を確認せず置換しない |
| 正規化しないpノルム・KS | 対象と定義によって最大応力の上界にでき、希釈しない | 要素数依存・保守性・大きな集約パラメータでの数値問題。特異点も拾う | 応力感度を使うときの候補。独立した局所検査が必要 |
| 物理モデルを整えた局所応力の最大値・局所制約 | 材料総量と無関係に危険部位を扱える | 特異点・形状近似・解析解像度を先に整える必要 | **最終的な本命** |

固定上位体積の平均は、上位を**捨てる**方法より高い値も評価に反映する。ただし、これは局所最大応力の上界ではない。
同じ8.33 MPaを新指標の閾値に機械的に移してはいけない。指標ごとに意味が違う。

また「初期全材料のNを固定して99.5%点を取る」「空セルを0として設計空間全体で割合を取る」は推奨しない。
初期空間の広さで捨てる高応力体積が決まり、巨大な設計空間ほど危険箇所を隠しやすくなる。

### 5.2 推奨する評価の構成

**一般部、保持部ごと、接続部ごとに評価を持ち、すべてを確認する。保持部を合否から丸ごと消さない。**

- 一般部: 製造される表面形状に対応した局所応力を基本とする。
- 保持部: 穴・取付面など、実際の荷重伝達に対応した評価を持つ。
- 接続部: 保持部と設計材料の取り付きで発生する応力集中を独立して見る。保持部周囲を除外して隠さない。
- 特異点が疑われる箇所: 生のピーク、距離に対する分布、格子細分への応答を別に記録する。根拠なく「数値ノイズ」と判定しない。

領域分割だけで問題は解けない。領域内の評価も可変材料体積で薄まらないようにする。
暫定的に固定体積の指標を使うなら、体積と評価位置をCAD上の寸法や取付部ごとに定義し、最適化中に都合よく広がらないようにする。
遠方の低応力材料の追加・削除で評価が改善・悪化しないかを反例で確認する。

### 5.3 評価式より上流を直す案

拘束端・鋭角・集中荷重はモデル化による特異点を生みうる。真の応力集中は十分細かい解析で有限値へ収束するが、特異点のピークは同じようには収束しない。
現行hangerの集中がどちらかは、固定形状での局所解析が必要である。[S2](https://www.comsol.com/blogs/singularities-in-finite-element-models-dealing-with-red-spots)

検討する具体策は次のとおり。

1. **取付のモデル化**: 実際のねじ・ピン・座面の支持、接触、必要な自由度に対応させる。単に結果を軽くするため拘束を弱めることはしない。部品の実際の使い方を条件として定義する。
2. **形状表現**: 実物の丸み・肉厚と、ボクセルの階段角を区別する。固定した最終形状を、形状に沿うメッシュや局所細分で解く。
3. **局所サブモデル**: 全体解析の変位・反力を保持部周辺の細かい解析へ渡す。探索候補間で荷重分担が変わるので、最初の1回の評価を永久には流用しない。
4. **応力回復・非局所評価**: 近傍からの応力回復、有限の実距離での評価、断面の膜・曲げ応力などを候補にする。ただし評価距離や許容値は材料・破損様式に結び付ける。任意の平均半径だけで破損判定を置き換えない。

最初に全てを高精度化する必要はない。少数の保存形状を独立に評価し、保持部の集中が支配する理由を調べれば、簡易評価に何を残すべきか決めやすい。

## 6. 原因2への選択肢

### 6.1 現行の二値探索を生かす案

| 方法 | 解決する範囲 | 残る問題 | 優先度 |
|---|---|---|---|
| 一律5%へ縮小 | 大きな一歩の損失を抑える。既存1条件で249.7→155.0 cm³ | 23→80分。経路の復元不可。効果は非単調になりうる | 比較基準として残す |
| 応答を見て歩幅を調整・巻き戻す | 危険な局面でだけ小さくする | 良い部材を徐々に失う場合や、すでに失った部材には不十分 | **最初に試す** |
| 過去形状から別の削り方で再開 | 消す前まで戻れる。現在のFEM・幾何検査を流用可能 | 再計算が必要。どこへ戻るかの選択が必要 | **最初に試す** |
| 一定体積で追加・削除する | 現在の体積のまま荷重経路を改善できる | 追加位置の評価、幾何制約、振動対策が必要 | **中期の本命** |
| 複数の初期形状・粗い格子からの開始 | 単一の経路依存を弱め、消えた長い部材を再提示できる | 総計算費用、格子間の写像、アンカー保存 | 可逆探索と併用 |
| 最後に低応力部分を単純除去 | 安価な仕上げ | 低応力と不要は同義でない。骨組みは改善できない | 再解析付きの補助に限定 |

歩幅を変えると最終体積は単調には変わらない。既存の上限0.25〜0.5、危険域を後回しにする順位変更も、複数例で失敗またはばらつきを示している。[過去の実験](TOPOPT_STOP_RULE.md)
従って5%や別の閾値を1条件に合わせて固定するだけでは十分でない。

### 6.2 適応的な歩幅の具体案

候補を評価したとき、安全率だけでなく次を見る。

- 実際の削除体積。最小幅処理の巻き添えと島の除去も含める。
- コンプライアンスと重要な位置の変位の変化。
- 各部位の応力制約の変化。
- 可能なら、削除予定の**全セル**の要素エネルギー和による一次予測と、実際のCの変化の差。

一定荷重での微小な剛性除去なら、`ΔC ≈ Σ(除去する要素の u_eᵀK_eu_e)` が一次近似になる。
20%の二値削除や接続の変化は微小ではないため、予測を過信せず、予測が外れたら元の合格形状へ戻して小さい候補を作る。
今回の6.14倍の変化は、その検証対象として適している。

**コンプライアンスの急変は歩幅を調整する指標とする。** 最小体積・応力制約の問題を、暗黙に「剛性を下げてはいけない問題」へ変えない。
同じ候補を小分けにすればいつか通ることもあるため、局所的な歩幅制御と、後述の再配置を組み合わせる。
閾値の候補は比較実験で定める。今回の1本だけから「Cが何%増えたら棄却」を製品定数にはしない。

### 6.3 追加と削除を許す具体案

候補生成を「現在の形から削る」だけから、次へ広げる。

1. 現在の体積付近で、材料の配置を改善する段階を設ける。
2. 追加候補を、材料表面、接続部周辺、保存した過去形状、粗い探索で得た別の骨組みから作る。
3. 最小幅を満たす塊・部材単位で追加し、別の低寄与部分を削る。追加だけの中間形が一時的に重くなることも許す。
4. FEMと幾何条件で評価する。作業中の形と、出力用の最軽量な合格形を別々に保存する。
5. 再配置で得た応力余裕を使って次の体積削減へ進む。

**1セルの周辺成長だけでは、長く失われた斜材を復元しにくい。** 途中までの枝は荷重を運ばないため低く評価される。
過去の形状にあった部材をまとめて戻す、または別の骨組みを初期候補にする仕組みが必要になる。
単に現在の形を一様に膨張して削り直すだけでは、同じV字の周辺に留まる可能性が高い。

現行実装には追加評価用の情報がない。`acceptance.safety_check` は材料セルだけで剛性を組み、空セルの要素エネルギーを0にしている。
したがって「空セルのエネルギーが高い順に戻す」はそのままでは実装できない。
近傍からの感度の補間、仮追加の有限差分評価、別の連続場、部材候補の少数評価などが必要になる。

追加側では、保持・除外・アンカーだけでなく、多様体性、芯の連結、最小幅、閉じた空洞を作らない条件も検査する。
現在の `peel` の削除時の保証は、追加にも自動的に成立するわけではない。

### 6.4 別の最適化方式への移行

| 方式 | 利点 | duocadでの難点 | 判断 |
|---|---|---|---|
| BESO型の双方向探索 | 材料の追加・削除を一つの反復で扱う。二値形状と相性がよい | 剛性最適化の順位だけでは応力制約に整合しない。空領域の情報、振動、製造制約の扱いが必要 | 二値の可逆探索を設計する参考として有力 |
| SIMP等の密度法＋局所応力制約 | 感度から配置を連続的に変えられ、失った経路も回復しうる | 中間密度、応力緩和、投影、最小幅、最終二値形の再検査。空間全体を解く費用 | 抜本改修の比較対象 |
| レベルセット＋形状/トポロジー感度 | 境界を直接扱い、滑らかな最終形状に近づけやすい | 境界移動だけでは新しい部材や穴を作れない方式もある。穴生成等が必要 | 表面生成まで一体で改修する場合に有力 |
| 梁・トラスの候補網から部材を選ぶ方法 | 長い荷重経路を部材単位で比較できる | 接続部・曲げ・3D形状を梁/トラスだけで表せない。候補網にない形は得られない | hangerの初期骨組み候補に適する |
| 多数の乱数探索・遺伝的探索 | 勾配を作らず広い形状を試せる | 1回のFEMが重い現状では費用が大きい | 全ボクセルを直接探索する主方式にはしない |

BESOには材料を追加・除去する2D/3D剛性最適化の一次研究がある。ただし、この実績はduocadの応力制約・最小幅・閉空洞禁止の組での優位性を保証しない。[S3](https://www.jstage.jst.go.jp/article/jsmec/49/4/49_4_1091/_article)

局所応力制約付きの質量最小化には、拡張ラグランジュ法で多数の局所制約を扱い、一つの随伴ベクトルで感度を計算する研究がある。
応力を改善する方向を直接使える点が、現行のエネルギー順位との本質的な違いである。
論文の応力制約における「特異最適解」と、拘束端のFEM応力特異点は別の問題であり、前者の緩和だけで後者は解消しない。[S4](https://paulino.scholar.princeton.edu/sites/g/files/toruqf6546/files/documents/SMO_20_TopologyOptimizationWithLocalStressC.pdf)

単一荷重・一つにまとめた制約指標なら、随伴法は概ね追加の線形方程式1本で感度を得る構成にできる。
ただし複数荷重・複数の独立指標では本数が増え、行列の再利用にも実装が要る。探索全体が「ちょうど2倍」になるとは見積もれない。
現在は削減後の材料だけをFEMに載せる利点があり、密度法への変更によるメモリ増も実測が必要。

### 6.5 停止条件と入口条件も変更対象

- **目標付近では仕上げ探索へ移る。** 安全率の窓に入ったら即終了ではなく、小さい削除・交換を限られた予算で試す。
- **終盤は改善量と計算費用で打ち切る。** 一定の評価予算の中で有意な体積改善がない場合に止める。予算終了と局所探索の停滞を表示上も区別する。大域最適とは呼ばない。
- **再配置後は過去の単セル棄却を見直す。** 現行の `poison` は削除だけの経路を前提とする。追加後に応力場が変われば、以前落ちた位置も有望になりうる。
- **全材料不合格だけで設計不能と断定しない。** 材料追加で全体剛性が増しても局所応力は単調に下がらない。入口の幾何・荷重成立の失敗と、全材料の応力超過を分ける。後者には、出力用の合格形を確保する前の制約改善探索を検討する。

## 7. 両原因を一緒に解くときの注意

### 7.1 片方だけでは別の悪い形に移る

| 応力評価 | 削除のみ | 追加・再配置も可能 |
|---|---|---|
| 全材料99.5%点 | 現状: 母数維持＋経路固定 | 荷重経路は改善しても、低応力材料を増やす抜け道を探索が利用しうる |
| 母数で薄まらない局所評価 | 重りは減るが、誤った骨組みは残りうる | **目指す組み合わせ**。なお非凸性による局所解は残る |

既存の「保持R2除外で−34%」「歩幅5%で−38%」は同じ条件の別実験であり、足し合わせても掛け合わせても併用効果にはならない。

### 7.2 最小幅と最小空隙も探索中の制約として考える

材料だけに最小幅を設けても、小さい穴の発生は防げない。
後処理で穴を埋めると体積・荷重経路が変わるため、探索の比較で最終製品が本当に軽くなったかが分からなくなる。
材料側・空隙側の寸法を物理単位で定義し、最終評価に含めるのが望ましい。

侵食・中間・膨張の複数形状を評価するロバストな投影法は、長さの制御と形状変動への対処に関する参考になる。[S5](https://orbit.dtu.dk/en/publications/on-projection-methods-convergence-and-robust-formulations-in-topo/)
S5には[2022年の訂正](https://link.springer.com/article/10.1007/s00158-022-03326-6)がある。訂正本文は今回取得できていないため、具体的な最小寸法の換算式や保証は採用せず、方式の参考に留めた。
3Dの応力制約では製造誤差に対して3形状だけでは不十分な例も報告されており、「3つ評価すれば保証」とは扱わない。[S6](https://arxiv.org/abs/2006.12927)

これは探索方式を置換する場合の統合案。最初の母数問題・歩幅の試作に、平滑化とメッシュ集合演算の全面改修まで同時に含める必要はない。

## 8. 推奨する検証計画と採否基準

### 第1段階: 評価式の抜け道を消す

1. 保存済みの現行形、保持R2除外形、5%形、移植トラスを共通の評価器で採点する。
2. 保持部・接続部・一般部の応力分布を、同じ物理位置・距離で比較する。
3. 固定局所体積の上位平均・超過体積を探索指標候補として比較し、少数の形状を独立の局所解析で検証する。
4. 遠方の低応力材料の増減、危険域の移動、超過応力の狭い領域への集中、格子細分を反例にする。

採否基準: 母数の操作だけで合格にできず、保持部と接続部の危険が見えること。
局所解析との対応が未確定の指標は、探索用の指標として扱い、合格保証には使わない。

### 第2段階: 探索を比較する

評価式を同じにした上で、次を比較する。

- 20%削除のみ（現行相当）
- 5%削除のみ（既存の改善案）
- 適応的歩幅＋チェックポイントへの復帰
- 上記＋一定体積での追加・削除

題材は、hangerの原因2が顕著な低荷重条件と原因1が顕著な高荷重条件、単純な引張・曲げ、L字、複数支持の荷重分担が変わる形を含める。
まず小さい問題で候補を絞り、hangerは逐次実行する。既存の全体積FEMは1.6 mmで24.2 GBのピークがあり、複数条件を同時には走らせない。

同じ評価回数だけでなく、**同じ総実行時間**で得られる最良形を比較する。粗い格子の探索、失敗候補、移植、仕上げの時間も含める。
最小幅・フィルタ幅・評価領域はmmで固定し、格子の細分と半セル程度の原点移動も比較する。原点を変える場合は同じCAD・荷重へアンカーを作り直し、合力・作用位置を検査する。
現行の3セルのエネルギーフィルタも物理幅が変わるため、比較条件として明示する。

採否基準:

- 共通の応力・幾何基準を満たす形の体積が減るか。
- 最悪条件で体積・時間がどれだけ悪化するか。
- 途中で失った部材を復元できるか。
- 格子・初期形状に対するばらつきが減るか。
- 単なる一様な肉や、応力を集約から隠すための材料が増えていないか。

「20%軽量化できるはず」等の数値目標は今回の結果からは置けない。まず効果と費用を測る。

### 第3段階: 最終製品として比較する

平滑化・保持/除外の集合演算後の形状で、同じ荷重・境界条件を用いて再解析する。
保持部の局所評価、変位、材料・空隙の最小寸法も確認する。
最終処理が通らない現状の候補には、「探索マスクでの比較」と明記する。探索の改善と、#95の完成形生成の問題を混同しない。

## 9. 実装を始める場合の接点

| 接点 | 変更の方向 |
|---|---|
| `stress.py:representative_stress` / `SafetyReport` | 単一パーセンタイルだけでなく、部位・評価法・ピーク・評価体積を返す |
| `acceptance.py:safety_check` | 評価領域と判定規則を受け取る。Cと必要な変位を保存。追加候補用の情報は別途用意 |
| `binary_search.py:SearchConditions` / `evaluation_identifier` | 評価領域、物理距離、集約式、閾値を条件識別子に含める |
| `binary_search.py:_reduce_volume` | 試行中の状態と最良合格形を分離。歩幅制御、復帰、再配置、仕上げを導入 |
| `binary_search.py:peel` / `min_width.py` | 巻き添え込みの候補評価。追加側の幾何検査。削除側の保証を保つ |
| `optimize_run.py` / 結果表示 | 探索指標と検証済み性能を区別。新評価式に対する目標係数を再検証 |

保持・除外、表面からの削除、芯の連結などの既存契約を一度に外す必要はない。
SIMP/MMA等は過去に削除する方針が採られているため、本書ではゼロベース比較の選択肢として評価した。復活を実施したわけではない。
なお `stress.py` 冒頭の「応力制約最適化は採らない」という説明は旧構成由来で、現在は呼び出し側が応力を削除候補の合否に使っている。役割の正は実装と現行計画で確認した。

## 10. 判断の要約

**まず試すべき改修は「母数で薄まらない部位別評価」と「性能急変時の巻き戻し」。その後、同体積での再配置を加える。**

保持部の一律除外は根本解ではなく、5%固定も経路依存を弱める対処に留まる。
抜本案の局所応力制約付き最適化は有望だが、解析精度と製造制約の問題を自動的に解決するものではない。
評価の意味を先に整え、同じ意味で候補形を比較することが、軽いが危険な形や、計算上だけ有利な形を選ばないための要点である。
