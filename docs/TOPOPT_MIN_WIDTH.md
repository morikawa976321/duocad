# 最小幅(部材の太さ): くびれの探索規則・芯の隣接・完成形の診断

探索が守る最小幅の規則 R(m)・S(m) の上に足した「くびれ判定」(#120)と「芯の隣接」(#122)、および完成形の最小幅・強度の原因解析と診断(#117)の結論・根拠の数値・再現手順。
R(m)・S(m) 自体の仕様は [TOPOPT.md](TOPOPT.md)「最小幅の保証」、層数・安全率のずれの実測は [TOPOPT_THICKNESS.md](TOPOPT_THICKNESS.md) が正。
旧 `TOPOPT_FINAL_WIDTH_117.md`・`TOPOPT_NECK_RULE_120.md`・`TOPOPT_CORE_ADJACENCY_122.md` を統合した。

## 1. 定義と言葉づかい

- **R(m)**: 全材料セルが m 立方(全部が材料)に属する。**S(m)**: 芯(m 立方の最小角の集合)の連結成分が、保持成分経由も含めて1つ。
- **くびれ**(探索の判定対象): 1手を抜いた後、**材料の前線をつなぎ直す最小の窓の中で、芯の前線がつなぎ直されない**こと。
  - 材料も割れて本体から離れる手(部材を切り切る手)はくびれではない(大域の連結は S(m) と既存の連結判定が見る)。
  - 判定窓の中に太い迂回路がある1セル幅の接触面(**折れ目**)はくびれではない。窓の中に前線どうしを結ぶ芯の経路があるかで決まる。
  - 立方が保持成分に重なる/接する芯は、その保持成分を介してつながるとみなす。両側が同じ保持成分に結ばれる接触面はくびれと数えない。
- **端の太さ**(自由端・張り出し): 位相を変えない薄化。ボクセルでは R(m) が担い、完成形では測らない(参考値のみ)。
- 主張できるのは「**各手について、2.2節の判定が却下すべき手は受理しない**」ことだけ。形全体の静的な最小幅の保証とは書かない。既にあるくびれの薄化の防止も保証しない。
- **却下しすぎる類型**(安全側): 鋭角の接合(約29°未満。窓半径 2m から見積もった推定で、検証済みの境界ではない)、判定窓の中の迂回路の有無の境界付近。
- 探索の規則(軸立方の離散規則)と完成形の侵食検査(ユークリッド)は**別の契約**。完成形の警告は工程の変形・尺度の違い・初期違反のどれでも起きうる。

背景の実測: R(m)・S(m) を満たしても、輪の中で2つの塊が1セル幅の面だけで接するくびれが残る(S(m) は芯が大域でつながるかしか見ず、輪の別経路でつながれば通る)。
hanger S2(m=6、要求10mm、格子約2mm)の採用形には材料の輪5本、隣り合う材料セルが共通の m 立方に入らない組が39組・5塊あった。
規則なしの `peel` を乱数順で回すと、103ステップ中77で「材料の輪の数は変わらないのに太い部分の輪の数が変わる」(=輪の中のくびれを作る)。

## 2. 探索の規則

### 2.1 芯の隣接: m ≥ 4 は26連結、m ≤ 3 は6連結(#122)

芯どうしの隣接を `min_width.CORE_26_MIN_M`(=4)以上で26にした(`core_structure`)。本人判断(2026-10-08): 「実装開始」。

- 隣接は `CoreConnectivity.structure` の1か所で決める。S(m) の大域判定・窓の判定・`NeckJudge`・静的診断はすべてこれを使う。**前線の膨張と芯のラベルは必ず同じ隣接にする**(片方だけ26にすると、斜めにだけ接していた成分が前線から漏れ、割れているのに「つながる」と答える危険側の誤りになる)。
- 変えなかったもの: 材料の連結(材料の前線、`bite_verdict`、受入検査)は6のまま。保持成分への結び(立方が保持成分と重なるか6近傍で接する)も6のまま(保持は規則の対象外で薄いこともあるので、稜線・頂点だけの接触では結ばない)。画面の文言「探索が守る立方の幅(部材の太さの保証ではない)」は R(m) の意味なので変えない。
- 使った隣接は結果の `diagnostics['min_width']['core_adjacency']`(段階4まで進んだ結果では `diagnostics['initial']['min_width']['core_adjacency']`)に残る。
- 根拠: 芯の2点が26近傍(角のずれ d ∈ {−1,0,1}³)のとき、2つの m 立方の和集合の中を通れる球の最大直径は **min(m, √(o₁²+o₂²))**(o は重なり箱の辺 m−|dᵢ| の小さい順)。面の段 (1,0,0) は m、(1,1,0)・(1,1,1) は min(m, √2(m−1))。√2(m−1) ≥ m ⇔ m ≥ 2+√2 ≈ 3.41 なので、**m ≥ 4 なら斜めの段も直径 m の球を通す**。内接球で測る保証 m×spacing は6連結のときと変わらず、失うのは「立方が滑る」ことだけ。
- m=2 では √2 < 2 で (1,1,1) 段は1セル共有の首になる([TOPOPT_THICKNESS.md](TOPOPT_THICKNESS.md) 節J3)。m=3 では 2√2 ≈ 2.83 < 3。「m=3 でも要求幅 w ≤ 2√2×spacing なら26」案は、保証する量が m×spacing から min(m, √2(m−1))×spacing に変わり画面の表示と食い違うので採らなかった。
- 保証の範囲: **保持を介さない芯の経路について**の十分条件であって同値ではない(反例: m=6 で角が (0,0,0) と (2,1,0) の2立方は、直径6の球が通るが芯は26連結でも2群になる)。完成形の保証ではない(3章)。格子の間隔が3軸で等しいことが前提(`Grid.spacing` はスカラー)。

### 2.2 局所くびれ判定(旧 NECK_RULE_120 §2、#120)

`duocad/topopt/neck.py` の `NeckJudge` を `binary_search.peel` に入れた(`skipped_neck`)。既存の `CoreConnectivity.verdict` は流用しない。

1手について:
- **削除集合 X**: 選んだセル + 巻き添え(島として消えるセルは含めない。島を消す手は既存の大域判定に任せる)。**消失芯 L**: 削る前は芯で、削った後は芯でない角。
- **材料前線 F_mat**: X に6近傍で接する、削った後の材料セル。**芯前線 F_core**: L に芯の隣接で接する、削った後の芯。
- **判定窓**: X の外接箱に余白 2m を付けた窓から始め、余白を倍にしていく(窓が格子の 1/8 を超えたら格子全体。`after_bite` と同じ手順)。F_mat が窓内で1成分になる最小の窓 W_mat を探す。格子全体でも1成分にならなければこの判定では通す。芯は角の座標で数え、材料の窓は角の窓が覆う立方の範囲(始点から、終点 + m−1 まで)にそろえる。
- **群**: W_mat 内の削った後の芯を芯の隣接でラベルし、保持成分ごとの結びを union-find で足す(保持の中の経路が窓の外を通っても結ぶ。「保持経由は太い」の決定による明示的な例外)。
- **判定**: F_core が2群以上なら却下(`skipped_neck`)。0群・1群なら通す。S(m)(`after_bite`)と材料の連結判定はそのまま必須。初期形に既にあるくびれは咎めない。
- 採らなかった案: 中軸上の太さで測る方式(`final_width.medial_points`。標本化に依存して使えない。合成の面接触くびれで 1倍 1.24・2倍 6.00(見逃し)・3倍 1.04・4倍 1.05 セル)、P(m)・χ や Betti 数による規則(輪の入れ替わりの相殺・閉じた空洞の発生・核と余核が残る反例)。

**静的診断**(探索の判定ではない。開始形と結果形で `diagnostics['reduction']['static_necks']` に記録し表示しない): 6近傍の全材料対 (p, q) について、組の外接箱 ±2m の窓で、p を覆う芯と q を覆う芯が同じ群になるかを**組ごとに**数える。片側を覆う芯が空なら「つながらない」。保持に触れる組は除く。探索の判定窓は可変、静的診断は固定 ±2m なので、太い迂回路が 2m〜4m にある組は結果で見かけ上増える。

## 3. 完成形の診断(旧 NECK_RULE_120 §3、#117)— 診断であって保証ではない

完成形の最小幅を保証する実装は入っていない。入ったのは次の診断で、`duocad/topopt/neck_persistence.py`(つなぎ目の幅)と `duocad/topopt/final_check.py`(強度)。

### 3.1 原因(#117 の解析)

原因は、**ボクセルで成立した最小幅の規則が、表面生成・平滑化・最終集合演算で保存されないこと**。平滑化だけが原因ではない。
1. **表面生成**(marching cubes、level=0.5): セル中心の0/1値を補間した等値面で、平面の中央は元の位置でも稜線・角は斜面になる。この段階だけで材料立方による幅の規則は失われる。
2. **平滑化**(Taubin、λ=0.5・μ=−0.53・30反復): 局所厚さ・最小幅の制約が無い。全体の体積が増えても端の断面は薄くなる。
3. **検査の対象が完成形ではない**: 最小幅とFEMの検査は平滑化前のマスクが対象。最終メッシュの検査(`finalize.final_mesh_checks`)は接続・向き・単一ソリッド・自己交差・保存精度で、幅や強度は判定しない。

立方体 opening で失う体積割合を、部材の厚さの減少率や強度低下率として読んではいけない(角の丸め・立方体の向き・再占有化の格子でも変わる)。
旧段階09の「39.9% の opening 損失＝部材が11mm未満に細った」という解釈は、この比較では裏付けられず訂正した。

### 3.2 診断の仕様

- 完成メッシュを探索格子の 1/2 で標本化する(標本数の上限を超えるときは粗くせず「未確定」)。距離は二値 EDT。
- 位相の変化は**持続ホモロジー**(立方複体のフィルトレーション、β0・β1 の生成と消滅。gudhi 3.13.0)で対応付けて寿命を測る。
  - **材料が増える向きで本質バーに対応する事象(材料の輪のくびれ = β1)は、寿命閾値を適用せず**、総誤差境界と区間の包含が確認できれば区間を表示する。
  - **有限バーに対応する事象(木のくびれ = β0 の合流など)は、寿命 > 2ε を必要条件とする**(木のくびれの寿命は約(小さい側の太さ − 首の幅)/2)。条件を満たさない事象も捨てず、位置と半径の範囲をつけて「未確定」として報告する。β0 の分裂で小さい側の体積が V_min(例 (2s)³)未満のものは、数だけ「未確定(微小片)」。
  - ε = √3·s(二値 EDT の偏り s√3/2 + 標本化 s√3/2。s は標本間隔)。区間は変化の直前・直後の半径 r_a, r_b から [2(r_a−ε), 2(r_b+ε)]。向きを乱数で変えた木のくびれ4例・輪のくびれ4例すべてで区間が真の直径を含んだ(`tests/test_neck_persistence.py`)。
- **表示**: 「最小幅 検証済み」「つなぎ目: 適合」は出さない(本人判断 2026-10-07)。
  - 「つなぎ目: 幅不足の疑い(直径の区間 [a, b] mm、位置)」— 上の条件を満たし、区間の上端 < d。
  - 「つなぎ目: 未確定」— 区間が d をまたぐ、条件を満たさない事象がある、標本数の上限超え、掃引できない。
  - 「つなぎ目: 幅不足の疑いは観測されなかった(標本間隔 s・ε より細かい首は見えない)」— r ≤ d/2 で β1 の死も β0 の分裂(微小片を含む)も一つも無いときだけ。
  - 「端は未検証(参考: 探針の最小 x mm。探針ゼロなら取得不能)」。輪の誕生(板の中央の薄い所)は「端の薄化の疑い(参考)」として別に出す。
- **強度**: 完成メッシュを探索格子の 1/3 へ占有化して FEM を解き直し、表面の最大応力で安全率を出す([TOPOPT_STRESS_GATE_DILUTION.md](TOPOPT_STRESS_GATE_DILUTION.md) 10章)。本来の目標安全率を割れば失敗(本人決定)。割ったときは肉盛りが入るまで警告を付けて結果を足す(`optimize_run.FINAL_UNSAFE_BLOCKS = False`、#129)。

## 4. 実測の結論と根拠

小型3題材(dilution 2.5mm、path 2.5mm・2.0mm、m=3)は輪0本。判定の有無で材料量・安全率・評価回数は**完全に同じ**で、断った手(19・80手)は S(m) が断っていた手と同数(先取りしただけ)。peel の時間は +0.2〜1.2秒、静的診断は開始・結果とも0組(`topopt_checks/compare_neck_judge_120.py`、出力 `output/neck_judge_120/`)。

`tests/test_neck.py`: 参照実装(`CoreConnectivity` を使わず窓内の全セルから直接グラフを作る)と乱数80通りで「くびれを作る」168手・「作らない」444手が全て一致。

### 4.3 完成形の幅と強度の原因解析(#117)

製品コード `0d3114642ea4ec780901da079c7d6b56f514e94b`、全数値は [measurements.json](topopt_width_117/measurements.json)。探索は再実行せず保存済み hanger と合成形状を解析した。

**単純な板の局所厚さ**(32×12×mセル、1セル=1mm、穴・保持・除外なし。メッシュとz方向直線の交点2つの距離。y=6.125mm、端 x=0.5mm / 中央 x=16mm):

| 元の厚さ | 表面生成直後(端／中央) | 30回平滑化後(端／中央) | 30回後の体積変化 |
|---|---|---|---:|
| 2mm | 2.0000 / 2.0000 | 1.6536 / 1.9750 | −1.69% |
| 4mm | 4.0000 / 4.0000 | 3.6844 / 3.9764 | +1.61% |
| 6mm | 6.0000 / 6.0000 | 5.6833 / 5.9767 | +1.30% |

## 5. 残した懸念

- m が3から4に変わる所で規則が6から26に切り替わる。要求幅をわずかに太くすると受理される形が増え、材料量が要求幅に対して単調でなくなることがありうる(保証する幅 m×spacing は単調に増える)。
- 斜めの階段の部材が増えると、ボクセル FEM の凹の角の応力が増えうる。安全率の調整と完成形の検査の扱う範囲で、幅の規則の問題ではない。hanger で完成形の安全率が探索時より 1.4% 下がった観測(4.2節)がその現れかは未測定。
- 完成形の「最小幅」の定義が未確定。軸に沿う材料立方の被覆は、丸い断面や斜材の局所厚さと同じではない(保持部の免除・角と接合部の扱いも必要)。損失体積の任意の許容率をそのまま採用しない。
- 平滑化の回数を減らすだけでは足りない(0回でも表面生成による不一致がある)。頂点移動の厚さ制約・表面生成の変更・前段での寸法余裕を比較する。余裕量は mm・格子幅・部材形状に依存し、板の薄化量を一律の補正値にしない。
- 強度の採否には格子依存性の確認が要る(hanger の完成形をさらに細かい格子で、固定面特異点の近傍と一般部を分けて)。0.47% という差だけで探索目標係数を変更しない。
- #117 は 2026-10-09 に閉じた。入ったのは探索のくびれ判定(2.2節)と完成形の診断(3章)で、完成形の最小幅を保証する実装ではない。残りは #129(肉盛り)と #130(要素サイズの上限)に分けた。
