# 最小幅: くびれの探索規則と完成形の検査(方式の合意)

2026-10-07。対象: [Issue #120](https://github.com/morikawa976321/duocad/issues/120)(探索規則)と [Issue #117](https://github.com/morikawa976321/duocad/issues/117)(完成形の検査)。
**方式の合意であって、実装も検証もまだ無い。** Claude(対話セッション)が案を書き、fable-consultant と Codex consult(gpt-6-astra)が
独立に批評して、10往復の後に3者とも同じ版(v5.4)に合意した。本人の判断が要る3点は末尾。原因解析は [TOPOPT_FINAL_WIDTH_117.md](TOPOPT_FINAL_WIDTH_117.md)。

## 背景(実測)

- 探索の規則 R(m)(全セルが m 立方に属する)と S(m)(芯の6連結成分が保持経由も含めて1つ)を満たしても、**輪の中で2つの塊が1セル幅の面だけで接する
  くびれ**が残る。S(m) は芯が大域でつながるかしか見ないので、輪の別経路でつながれば通る。
- hanger S2(m=6、要求10mm、格子約2mm)の採用形: 材料の輪5本。隣り合う材料セルが共通の m 立方に入らない組は39組・5塊。
  塊の外接箱 ±W の窓の中だけで「p 側を覆う芯と q 側を覆う芯が S(m) の結び方で同じ群か」を見ると、W = m でくびれ3、**W = 2m・3m でくびれ1・折れ目4**。
- S2 の各段階(ボクセル → marching cubes → 平滑化 → 集合演算)を侵食して位相の変化を見ると、どの段階でも輪 5→4 の変化(くびれ)が出る。
  3等分の標本では直径がボクセル 2.66 / MC 3.33 / 平滑化 3.99 / 集合演算 3.99mm で、**平滑化でくびれは太る**。
- 中軸上の太さで測る試作(`final_width.medial_points`)は**標本化に依存して使えない**: 中軸の枝で最寄り2点が150°以上開く区間は、くびれの中心から
  幅の約0.27倍しかなく、検出が標本の位置で決まる(合成の面接触くびれで、1倍 1.24・2倍 6.00(見逃し)・3倍 1.04・4倍 1.05 セル)。
- 小型3題材(dilution 2.5mm、path 2.5mm・2.0mm、m=3)はどれも輪0本で、侵食しても要求6mmまで位相は変わらない。中軸方式が拾った2〜4mm の
  細い所は位相の変化としては現れない(端の薄化かどうかは未照合)。
- 規則なしの `peel` を乱数順で回すと、103ステップ中77で「材料の輪の数は変わらないのに太い部分の輪の数が変わる」= 輪の中のくびれを頻繁に作る。

## 1. 定義と言葉づかい

- **くびれ**(探索の判定対象): 1手を抜いた後、**材料の前線をつなぎ直す最小の窓の中で、芯の前線がつなぎ直されない**こと(§2)。
  - 材料も割れて本体から離れる手(部材を切り切る手)はくびれではない(大域の連結は S(m) と既存の連結判定が見る)。
  - 判定窓の中に太い迂回路がある1セル幅の接触面(**折れ目**)はくびれではない。輪の大きさではなく、**判定窓の中に前線どうしを結ぶ芯の経路があるか**で決まる。
  - 立方が保持成分に重なる/接する芯は、その保持成分を介してつながるとみなす(S(m) の結び)。両側が同じ保持成分に結ばれる1セル幅の接触面はくびれと数えない。
- **端の太さ**(自由端・張り出し): 位相を変えない薄化。ボクセルでは R(m) が担う。完成形では測らない(§3、参考値のみ)。
- 探索の規則は「探索規則」と呼ぶ。主張できるのは「**各手について、§2 の判定が却下すべき手は受理しない**」ことだけで、形全体の静的な最小幅の保証とは書かない。
  既にあるくびれの**薄化の防止は保証しない**(実際に断る場合もある)。
- **却下しすぎる類型**(安全側。文書と停止理由に出す): 鋭角の接合(約29°未満。窓半径 2m = 4r から見積もった推定で、検証済みの境界ではない)、
  6連結の芯での (1,1,0) 段(m ≥ 4 では継ぎ目の太さは m そのもの)、判定窓の中の迂回路の有無の境界付近。

## 2. 探索: 局所くびれ判定(既存の `CoreConnectivity.verdict` は流用しない)

1手について:
- **削除集合 X**: 選んだセル + 巻き添え(島として消えるセルは含めない。島を消す手は既存の大域判定に任せ、新判定は島を除いた形で行う)。
- **消失芯 L**: 削る前は芯で、削った後は芯でない角。
- **材料前線 F_mat**: X に6近傍で接する、削った後の材料セル。**芯前線 F_core**: L に6近傍で接する、削った後の芯。
- **判定窓**: X の外接箱に余白 2m を付けた窓から始め、余白を倍にしていく(窓が格子の 1/8 を超えたら格子全体。`after_bite` と同じ手順)。
  **F_mat が材料の窓内で1成分になる最小の窓 W_mat** を探す。格子全体でも1成分にならなければこの判定では通す。
  芯は角の座標で数え、材料の窓は角の窓が覆う立方の範囲(角の窓の始点から、終点 + m−1 まで)にそろえる(芯の迂回路が材料窓の外を通らないように)。
- **群**: W_mat 内の削った後の芯を6連結でラベルし、保持成分ごとの結び(現行 `_links` と同じ候補域に入る芯成分どうしを結ぶ。保持成分は大域のラベルなので、
  保持の中の経路が窓の外を通っても結ぶ —「保持経由は太い」の決定による明示的な例外)を union-find で足す。
- **判定**: F_core が2群以上なら却下(`skipped_neck`)。0群・1群なら通す。現行 S(m)(`after_bite`)と材料の連結判定はそのまま必須。
- 初期形に既にあるくびれは咎めない。6連結と26連結で判定が食い違った回数をログに出す(芯の隣接を変えるかは別 Issue)。
- 中軸方式・P(m)・χ や Betti 数による規則は使わない(輪の入れ替わりの相殺、削除による閉じた空洞の発生、核と余核が残る、の反例があり、数で数える方式は捨てた)。

**静的診断**(探索の判定ではない。開始形と結果形の両方で取って記録し、表示しない): 6近傍の全材料対 (p, q) について、組の外接箱 ±2m の窓で、
p を覆う芯と q を覆う芯が上と同じ群の作り方で同じ群になるかを見て、**組ごとに**つながる/つながらないを数える(塊を `any` でまとめない)。
片側を覆う芯が空なら「つながらない」。保持に触れる組は除く。結果で増えた組は個別に見る(探索の判定窓は可変、静的診断は固定 ±2m なので、
太い迂回路が 2m〜4m にある組は見かけ上増える)。

## 3. 完成形(#117)— 診断であって保証ではない

- 完成メッシュを探索格子の 1/2 で標本化する(標本数の上限を超えるときは粗くせず「未確定」)。距離は当面は二値 EDT、区間の幅を見て三角形への正確な距離へ移るか決める。
- 位相の変化は**持続ホモロジー**(立方複体のフィルトレーション、β0・β1 の生成と消滅の組。既製のライブラリを使う予定)で対応付けて寿命を測る。
  - **材料が増える向きで本質バーに対応する事象(材料の輪のくびれ = β1)は、寿命閾値を適用せず**、総誤差境界と区間の包含が確認できれば区間を表示する。
  - **有限バーに対応する事象(木のくびれ = β0 の合流など)は、寿命 > 2ε を必要条件とする。** β0 の分裂は、侵食の向きでは始点の成分の分裂に見えるが、
    材料が増える向きでは有限バーの死なので、それだけでは例外にしない。木のくびれの寿命は約(小さい側の太さ − 首の幅)/2 で、太い部材をつなぐ細い首ほど長い。
  - 条件を満たさない事象も捨てず、位置と半径の範囲をつけて「**未確定**(雑音と区別できない変化)」として報告する。β0 の分裂で小さい側の体積が
    V_min(例 (2s)³)未満のものは、数だけ「未確定(微小片)」として記録する。
  - ε は使用するフィルトレーションについて確認した総誤差境界。二値 EDT では ε を標本化の δ = s√3/2 と自動的に同一視せず、
    対応の誤差境界と表示区間の包含が確認できない場合は「未確定」。
  - 区間は変化の直前・直後の半径 r_a, r_b から [2(r_a − ε), 2(r_b + ε)]。幅は正確な距離で約 4.5s、二値 EDT で約 6.2s(s は標本間隔)。
    足りなければ s 自体を小さくするか、未確定のままにする(刻みだけ細かくしても空間標本化の幅は残る)。
- **表示**: 「最小幅 検証済み」「つなぎ目: 適合」は出さない。
  - 「つなぎ目: 幅不足の疑い(直径の区間 [a, b] mm、位置)」— 上の条件を満たし、区間の上端 < d。
  - 「つなぎ目: 未確定」— 区間が d をまたぐ、条件を満たさない事象がある、標本数の上限超え、掃引できない。
  - 「つなぎ目: 幅不足の疑いは観測されなかった(標本間隔 s・ε より細かい首は見えない)」— r ≤ d/2 で β1 の死も β0 の分裂(微小片を含む)も一つも無いときだけ。
  - 「端は未検証(参考: 探針の最小 x mm。探針ゼロなら取得不能)」。探針はボクセル形の EDT ≥ r_req + 0.5 標本の点(端面から r_req 以内の先端部と保持の隣接は入らない)。
  - 輪の誕生(侵食で生まれる輪 = 板の中央の薄い所)は「端の薄化の疑い(参考)」として別に出す。
- 探索の規則と完成形の侵食検査は**別の契約**(軸立方の離散規則とユークリッド侵食は同じ尺度ではない。完成形の警告は工程の変形・尺度の違い・初期違反のどれでも起きうる)。
- **強度**: 完成メッシュを探索格子で再解析し、本来の目標安全率を割れば失敗(本人決定済み)。

## 4. 実装前の基準検査

1. 座標で固定した例: 直角稜、T・L、1軸階段、(1,1,0) 段、輪の中の面接触くびれ、木のくびれ、斜め重なりくびれ、折れ目、遠い迂回路を切る例
   (輪 + 折れ目 + 距離 3m の迂回路)、鋭角の V 継ぎ目(25・30・35・45・60°)、保持成分2つに別々に結ばれる芯対、保持の経路が窓外を通る例、前線ゼロ、島を消す手、
   Codex が出した `verdict` の None 例(m=2、keep=[2,2:22,2:4]、before=[3:7,2:4,2:4]∪[3:5,4,2]、削除=[3,2:4,2:4]。新判定では「通す」)。
2. §2 の判定を、`CoreConnectivity` を使わずに窓内の全セルから直接グラフを作った参照実装と、乱数の peel 列・固定例で照合する。
3. 完成形: 軸平行の板、斜めの板(|x+y+z| < 1.9、真の厚さ 2.194)、丸棒、解析可能な首(浅く重なる2球など)で、原点ずらし・回転・間隔を変え、
   バーの種類と端点を追って、寿命閾値と「未確定」への振り分けが §3 どおりか確かめる。hanger S2・k=2 で、r_b = 1.5s の変化が「幅不足の疑い」に出ること。
4. 費用: m = 2・3・6 で1手の中央値・95%点・最大。小型3題材と hanger で材料量・時間・停止理由を規則なしと比べる(停止理由に `skipped_neck` の数を出す)。

## 本人の判断が要る点

1. **折れ目を違反と数えない**こと(判定窓は「材料の前線がつながる最小の窓、最小 2m」)。数えるなら定義ごと見直し(局所寸法の測定に戻り、標本化依存の問題も戻る)。
2. 完成形の表示から「最小幅 検証済み」「つなぎ目: 適合」を外し、§3 の表示にすること。
3. 持続ホモロジーのライブラリを依存に加えること(輪のくびれだけなら Betti 数の比較と区間で足りるかを §4-3 で先に確かめ、足りれば見送る選択肢もある)。
