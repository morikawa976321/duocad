# 保持ソリッドと探索 — 解いた形と納品する形の差(実測)

探索は保持セルを削除候補から外していない(`binary_search.ranked_cells` は全材料セルを並べ、`peel` は保持かどうかを見ない)。
保持を守るのは合格条件(3)「各保持CADとの共通体積が数値許容差を超える」だけで、最終形状では `finalize` が
保持の実形状を union し、除外の実形状を cut する。その後に FEM は解き直さない。
この文書は、その差の大きさを hanger で測った記録。**判断は書かない**(実測だけ)。

| | m1 | m2 | m3 | thick_m2 |

採用マスク単体はどれも不正則頂点 0・空洞 0・1成分。`finalize` の後段検査(`kernel_brep.inspect_solid`)は水密・単一ソリッド・自己干渉だけを見て、

保持は設計空間の 0.4% だが、目標近くまで削った形では**納品される材料の 22〜34%**(1,498 / 4,367〜6,689)を占める。
探索が最小化しているセル数と納品形状のセル数は、この3つで 13〜23% 違う。

### A3. CAD 実形状とセルの部分的な重なり(`finalize` の cut / union が動かす薄片)

除外セルはセル中心で判定して設計空間から引いてあるので、cut が削るのは「中心は外だが一部が除外CADに掛かる」材料セルだけ。

| | m1 | m2 | m3 | thick_m2 |
|---|---|---|---|---|
| 除外CADに部分的に掛かる材料セル(ソリッドごとの和) | 568 | 426 | 556 | 4,327 |
| cut が削る体積 | 1,400 mm³ | 1,162 mm³ | 1,559 mm³ | 13,919 mm³ |
| 採用マスクの体積に対して | 1.89% | 2.41% | 1.93% | 0.43% |

1セルあたりの掛かり方は中央値 0.1〜0.3 セル体積・最大 0.49(中心判定なので 0.5 未満)。いちばん大きい除外ボディ(平面で接する)は
掛かるセルが全て 0.286 セル体積で、その面に沿う材料が一様に 0.286 セル(0.68mm)薄くなる。

保持側: 保持でない材料セルのうち保持CADに部分的に掛かるもの(union が足す薄片)は m1 151 セル・576 mm³、m2 110・446、m3 122・391。

### A4. `mask` と `mask | keep` を同じ確定表で解く(FEM)

`acceptance.safety_check` と同じ式(CG、代表応力は材料セルの von Mises の 99.5% 点)。m3 の `mask` は探索の記録
(2.16011075418068)と全桁一致した。

| | m1 `mask` → `\| keep` | m2 | m3 |
|---|---|---|---|
| 安全率(製品の定義) | 2.922 → **3.149** | 2.0000 → **2.0251** | 2.160 → **2.571** |
| 最大変位 [mm] | 13.05 → 9.86 | 15.47 → 14.87 | 16.06 → 7.90 |
| コンプライアンス | −12.9% | −7.3% | −25.9% |
| 代表応力以上のセルのうち保持セル | 0/28 → 0/32 | 4/18 → 3/22 | **15/30** → 4/34 |
| **保持でないセルだけ**で取った 99.5% 点の安全率(同じセル集合の比較) | 2.847 → 2.981 | 2.012 → **1.979** | 2.507 → **2.495** |

- 製品の定義の安全率は3つとも上がる(保持を戻した形のほうが安全側)。
- ただし上がり幅には、(i) 低応力の保持セルが母集団に入って 99.5% 点が下がる分と、(ii) 薄く削られた保持セル自身の高応力が消える分
  (m3 は上位30セルの半分が保持セルだった)が入っている。**保持でない部分の応力は m2・m3 でわずかに上がる**(安全率で −1.6%・−0.5%)。

### A5. FEM なしの `peel` の空回し(保持を抜かせない版は詰むか)

全材料マスクから、全材料マスクの1回の求解(安全率 164.69。探索の初期値と一致)で取った古いエネルギーの順位で、1回 20% ずつ
何も抜けなくなるまで `peel` を回した。安全率は見ないので、できる形に物理的な意味は無い(幾何の却下だけを見る)。
「保持を抜かせない」は製品の `peel` をそのまま使い、順位から保持セルを外し、保持セルの角の節点を条件節点に足して作った
(保持セルを孤立させる手は連結性で落ちる)。

| m | 版 | 止まったセル数(うち保持以外) | 多様体で飛ばした率 | 連結性で飛ばした率 | 支えで飛ばした数 |
|---|---|---|---|---|---|
| 1 | 現行 | 636(256) | 15.4% | 0.92% | 2,270 |
| 1 | 保持を抜かせない | 1,754(**256**) | 15.0% | 0.53% | 0 |
| 2 | 現行 | 1,079(686) | 1.94% | 3.54% | 1,791 |
| 2 | 保持を抜かせない | 2,188(**690**) | 1.16% | 2.58% | 0 |
| 3 | 現行 | 1,762(1,381) | 2.09% | 17.5% | 1,907 |
| 3 | 保持を抜かせない | 2,878(**1,380**) | 1.46% | 16.1% | 0 |

率は「抜いた手 + 飛ばした手」に対する割合。6本とも最後の形は不正則頂点 0・空洞 0・1成分。
**保持を抜かせない版は途中で詰まらず、保持以外のセルは現行と同じところまで減り、却下率は現行より低い。**

### 測れていないもの

- 段階3(初期合格の探索)の候補生成・島処理と、保持を抜かせない規則の相互作用。hanger は全材料マスクが1回目の評価で合格するので段階3の操作が走らない。
- 保持を抜かせない版で実際に探索したときの採用形状・評価回数(フル実行)。
- 細かい格子(k=2 以上)での `mask | keep` の安全率。
- B-rep の最終形状を同じ格子でボクセル化し直して採用マスクと比べること。
