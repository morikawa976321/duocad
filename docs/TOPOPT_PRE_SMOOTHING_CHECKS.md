# 島除去後・平滑化前の受入検査

検査対象は `rho_clean > level` のセルを、格子の実寸の閉じた立方体として集めた材料領域。
閾値上のセルは材料に含めない。既定は製品と同じ0.5。
密度積算量と、この二値領域の体積は別々に報告する。
探索・島除去の方法は変更せず、その出力を検査する。表面抽出・平滑化・最終CAD生成は呼ばない。

## 合格条件

| 項目 | 検査 |
|---|---|
| 水密な正常な境界 | 各格子頂点まわりの境界の交線が単一閉路。角・辺だけの接触も検出する。空モデルは不合格 |
| 単一ソリッド | 材料セルの6近傍連結成分が1個 |
| 保持との重なり | 各保持CADと材料の共通体積が許容差より大きい |
| 除外内の空間 | 各除外CADの体積から共通体積を引いた量が許容差より大きい |
| 荷重・拘束が有効 | 元の各面のアンカー節点が全て材料に接する。面別の荷重を欠落・再配分しない |
| 目標安全率 | 残った二値領域だけのFEMを再構築して解き直し、残差検算を通過し、安全率が目標以上 |

有限個の閉じたセルの和には自由境界辺がない。ただし境界は非多様体になり得るため、
頂点を囲む8セルの256通りの配置から、境界の局所的な接続を検査する。
内部空洞や貫通穴は正常な境界として許可する。この合格は後段の平滑化メッシュの合格を保証しない。

CADとの体積比較はセル中心による占有近似ではない。材料セルを互いに体積を共有しない
直方体列にまとめ、元のCADとの共通体積をOCCTで計算して合計する。格子外の除外空間も数える。
許容差は `max(1e-9 mm³, 条件CADの体積 × 1e-9)`。計算エラー・警告は判定不能とする。
この条件は僅かな重なり・空間でも合格する。保持全体の包含や除外全体の空洞化は要求しない。
保持条件なしは不合格、除外条件なしは合格（空集合）。

FEMでは材料セルの密度を1とし、それ以外を剛性行列から外す。材料に接しない自由度だけを
追加固定し、浮いた材料に拘束を補うことはしない。元の荷重をNで与え、長さとヤング率を換算する。
剛体運動の拘束不足は不合格。ソルバー・残差・非有限値の問題は判定不能とし、安全率不足と区別する。
応力の代表値は現行の99.5パーセンタイルを既定とし、素の最大応力も記録する。
既定の許容応力・ヤング率は `duocad/topopt/material.py` と共用する。

## 実行

保存済み実行（採用候補を示す `selected-result` と `input.json` が必要）:

```powershell
python topopt_checks/check_pre_smoothing.py --run output/optimization_runs/RUN_ID --out output/pre_smoothing_checks/report.json
```

最後に評価した候補ではなく、`selected-result` に記録された採用候補の `rho_clean` を読む。
除去前の場は、同候補の密度へ保存済みの保持・除外マスクを製品と同じ順序で適用して復元する。
目標安全率・閾値・許容応力・ヤング率・パーセンタイルも保存値を使う。
採用記録がなければ推測せず判定不能にする。

将来のメッシュ化しない探索からはNPZを直接渡せる:

```python
np.savez_compressed("fields.npz", rho_clean=after_removal,
                    rho_before=before_removal, origin=grid.origin, spacing=grid.spacing)
```

```powershell
python topopt_checks/check_pre_smoothing.py --fields fields.npz --document models/hanger_bar_attachment.json --target 2 --out output/pre_smoothing_checks/report.json
```

`rho_before` は保持・除外の塗り直し後、島除去前の場。両配列は同じ格子上の有限な0〜1の密度。
`--level`、`--allowable-mpa`、`--youngs-modulus-mpa`、`--percentile` で明示指定もできる。
`--solver` は `cg`（既定）、`direct`、`mg`。CLIは条件文書から同じ格子上のアンカーを作る。
Pythonから密度場(NPZ相当)を渡すなら `duocad.topopt.acceptance.inspect_document` が入口
(密度→boolの閾値変換と密度積算量の付記をここに閉じる)。既にboolマスクとアンカー表がある
場合だけ `duocad.topopt.acceptance.inspect` へ直接渡せる(密度・`level`は受け取らない)。

終了コードは0=6項目合格、1=1項目以上不合格、2=判定不能（不合格が既に確定した場合は1を優先）。
各条件の名前・共通体積・失われた節点数・安全率・残差・材料ハッシュをJSONに保存する。

## 探索の診断は別判定

履歴の候補体積は探索に渡した密度積算の目標値であり、最終二値領域の体積ではない。
各候補の体積・安全率・エラー、観測された安全側／不足側の区間幅、単調性の逆転を報告する。
収束は元の探索の申告として記録し、回数上限と区別する。古い記録で理由を確定できない場合はunknown。
失敗した計算は不足側の実測値として使わない。未評価区間の単調性や大域的最小性は保証しないため、
`minimum_proven` は常にfalse。履歴なしでも6項目の形状検査は可能。

