# 平滑化(Taubin)後の自己交差が起きるボクセルの形

製品の `mesh.build_surface_from_mask`(パディング → marching cubes → Taubin 30回)が作る三角形メッシュに自己交差が出る箇所を、
検証材料の64条件(荷重4 × 要素サイズ4 × 最小幅4。解なし0件)で全数集めて、平滑化前のボクセルの局所形に結びつけた記録。
**何が起きているかと規則まで**。改良案・修正方針は書かない(末尾「相談で決めること」)。

- 入力: `output/smoothing_corpus/voxel/<条件名>.npz` の `mask`(前提タスクの契約。座標はセル中心規約、セル `i` は `[i, i+1]`)
- 分析: [topopt_checks/analyze_smoothing_intersections.py](../topopt_checks/analyze_smoothing_intersections.py)(製品の関数は書き直さず既定値のまま呼ぶ。64条件で約16秒)
- 出力(gitignore 済み): `output/smoothing_corpus/intersection_sites.json`(全条件の全交差箇所を1件1行)・`intersection_records/<条件名>.json`(1条件の原本。管の列の全件を含む)・`intersection_synthetic.json`・`intersection_locality.json`・`intersection_sensitivity.json`
- 再現: `analyze_smoothing_intersections.py`(全条件)/ `--report`(本書の集計表)/ `--synthetic` / `--locality` / `--sensitivity`
- 全64条件で、平滑化後の交差件数が `mesh_manifest.json`(`build_smoothing_corpus_meshes.py`)と一致することを確かめてある(`counts_match_mesh_manifest`)。

## 用語と測り方

- **細い空隙**: 空セルで、ある軸の両隣(±1セル)が材料のもの。その軸を「挟まれた軸」と呼ぶ。
- **管**: 挟まれた軸がちょうど2つで、残る1軸(管の軸)に沿って連なる空セルの列。断面(管の軸に垂直な4方向)が四方とも材料で閉じた 1×1 の空隙。
  列の両端の外側が材料なら「止」、空セルなら「開」。長さ L = 列のセル数。板を貫く 1×1 の穴は 開-開 で、L が板厚に当たる。止まり穴は 止-開。
  実データの管はすべて、断面の斜め4セル(対角)も材料だった(`diag_empty_max` = 0。全534列)。
- **溝**: 挟まれた軸がちょうど1つの空セル。断面4方向のうち材料の個数 k = 0(両側が開いた薄い隙間)・1・2(隣り合う2方向)で分ける。
  片側が開いた切れ込み・溝・板の縁の細い隙間はここに入る。
- **空洞**: 3軸とも挟まれた1セル。64条件で0セル。
- **壁の間隔**: 挟まれた軸 a について、そのセルの a 方向の低い面と高い面に立つ平滑化後の頂点の a 座標の差[要素]。平滑化前は 1.0。負なら壁が入れ替わった。
  二値マスクの marching cubes は境界面の中心に頂点を1つずつ置くので、頂点と境界面が1対1に対応し、この差は曖昧さなく取れる。
  管は2つの挟まれた軸の小さい方を、その列のセルすべてで取った最小を「壁の間隔の最小」とする。
- **交差の塊のまとめ方**: 交差した三角形の対を、三角形を共有するものどうしでつなぎ、さらに平滑化前の頂点の重心どうしが 3.0 要素未満のものをまとめて1箇所とする
  (**3.0 は分析者が置いた値**。実データでは、まとめる前の塊がすでに1箇所ずつだった。64条件で塊は4つ)。
- **壁の間隔の区切り**(0.1 / 0.25 / 0.5 / 0.75)は分布を見やすくするために分析者が置いた値で、実測値ではない。
- **管の周りの材料の厚さ**: 管の4方向それぞれに続く材料のセル数の最小(上限8)。
- 保持・除外への接触は、npz にその情報が無いので**追跡していない**(`keep_or_exclude_contact: "not_tracked"`)。設計空間の縁(マスク格子の外周から1セル以内)は `near_grid_edge`。4箇所とも縁ではない。

## 規則

### R1(潰れ): 四方が閉じた 1×1 の管は、長さが一定以上で壁の間隔が約 0.05 要素以下まで潰れる

- 実データ: 止-開の管は長さ2以上で 62列中60列が 0.1 未満(残り2列も 0.124 以下)。開-開の管は長さ3で 17列中7列、長さ4以上で16列すべてが 0.1 未満(最大 0.090)。開-開 長さ5以上の間隔は 0.035〜0.062 に収まる(長さに依らずほぼ一定)。
- 溝(断面が閉じていない空隙)は、実データ13,594 セルで最小 0.122(k=2 の隅の溝 10 セルが 0.1〜0.25 に入る)。k=0 の最小は 0.500・k=1 は 0.237。
- 合成(下記): 開-開の 1×1 貫通穴は板厚3で 0.065、板厚4〜12 で 0.044〜0.051。止まり穴は深さ1で 0.289、深さ2〜8 で 0.013〜0.022。2×2・1×2 の貫通穴と片側が開いた溝は管に当たらず潰れない。

### R2(交差): 交差は R1 で潰れた管のうち、開-開で長さ3〜4 の列でだけ起きた。ただし長さでは決まらない

- 実データ: 開-開の長さ3〜4 の19列のうち4列で交差(長さ3: 3/17、長さ4: 1/2)。開-開の長さ5以上(14列)・止-開(長さ2以上の62列)・開-開の長さ1〜2(109列)では0。交差箇所4のすべてが管の列に触れている。
- 合成(孤立した板・棒。管に当たる形): 板厚(= 開-開の長さ)**4 のときだけ**、平板・135通りの棒(幅3〜7セル・穴位置あり)・穴から2セル以上離れた板面を15%ずつ盛る/削る100通りのすべてで交差する。長さ3・5〜12 は棒135本でも0、面を乱した100通りでも0。
  (板厚1の棒の2/135 = 5×5 の棒で穴が縁から1セルの位置、は板が1層しかない別の形。実データに板厚1で交差はない。)
- **食い違い**: 実データの長さ3の3箇所は、合成の長さ3(0本)を再現しない。周囲の形(周りの材料の厚さ2〜7、管の端の外への溝の延び 0〜2 セル、端の周りの材料の量)を管ごとに表にしても、
  交差した3列と交差しなかった14列を分ける特徴は見つからなかった。長さ4の1箇所は合成の長さ4(常に交差)と合うが、実データのもう1本の長さ4(F0500_h2.4_w3)は交差していない
  (合成で片端に 2 セルの溝を足した長さ4は交差するので、その差は溝の延びでは説明できない)。
- **局所性**: 実データの開-開の管(長さ3以上の33列)の周りを、管の両端の外へ半径4セルで切り出して単独でメッシュ化すると、交差の有無が33/33列で一致した(半径6でも同じ。半径2または3では交差した4列のうち2列しか出ない)。
  遠くの形には左右されず、管から4セル以内の形で決まる。
- **脆さ**: 開-開の長さ3〜4の19列の窓(半径4)で、管の周囲1層を除く全セルを1個ずつ反転した。交差した4窓では、反転の 0.6〜6.4%(55/864・18/864・36/864・6/936)が交差を消した(長さ3の3窓は 2〜6%)。
  交差しなかった15窓では 13,032 回のうち 5 回(0.04%)だけが交差を作った。長さ3で交差する配置は限られた配置で、周囲の数セルの編集で消える。

## 分かっていないこと

- 長さ3の交差(実データ3箇所)を起こす周囲の形。交差したものと同じ長さ・同じ端の管が14列で交差していない。管から4セル以内の形で決まることまでは分かっている。
- 交差の有無が三角形の並びの細部に依ること(marching cubes の三角形分割は8隅の配置で決まる)と、Taubin の30回が広い範囲の頂点数(近傍の数)に左右されること。本書は原因の機構までは調べていない。
- 保持・除外のCAD領域との関係(npz に無い)。製品経路では交差はメッシュの `finalize` で 保持・除外の外にあった場合も最後の検査で落ちる(`TOPOPT_ACCEPTANCE.md`)。
- 板厚1の合成(棒2/135本)の交差の原因。

## 相談で決めること

- 平滑化の改良で、何を守る対象にするか(管の潰れ自体 / 交差だけ / 止まり穴の潰れ)。潰れは30/64条件にあり、交差は4/64条件。
- 長さ3の交差の規則が見つからないまま、「開-開・長さ3〜4 の管」を予防の対象にするのか、平滑化後の検査で見つけて扱うのか。
- `TOPOPT_ACCEPTANCE.md` の止まり穴の記述(0.24 以上)を、本書の実測(0.01〜0.12)に合わせて直すか。
- 保持・除外との接触を調べる必要があるか(調べるなら npz に保持・除外のマスクを足して条件を作り直す必要がある)。
