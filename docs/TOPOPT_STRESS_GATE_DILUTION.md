# 母数に依らない応力の合否判定 — 採用した判定・実測・却下した案(2026-10-08〜09)

全材料の99.5%点で安全率を判定すると不要な材料が残る問題(原因1。[TOPOPT_IDLE_MATERIAL.md](TOPOPT_IDLE_MATERIAL.md))への、評価式・合否判定の案出しと実験の記録。
本人の依頼(2026-10-08)。1〜9章は製品の既定を変えずに研究用の差し替えで測り、**2026-10-09 に本人指示で製品に入れた**(10-4)。
原因2(削除の局所解)と SIMP は対象外。調査は Claude(Opus 5.5)が行い、判断の難所で fable-consultant(Fable 5.1)と codex consult(gpt-6-astra)に意見を求めた(相談役の発言は「相談役」と書く)。
2026-10-09 に本人の指摘を受けて、最高応力(ピーク)の観点を 10 章に足した。

- 実験コード: `topopt_checks/stress_gate/`(製品コード `duocad/` は無変更)。結果: `output/stress_gate_20261008/`(追跡しない)。再現コマンドは11章。
- 記号: σt = 探索の目標応力 = 許容40MPa ÷ (利用者目標2.0 × 係数2.4) = 8.33MPa。h = 探索格子の要素サイズ、w = 最小幅[mm]、
  k = 同じ形を k³ に割って解き直した細分。**Q_V** = 「それを超える応力を持つ材料の体積が V になる応力」(固定物理体積の上位値。`Q_V ≤ σt` は「σt 超の体積 ≤ V」と同値)。

## 結論(先に要約)

1. **母数依存は Q_V で厳密に消える。** 応力場を固定して低応力材料を5〜30%抜く・1〜20倍足すと、現行の99.5%点は 8.27→1.28MPa まで動くが、Q_V は1桁目まで不変(段階A)。
   体積 V 以上の塊は位置に関係なく捕まり、V 未満の塊は捕まらない(設計どおり)。
2. **ただし Q_V だけに替えると、小型題材は全材料の時点で不合格になる。** 目標超過の正体は拘束面に接する1層の特異点(超過体積 300〜400mm³。
   細分で体積は収束し、最大値は発散)で、現行はこれを母数で隠していた。**拘束・荷重面の節点から d=h 以内(接する1層)を判定から外し**、
   保持ボディも外すと、**小型13条件(有効11+基準2)の全部で現行より軽くなった(−5〜−79%)**。
   細分(k=2,3)の部材域は利用者目標の応力20MPaに対して Q_{w³} で最大9.4MPa。
3. **hanger(1000N・h=2.4・w=10)では材料は減らなかった(+0.5%)。** 評価回数は 23→195、時間は 847→4,668 秒。
   しかも保持リングの付け根(設計材料)に、V=w³=1000mm³ より小さい高応力の塊(k1 で 19.3MPa=2.3σt)を通した。
   hanger で材料を決めているのは拘束面の特異点ではなく**取付リングの付け根の応力集中**で、現行はこれも母数で 11.4MPa に抑えて見せていた。
   V を (w/2)³ に絞ると小型では現行より軽いまま付け根型の集中を抑えられるが、hanger 1000N では全材料の時点で付け根が不合格になる(6章)。
4. **境界域(保持・拘束面まわり)を「半径 w の球平均 ≤ σt」で探索中に判定する案は採らない。** 球の中で低応力の塊を残せば平均が下がる(球の中の母数希釈)ため、
   hanger で +67%・評価回数24倍になった。境界域は探索で裁かず、入口と最終形で固有量を報告する。
5. **最高応力(10章)**: 体積の判定だけで軽くした形は、印刷形(平滑化後)のピークが利用者目標を割ることがある(dilution で約27MPa、ピーク基準 20MPa)。
   探索格子の**表面の面中心応力**の最大を 2.4 倍すると細格子・平滑化形の真のピークを6形すべてで上回った。探索の後に高応力部のまわりだけ材料を1〜2層足す(局所の肉盛り)と、
   dilution で +8% の材料でピークが 27→12MPa、それでも現行より −75%。hanger ではピークは利用者の形が決める下限(全材料で 15.5MPa、要素中心)に張り付いており、
   探索中にピークを判定すると +87% 重くなる一方、探索後の肉盛りなら +0.13% で下限まで戻る。
6. **製品への反映(2026-10-09 本人指示、10-4)**: 探索の判定を部材域の Q_{w³} に、完成形検査を探索格子の 1/3 での表面の最大応力に替えた。
   完成形が目標を割ったら結果を足さない(#129。肉盛りに代わる案の検討は [TOPOPT_PEAK_GATE.md](TOPOPT_PEAK_GATE.md))。
   2026-10-11 に完成形検査の物差しを 0.67 mm 以下の格子・面積 4 mm² の上位値へ替えた(同 6章)。hanger の細分検証(1.2mm 格子で保持と除外が重なって作れない)は未実施。

## 2. 採用した候補

**部材域 Q_V**: 材料 ∧ ¬保持 ∧ 拘束・荷重節点から d 超 で Q_V ≤ σt。探索が変えられる部材の超過体積を測る。d = 特異点が支配する層、V = 許容する超過体積。V より小さい集中(付け根・接合部)は見ない。
他の候補: Q_V(全材料)と Q_V(保持外)は拘束面の特異域(体積 > V)で全材料から不合格になる。基準線相対(超過体積 ≤ 全材料の超過 + V)は予算を場所を問わず使え、固定面の予算を部材へ移せる。
境界域の球平均は 4・6章のとおり採らない。

題材は小型 dilution(300N・w=4mm)と path(3000N・w=6mm)。製品 step20 の採用形(保存)と全材料を、**同じ形のまま** k=2,3 に割って解き直した(実FEM)。

## 5. 段階C: 固定面近傍は細ったか(領域別の採点)

`phase_c_regions.py` で、拘束節点からの距離帯・保持・荷重面際ごとに k=1,2,3 で採点し、拘束面ごとの反力 ÷ 殻の面積(曲げなしの粗い公称応力)を出した。

- **dilution**: 取り付きは保持リングで、公称応力は現行・新ゲートとも 0.35〜0.47MPa(不変)。新ゲートで上がったのは拘束面0–2mm帯(Q_{w³} 9.54→10.98、発散する層)と2–4mm帯(6.36→7.75、σt 未満)。
- **path**: 拘束面1の4mm殻の面積 592→448mm²、公称応力 1.67→2.29MPa(+37%)。拘束面9は不変。
- 小型の公称応力は20MPaの1/10以下で、「この2題材では取り付きの容量から遠い」まで。殻の面積は荷重を横切る実断面ではなく曲げも入らない(相談役 astra)。
  取り付きを無制限に細らせない歯止めは、最小幅の規則(m 立方の芯)と、d=h のすぐ外の帯が部材ゲートに入っていること(相談役 Fable)。

## 7. 推奨(10-4 で製品に入れた形の元)

    部材域 R = 材料 ∧ ¬保持ボディ ∧ (拘束面の節点から h 超) ∧ (荷重面の節点から h 超)
    合格 ⇔ Q_V(R) ≤ 許容 ÷ (利用者目標 × 2.4)       V = w³(製品)。(w/2)³ は第一候補だったが 10-4 で w³ を選んだ

- **母数依存**: R の外の低応力材料をいくら足し引きしても Q_V は変わらない(段階Aで厳密に確認)。
- **局所超過**: V 以上の塊は位置によらず捕まる。V 未満の塊は捕まらない。V=w³ は小型(w=4〜6mm)では十分小さいが、hanger(w=10mm)で付け根の 2.3σt の塊を通した。
  V を w に結びつけるのは「最小幅より細かい形は探索が作れない」という意味づけで、強度上の根拠ではない(相談役 astra)。
- **係数2.4**: 細い部材の曲げを要素中心で過小に見る分の補正。部材域の Q_V に対しては、小型の k3 で k1→k3 比が 0.94〜1.17 に収まった。
  付け根・接合部の集中に 2.4 で足りるかは未確認(TOPOPT_TARGET_FACTOR §5 が首で 2.42 を測っており、足りない可能性がある)。
- **拘束面近傍(格子依存)**: 接する1層(d=h)は判定から外し、別に報告する。この層の最大は細分で発散し(10.45→18.06)、値の意味は実取付(剛固定か)に依存する。
  外す根拠は「細分で発散するのはこの層だけ」という実測で、数値ノイズと断定したのではない。
- **境界域(保持ボディ・拘束/荷重面の1層)**: 探索の合否に入れない。入口(全材料)と最終形で、固有量(保持ボディごとの Q_V・目標超過体積・拘束面ごとの反力)を σt と 20MPa の2つの閾値で報告する。
- **入口**: 全材料で R の Q_V が σt を超えるなら「設計空間が探索目標を満たさない」と報告する。
- **現行より悪化する条件**: 評価回数が小型 0.55〜5.8倍・hanger 1000N で 8.5倍(時間 5.5倍)。現行が合格を出していた入力(hanger 2000N)で「開始不可」が出る。
  境界域は探索中に拒否しないので、保持まわりの値は現行より上がりうる(hanger の球平均 8.65→11.40)。

## 10. 最高応力(ピーク)の観点(2026-10-09)

本人の指摘(原文):

> 実際に3DPして実利用する上では高応力部の体積よりも重要な要素として、最高応力部の応力、というものを考える必要があろう。
> 破壊はもっとも応力の高い部分の応力がどれだけ低くできるかにかかっている。

### 10-1. ピークは何で測るか

- ボクセルの素の最大は使えない。拘束面の層と、階段状境界の入隅で細分のたびに上がる(マスクをそのまま割った「階段形」で dilution の新ゲート形の表面の最大が k=1..4 で 19.5→30.0→36.6→42.4MPa)。階段は印刷物には無い。
- **印刷形で測る**: 採用マスクを製品と同じ手順で平滑化(`mesh.build_surface_from_mask`)し、k=2..4 の細格子へ占有化して解く(`phase_d_peak.py`)。
  保持・除外の集合演算はかけず、細格子の保持セルを足した。平滑化形の表面の最大は k=3→4 でほぼ止まった(dilution 新ゲート形 26.99→26.88MPa)。「滑らかな表面の真の最大」の近似にとどまる(相談役 astra)。
- **探索格子でのピークの代理 = 露出面の面中心の von Mises**(`gate_metrics.exposed_face_vm`。FEM の追加なし)。要素中心は曲げの表面応力を大きく取りこぼす。
  直線の片持ち梁(m セル角、`check_face_stress.py`)で理論の表面応力に対する比:

  | m | 1 | 2 | 3 | 4 |
  |---|---|---|---|---|
  | 要素中心の最大(係数2.4の根拠と同じ値) | 0.027 | 0.424 | 0.628 | 0.721 |
  | 露出面の面中心の最大 | 0.562 | 0.804 | 0.909 | 0.936 |

**探索格子(k=1)の表面の最大 と 平滑化形の細格子(k=2/3/4)の表面の最大**(判定域 = 保持外・拘束/荷重節点から h 超、MPa。ピーク基準 20MPa)

| 形 | 材料 mm³ | k1 表面 | 平滑化 k2 / k3 / k4 | 比(細/k1) | 20MPa |
|---|---|---|---|---|---|
| dilution 現行 | 88,368 | 1.36 | 1.33 / 1.33 / − | 0.98 | 満たす |
| dilution 部材域 Q_{w³} | 20,368 | 19.50 | 22.94 / 26.99 / 26.88 | 1.38 | **割る** |
| dilution 部材域 Q_{(w/2)³} | 18,816 | 12.40 | 23.74 / 27.55 / 28.52 | 2.30 | **割る** |
| dilution Q_{w³} + 肉盛り2層 | 22,032 | 7.97 | 8.77 / 11.00 / 12.20 | 1.53 | 満たす |
| path 現行 | 71,928 | 3.11 | 3.48 / 3.54 / − | 1.14 | 満たす |
| path 部材域 Q_{w³} | 41,064 | 6.50 | 6.43 / 7.93 / 8.33 | 1.28 | 満たす |

- 比は 6形+肉盛り形3つの全体で 0.98〜2.30 で、係数 2.4 の内側に収まった。つまり「表面の面中心の最大 ≤ σt」は、この9形では印刷形のピークが利用者目標の応力 20MPa 以下であることを保守側に予測した。
  要素中心の最大では比が最大 3.4 になり、2.4 で覆えない。
- 体積だけで判定した軽い形(Q_{w³}・Q_{(w/2)³})は、Q 側は合格でもピークで割る。**本人の指摘どおり、体積の判定だけでは足りない。**

### 10-2. ピークを下げる手段(探索中に判定する / 探索後に肉盛りする)

**探索後の局所の肉盛り**(`phase_f_relief.py`): 判定域で要素中心の応力が最大の 0.8 倍以上のセルから 2 セル以内にある、材料に面で接する設計空間の空セルを1層足して解き直す、を繰り返す。
製品には入れていない(#129 は結果を足さない `final_unsafe` で閉じた。[TOPOPT_PEAK_GATE.md](TOPOPT_PEAK_GATE.md))。足した体積と表面の最大(k1): hanger 1000N 現行 442,686 mm³ に +0.13% で 25.05 → 21.65、
部材域 Q_{w³} 444,718 mm³ に +0.42% で 29.33 → 23.05(全材料は 21.19)。dilution は Q_{w³} 20,368 mm³ に +8.2% で 19.50 → 7.97、Q_{(w/2)³} 18,816 mm³ に +30% で 12.40 → 7.43。

- **hanger のピークには下限がある。** 材料が +67% の形も現行の形も、肉盛りすると 15.9MPa(要素中心)で止まり、全材料の 15.45 に近い。
  この下限は利用者が決めた保持リングと荷重で決まり、探索では下げられない。探索にできるのは**この下限より上のピークを作らない**ことだけ(相談役 Fable)。
- **探索中のピーク判定**(判定域の最大 ≤ max(σt, 1.05×全材料の値)): dilution(表面)で 88,368 → 21,240(−76%、印刷形の表面ピーク 14.7MPa)、評価 18 → 160 回。path(表面)は 41,064(−43%)で判定は一度も効かず。
  hanger 1000N で出た +87%(442,686 → 827,933)は実装の副作用(ピーク比を歩幅・停止に流していた)でピークの物理ではない。却下専用に直した検証と不採用の結論は [TOPOPT_PEAK_GATE.md](TOPOPT_PEAK_GATE.md) 2〜5章。

### 10-3. 推奨(ピークを入れた形)

当時の推奨は、探索を Q_{w³}(部材域)≤ σt(σt = 40/(2.0×2.4)。母数依存を断つ体積の判定。7章)で行い、探索の後に判定域の表面の面中心の最大 P を肉盛りで max(σt, (1+ε)·P_全材料) 以下まで下げ(ε は 5% で試した)、
P_全材料 > σt なら入口で報告し、完成形を探索格子の 1/3 へ占有化して表面のピークを測る(10-4 で製品の final_check)、だった。肉盛りは入れていない。

- **閾値の意味**: σt = 40/(2.0×2.4)。面中心の表面応力は印刷形のピークの 0.43〜1.02 倍だったので、2.4 倍しても利用者目標のピーク(20MPa)を超えないと見積もる。
  2.4 は部材の曲げの較正(TOPOPT_TARGET_FACTOR)の値の流用で、表面ピーク用に較正したものではない。9形の実測では足りたが、比 2.30 の形があり余裕は小さい。
- **未解決**: (a) 許容 40MPa(降伏50×0.8)と比べる量がピークでよいか。延性の PETG なら局所の降伏は断面の崩壊ではなく、FDM の層間は脆くピーク(特に層に垂直な引張)で割れる。
  どちらが支配するかは**印刷した切欠き試験片でしか決まらない**(相談役2人とも同じ。臨界距離理論の点法・線法の長さ L もこの試験で決まる)。
  (b) hanger の細格子の検証。(c) hanger 1000N の付け根の固有のピーク(全材料で表面 21.2MPa、細格子では 1.0〜2.3 倍)は基準 20MPa を割る見込みで、探索では直せない
  (付け根にフィレット、荷重・目標の見直しなど利用者側の手になる)。
