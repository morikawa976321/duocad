# 母数に依らない応力の合否判定 — 候補・実測・推奨(2026-10-08)

本人の依頼(2026-10-08): 全材料の99.5%点で安全率を判定するために不要な材料が残る問題(原因1)を改善する
評価式・合否判定を、案出しと実験で絞る。**製品の既定は変えていない**(研究用の差し替えで測った)。
原因2(削除の局所解)と SIMP は対象外。調査は Claude(Opus 5.5)が行い、判断の難所で
fable-consultant(Fable 5.1)と codex consult(gpt-6-astra)に3往復ずつ意見を求めた(相談役の発言は「相談役」と書く)。

- 実験コード: `topopt_checks/stress_gate/`(製品コード `duocad/` は無変更)。結果: `output/stress_gate_20261008/`(追跡しない。再現コマンドは末尾)。
- 記号: σt = 探索の目標応力 = 許容40MPa ÷ (利用者目標2.0 × 係数2.4) = 8.33MPa。h = 探索格子の要素サイズ、w = 最小幅[mm]、
  k = 同じ形を k³ に割って解き直した細分。**Q_V** = 「それを超える応力を持つ材料の体積が V になる応力」(固定物理体積の上位値。
  `Q_V ≤ σt` は「σt 超の体積 ≤ V」と同値で、過去の M4a・M5a と同じ族)。

## 結論(先に要約)

1. **母数依存は Q_V で厳密に消える。** 応力場を固定して低応力材料を5〜30%抜く・1〜20倍足すと、現行の99.5%点は 8.27→1.28MPa まで動くが、
   Q_V は1桁目まで不変(段階A)。高応力をどこへ動かしても、体積 V 以上の塊なら位置に関係なく捕まり、V 未満の塊は捕まらない(設計どおり)。
2. **ただし Q_V だけに替えると、小型題材は全材料の時点で不合格になる。** 目標超過の正体は拘束面に接する1層の特異点(超過体積 300〜400mm³。
   細分で体積は収束し、最大値は発散)で、現行はこれを母数で隠していた。**拘束・荷重面の節点から d=h 以内(接する1層)を探索の判定から外し**、
   保持ボディ(利用者が決めた形)も判定から外すと、**小型13条件(有効11+基準2)の全部で現行より軽くなった(−5〜−79%)**。
   細分(k=2,3)の部材域は利用者目標の応力20MPaに対して Q_{w³} で最大9.4MPa。
3. **hanger(1000N・h=2.4・w=10)では材料は減らなかった(+0.5%)。** 評価回数は 23→195、時間は 847→4,668 秒。
   しかも保持リングの付け根(設計材料)に、V=w³=1000mm³ より小さい高応力の塊(k1 で 19.3MPa=2.3σt)を通した。
   hanger で材料を決めているのは拘束面の特異点ではなく、**取付リングの付け根の応力集中**で、現行はこれも母数で 11.4MPa に抑えて見せていた。
   V を (w/2)³ に絞ると小型では現行より軽いまま(−79%/−8%)付け根型の集中を抑えられるが、hanger 1000N では全材料の時点で付け根が不合格になる(本文6章)。
4. **境界域(保持・拘束面まわり)を「半径 w の球平均 ≤ σt」で探索中に判定する案は採らない。** 球の中で低応力の塊を残せば平均が下がる
   (球の中の母数希釈)ため、hanger で +67%・評価回数24倍になった。境界域は探索で裁かず、入口と最終形で固有量を報告する。
5. **推奨の位置づけ**: 製品の既定を今すぐ替える根拠はまだ無い。入れてよいのは「部位別の固有量の報告」と「研究用 opt-in のゲート」まで。
   既定の切替には、本人判断が3点(8章)と、hanger の細分検証(今は 1.2mm 格子で保持と除外が重なって作れない)が要る。

## 2. 候補(複雑さの低い順)

| 候補 | 式 | 何を測るか | 閾値の意味 | 失敗しうる例 |
|---|---|---|---|---|
| Q_V(全材料) | 材料全体の Q_V ≤ σt | σt を超える材料の体積 | V = 判定で許容する超過体積 | 拘束面の特異域(体積 > V)で全材料から不合格 |
| Q_V(保持外) | 保持セルを除いた Q_V | 同上 | 同上 | 拘束面が設計材料に接する題材では同じく不合格 |
| 基準線相対 | 超過体積 ≤ 全材料の超過体積 + V | 探索が作った超過 | 全材料の超過を予算として認める | 予算を場所を問わず使える(固定面の予算を部材へ移せる) |
| **部材域 Q_V(採用候補)** | 材料 ∧ ¬保持 ∧ 拘束・荷重節点から d 超 で Q_V ≤ σt | 探索が変えられる部材の超過体積 | d = 特異点が支配する層、V = 許容する超過体積 | V より小さい集中(付け根・接合部)を見ない |
| 境界域の球平均 | 保持 ∨ 拘束・荷重面 d 以内 のセルを中心とした半径 w の球平均(材料のみ)の最大 ≤ σt | 境界まわりの平均応力 | 2.4 を掛ける根拠は無い(相談役2人とも) | 球の中の低応力材料で平均が下がる(4章) |

## 5. 段階C: 固定面近傍は細ったか(領域別の採点)

`phase_c_regions.py` で、拘束節点からの距離帯・保持・荷重面際ごとに k=1,2,3 で採点し、拘束面ごとの反力 ÷ 殻の面積(曲げなしの粗い公称応力)を出した。

- **path**: 拘束面1の4mm殻の面積 592→448mm²、公称応力 1.67→2.29MPa(+37%)。拘束面9は不変。
- 小型の公称応力は20MPaの1/10以下で、**「この2題材では取り付きの容量から遠い」まで**しか言えない(相談役 astra: 殻の面積は荷重を横切る実断面ではなく、

## 7. 推奨

**評価式(研究用 opt-in として)**

    部材域 R = 材料 ∧ ¬保持ボディ ∧ (拘束面の節点から h 超) ∧ (荷重面の節点から h 超)
    合格 ⇔ Q_V(R) ≤ 許容 ÷ (利用者目標 × 2.4)       V = (w/2)³ を第一候補(w³ は比較用)

- **母数依存**: R の外の低応力材料をいくら足し引きしても Q_V は変わらない(段階Aで厳密に確認)。
- **局所超過**: V 以上の塊は位置によらず捕まる。V 未満の塊は捕まらない。V=w³ は小型(w=4〜6mm)では十分小さいが、hanger(w=10mm)で付け根の
  2.3σt の塊を通した。(w/2)³ は小型で現行より軽いまま、細分後の部材域の最大を 22→14MPa(dilution)に下げた。V を w に結びつけるのは
  「最小幅より細かい形は探索が作れない」という意味づけで、強度上の根拠ではない(相談役 astra)。
- **係数2.4**: 2.4 は細い部材の曲げを要素中心で過小に見る分の補正(部材中央区間の局所比)。部材域の Q_V に対しては、小型の k3 で部材域 Q の
  k1→k3 比が 0.94〜1.17 に収まり、移植は小型2形で実測された(相談役 Fable)。付け根・接合部の集中に 2.4 で足りるかは未確認(TOPOPT_TARGET_FACTOR §5 が
  首で 2.42 を測っており、足りない可能性がある)。
- **拘束面近傍(格子依存)**: 接する1層(d=h)は判定から外し、別に報告する。この層の最大は細分で発散し(10.45→18.06)、値の意味は実取付(剛固定か)に依存する。
  外す根拠は「細分で発散するのはこの層だけ」という実測(d=2〜6mm で部材域 Q の細分変化が同じ)で、数値ノイズと断定したのではない。
- **境界域(保持ボディ・拘束/荷重面の1層)**: 探索の合否に入れない。入口(全材料)と最終形で、保持ボディごとの Q_V・目標超過体積・球平均・拘束面ごとの反力を、
  σt と 20MPa の2つの閾値で報告する。球平均ゲートは採らない(4章・6章)。
- **入口**: 全材料で R の Q_V が σt を超えるなら「設計空間が探索目標を満たさない(場所: 付け根/拘束面/…)」と報告する。

**現行より悪化する条件・費用**

- 評価回数: 小型 0.55〜5.8倍(dilution w=8 で 18→105)、hanger 1000N で 8.5倍(時間 5.5倍)。Q_V の計算自体は並べ替え1回で FEM に比べ無視できる。
- 現行が合格を出していた入力で「開始不可」が出る(hanger 2000N、V=(w/2)³ なら 1000N も)。
- V=w³ を大きい w で使うと、付け根型の集中を現行より悪化させる(hanger 1000N)。
- 境界域は探索中に拒否しないので、保持まわりの値は現行より上がりうる(hanger の球平均 8.65→11.40)。報告で見せる。

## 8. 本人判断が要ること

1. **保持ボディ(利用者が決めた形)とその付け根を、探索目標 4.8(係数2.4込み)で裁くか。** 裁くと hanger は 1000N 前後から「開始不可」または現行より重い。
   裁かず報告だけにすると、付け根の集中は V の取り方しだいで現行より悪くなりうる。
2. **現行が合格を出していた荷重(hanger 2000N)で「設計空間が目標を満たさない」と断ることを受け入れるか。**
3. **V を何に結びつけるか**(w³ / (w/2)³ / 要素数)。小型だけの証拠で既定を替えるか、hanger の付け根の細分検証を待つか。
