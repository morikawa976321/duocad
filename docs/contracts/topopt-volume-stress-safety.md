## von Mises 応力と代表応力(duocad/topopt/stress.py)

実測の表(斜め板の細分3段)・留保・許容応力の導出は [../TOPOPT.md](../TOPOPT.md)「代表応力の規則」。ここは外せない契約。

- **代表応力は素の max でない。** 既定は ρ >= 0.5 の要素の von Mises の 99.5 パーセンタイル(`DEFAULT_RHO_MIN` / `DEFAULT_PERCENTILE`)。素の max は解像度を上げるほど安全率が下がり続ける(斜めに切った板を3段細分: 素の max は公称の 12.9 → 39.7 倍、ρ>=0.5 の max も 1.54 → 2.09 倍、99.5% 点だけが 1.32 / 1.29 / 1.30 で動かない)。「せっかくだから max で」と戻さない。現行の製品の探索は部材域の固定物理体積の上位値(`member_volume_stress`)を使い、99.5% 規則は `member_volume_mm3` を渡さない研究・検査の経路に残る。
- **ρ の閾値が効くのは「採用する代表値」のほうで、max を下げるためではない。** 斜め板では空要素が材料に隣接して素の max が 9.8〜30.5 倍に跳ねるが、ρ=1 の荷重直下(点荷重の特異点)に素の max がある出力では ρ の閾値で動かなかった(閾値を外すと代表値が 1.346 倍に上がる)。
- 99.5% と ρ>=0.5 は実測で選んだ値で理論値ではない。母集団の要素数が少ないと 99.5% 点は max に近づく(596 要素なら上位3要素)。解像度を跨いで安全率を比べるなら `RepresentativeStress.element_count` も見る。
- **応力は E に依存しない。** `sigma_real = sigma_nd * (F/F_nd) / L²`。E が効くのは変位だけ(`u_real = u_nd * (F/F_nd) * (E_nd/E) / L`)なので、安全率は E を変えても動かない(`material.DEFAULT_YOUNGS_MODULUS_MPA=2000` は変位表示専用の名目値)。無次元側の `E=1.0` / `nu=0.3` / 荷重 1.0 を実材料の値へ変えない(換算は後処理側の責任)。
- 換算則 `UnitScale` は解いた `Model` から無次元側の荷重を読んで作る。手で `solved_load` を書くと、荷重ベクトルに `force` を渡した系で応力が黙って定数倍ずれる。荷重 0 の系は例外。検査用の口 `UnitScale.for_model` の分母は合力でなく `load_magnitude_total`(節点力の大きさの総和。打ち消し合う荷重系でも 0 にならず、荷重が1つなら合力と厳密に一致)。製品は荷重を実単位[N]のまま解くので `UnitScale(..., solved_load=1.0)` を直接作る。
- **母集団が空(どの要素も ρ < 閾値)なら例外。** 0 を返すと安全率が無限大になり「材料が1つも無い形」が最も安全になる。母集団に非有限値が混ざった場合も落とす(nan は比較が常に偽で不合格判定にも引っかからない)。
- **要素応力は材料そのものの応力**(D は `model.E` そのまま。`rho^penal` を掛けない)。中間密度の要素はひずみが大きく出るぶん安全率を小さい側へ倒す(安全側)。
- **安全率の絶対値を信用しない。** ボクセルFEAで階段の問題は消えない。使ってよいのは同じ解像度での相対比較と「明らかに足りない/足りている」の判定だけ。縮めた解像度での実測が本番の数値になるとも限らない。
- `stress.py` は最適化の中を見ない純粋な後処理(感度も履歴も使わない)。変位 `u` は評価する形で解いたものを渡す(`evaluate` は `u` が必須引数。別の形の `u` を使い回すと古くなる)。
- 検査の罠: ① 全自由度を固定した面の近傍では梁理論が成り立たない(根元の要素は M·c/I を 8.5% 上回る)。解析解と比べる断面は**梁せい1つぶん先**に取る。② 単軸の解析解だけでは von Mises の定義を守れない(せん断項の係数 3 → 1 の変異は単軸状態では現れない)ので、純せん断と静水圧の2件を定義の検査として別に置く。③ `rho_min` を 1.0 近くにしても母集団は空にならない(ρ がきっかり 1.0 の要素が残る)。空の場合を検査するなら ρ を全部 0 にした合成場を渡す。④ 要素中心の B 行列は、局所節点順が `_build_edof` の回し方と一致していないと落ちずに「もっともらしい別の値」を返す。格子全体に6成分すべて非零の一様ひずみ場を入れて全要素が同じ σ になるかを見る検査を置く(変異で12件落ちる)。⑤ 空要素のある斜め板は CG を使わず `solver="direct"`。⑥ 例外を見る検査は `except Exception` まで受ける(狙った例外だけ捕まえると、変異体がトレースバックで死ぬだけでどの検査が守っているか出力に残らない)。
- 許容応力の定義は `material.py`(`PETG_YIELD_MPA=50.0` × `PRINT_DERATE=0.8` = `DEFAULT_ALLOWABLE_MPA=40.0`)に1か所。数字だけをハードコードしない。

## 受入検査の題材の縮小

現行の題材の大きさは [../TOPOPT.md](../TOPOPT.md)「受入検査の題材の大きさ」。縮小で分かった、解像度を触る後続が踏む罠だけ残す。

- **`voxelize.occupancy` のレイ縮退は解像度に対して単調でない。** 旧ケースの長辺要素数は 12 と 16 で落ち、13/14/15/17/18/20/22 は通る。要素サイズは 9.0mm 以上で落ち、6.0〜8.5mm は通った(現行の `occupancy` は縮退が出ると次のずらし幅でやり直す)。**1点で試して通ったら採る、をやらない**(複数点を測る)。
- 縮めると検出力が消える検査がある。縮小の可否は「その検査が何を検出するか」で決め、所要時間だけで決めない。
- 回帰基準の固定値(SHA-256・16 進 float)は題材を変えたら変えた側だけ、2回走らせて一致を確認してから取り直す。
- 秒数に依存しない: 同じコード・同じ機械で 1.7 倍振れる(熱状態)。**新旧の比較は同じセッションで測る。**
- 条件面を要素サイズに近づけると、拘束面と荷重面が同じ節点を掴んだり面が空になったりして、モデルが「荷重が自由な自由度に1つも載っていない」で落ちる(旧ブラケット題材で長辺を 14 まで落とすと再現し、18 にした)。
- 検査内のメモ(`check_anchor._table`)のキーは `id(shape)` なので、形をその場で構築して渡すとキャッシュが効かない(モジュール定数を使う)。
- Windows で変異検査のドライバの `subprocess.run(..., text=True)` は cp932 デコードになり日本語出力で `UnicodeDecodeError` を出してスレッドごと死ぬので `encoding="utf-8", errors="replace"` を明示する。ログをファイルへ落とすときも `PYTHONIOENCODING=utf-8` が要る。Bash ヒアドキュメントで書いた Python の `"\\n"` は実際の改行になるので、パッチ用の文字列に改行のエスケープを書かず、行単位の操作か Write ツールを使う。
