# 3D SIMPはウォームスタートしたCGで解く

duocadの `probe_topopt` で実測(numpy 2.4.6 / scipy 1.17.1、片持ち梁・体積分率0.3・penal 3・
密度フィルタ半径1.5)。**格子 40x16x16 = 10,240要素 / 35,547 DOF での1反復の所要**:

| 解法 | 所要 |
|---|---|
| `spsolve` | 7.1秒 |
| `splu`(`permc_spec='MMD_AT_PLUS_A'`。既定のCOLAMDより速い) | 6.3秒 |
| **CG + 対角(Jacobi)前処理 + 前回のUをx0に渡す** | **1.4〜2.1秒**(CG内部200〜300反復) |

直接解法だと60反復で7分を超えるが、CGなら約2分で終わる。**ウォームスタートが効くのは
密度がゆっくりしか変わらないから**で、x0を渡さないと反復数が増える。
30x12x12 まで落とせば直接解法でも1.1秒/反復だが、CGを使えば格子を落とさずに済む。

**`rtol` は 1e-9 にする。1e-6 では足りない。** 荷重・拘束をz対称に置いたとき密度場も
z対称になるはず、という検査(相対誤差1e-6以内)を回すと:

| rtol | 20反復での非対称さ | 60反復での非対称さ | 所要 |
|---|---|---|---|
| 1e-6 | 1.9e-08 | **1.7e-07**(許容1e-6に対し余裕6倍) | 基準 |
| 1e-9 | 2.2e-10 | 1.0e-09 | **+13%だけ** |

CGの停止判定は内積の丸めが解法ごとに違う経路を通るので、**対称な問題を解いても解は
厳密には対称にならず、反復を重ねるほどずれが育つ**。1e-6のままだと合否が丸め誤差の
積み上がりで揺れる。13%の追加コストで100倍の余裕が買えるので、迷わず締める。

コンプライアンスの値は rtol 1e-6 と 1e-9 で一致する(15.7709)。**締めて損をするのは
速度だけで、精度の判定は変わらない。**
