# 基準平面のクリックが黙って面に化ける(duocadの実機検査)

2026-08-23に実測。`web/scripts/*.mjs` の `createSketchOnBase('XY')` は
`window.__duocad.projectBasePlane('XY')` が返した画素をクリックしてスケッチを貼る。
この関数は「その画素で本当に基準平面が取れ、手前に面が無い」ことを確かめてから返すが、
**ソリッドがあるときに返るのは部品の輪郭のすぐ外側**になることがあり、クリックが1画素ずれるだけで
基準平面ではなく**部品の側面**に当たる。

結果、スケッチは XY 平面ではなく板の側面(法線 +Y)に貼られたが、
**後続のアサーションはどれもそれで通ってしまい、検査は緑のままだった**。
気づいたのは領域の重なりを見ようとして、当たり判定の実測値を出したときである。

対処は2つで、両方入れる価値がある:

1. **基準平面へ貼る手順は、ソリッドが1つも無いうちにまとめて済ませる**(輪郭が無ければ化けない)
2. **貼れた平面を毎回検算する** — `window.__duocad.sketches[i].frame` の `origin` と `normal` を見て、
   要求した基準平面でなければその場で赤にする。検算が無いと「別の状況を検査して緑」になる

一般化: **射影ヘルパが「当たることを確かめてから返す」型でも、返す点が境界すれすれなら
クリックは別のものを取る。** 検査は「狙った対象が取れたか」を対象側の属性で検算すること。
