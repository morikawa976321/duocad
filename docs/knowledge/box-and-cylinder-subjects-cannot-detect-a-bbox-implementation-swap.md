duocad で `BRepBndLib::Add` を `AddOptimal` へ差し替えたとき（2026-09-07）:

- pytest **1,029件が全部緑のまま**
- topopt 受入検査7本のうち落ちたのは1件だけで、それは「罠が現に存在する」と主張している
  検査自身。**差し替えを検知したのではなく、自分の前提が消えたことを報告しただけ**
- 7本の `MEASURED` の全項目を突き合わせて、**動いたのはタイマーだけ**

にもかかわらず、実物38ボディのうち **11個（29%）で bbox が1%超ずれ、最大9倍狂っていた**。
検査の題材が箱・円柱・平面ばかりで、そこでは両者が一致するからである。

**「差し替えても全部緑だった」は安全の根拠にならない。守られていないだけの可能性がある。**
実装の選択肢を差し替えて何も動かないときは、まず**題材がその差を出せる形か**を疑う。
確かめ方は変異検査（実装を1つ壊して、狙った検査が実際に落ちるか）で、**検査を書いた時点で
1回やる**（duocad `docs/TOPOPT.md`「変異検査の記録」がその台帳）。

対処は題材を1つ足すだけで済んだ: トリムされたトーラス片
（`BRepPrimAPI_MakeTorus(100, 10, pi/6)`）を入れると、同じ差し替えで狙った2件だけが落ちる。
