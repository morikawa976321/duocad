# 片持ち梁プリセットは見た目用のデモではない

duocad `probe_topopt` の片持ち梁プリセット(`simp.PRESET` / `run_preset()`)について本人が決めた:
**残す。ただし画面(ボタンの押し先)からは外し、合成ブラケットの4条件へ差し替える。**

「見た目用にだけ使われているなら消してよい」という見立ては誤りで、依存はこうなっている:

| 依存元 | 何に使っているか |
|---|---|
| `check_simp.py:177,184` | SIMPの受入検査の本体 |
| `check_mesh.py:68,75` | 9検査すべてが、このプリセットが出す密度場の上で走る |
| `mesh.py:367` | CLI |
| `server.py:52,205` | ボタン(ここだけ差し替える) |

**一番気づきにくいのは `simp.Model` の既定の境界条件そのものが片持ち梁だという点。**
`fixed_dofs=None` で x=0 面を全固定、`load=None` で先端1節点に −y。これに依存しているのは:

- `check_anchor.py:173-182` —「拘束を**明示的に**渡した結果と、渡さない**既定**の結果が一致する」
  検査の基準。面アンカー経路が旧経路と同じに配線されていることの保証で、既定が消えると
  比較対象そのものが無くなる。
- `check_simp.py:132` の `Model(8,4,4)`、`check_simp.py:249` の
  `optimize(20,10,10, solver="direct")`(拘束・荷重を渡していない)。

消すと4つの受入検査のうち3つとCLIが落ちる。加えて片持ち梁は**解析的に検算できる唯一の系**で、
z対称性の相対誤差 1.02e-09、コンプライアンス 292.23→15.38 の再現性が回帰の基準線になっている。

一般化: **画面に出ているものが、その部品の存在理由とは限らない。** 表示から外すことと、
定義を消すことは別の操作として扱う。
