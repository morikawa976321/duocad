duocad probe_topopt の応力検査(`check_stress.py` [2])で踏んだ。片持ち梁の根元(x=0 の
全自由度固定面)のすぐ隣の要素で σ_xx を測ると、**M·c/I を 8.5% 上回る**(64×16×8)。
拘束面では断面が自由に反れず、梁理論の前提が成り立たない(サンブナンの局所効果)。

**測る断面を梁せい1つぶん先へ寄せると比は 0.998 に落ち着き、そこから先はどこで測っても
同じ値になる**(offset を1〜2倍に振っても変わらない)。これは理論と合わせるための細工では
なく、比較してよい場所を選んでいるだけである。

そこで測れば trilinear hex の要素中心応力は素直に収束する(誤差 0.87% → 0.22% → 0.10%、
32×8×4 / 64×16×8 / 96×24×12。細分で約1/4ずつ = 2次収束)。**「FEAが解析解と数%ずれる」を
要素の精度のせいにする前に、拘束面からの距離を疑うこと。**
