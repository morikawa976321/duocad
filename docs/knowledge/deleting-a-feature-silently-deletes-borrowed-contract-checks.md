# 機能を消すと、それを題材に借りていた契約の検査も消える(2026-09-10)

duocadの形状最適化から案5(`derive_from_coarse_run`)を削除するとき、本人がタスク本文で**「14-6/14-7 は案5を題材にしているだけで、見ている契約は案5のものではない」**と名指しし、連続値保持側(`build_reference`)の同じ契約へ**付け替えること**を完了条件にした。

見ていた契約は「`run_topopt` は空の条件面のとき例外にせず `"result": None` で返す。受ける側は `.rho` へ触る前に自分で見て構造化された例外へ変換する」で、**案5とは何の関係も無い。** 案5と一緒に消していたら、残りの検査は全部緑のまま、素の `AttributeError` へ戻る穴が復活していた。

- **機能を消す前に「この機能を題材にしている検査は、この機能の契約を見ているのか」を1件ずつ問う。** 題材(setup)と主張(assert)が別物のことがある。
- 見分け方はassertの中身: 例外の型・戻り値の形・変異検査の対象が**削除する関数の外**を指していたら、それは借りているだけなので付け替え先を探す。
- 付け替えるときは**構造ごと**移す(正常系・例外の型・構造化診断・変異検査)。変異検査を落とすと「上げっぱなし」の実装でも緑になる。
