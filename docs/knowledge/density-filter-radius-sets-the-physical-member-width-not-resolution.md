duocadのトポロジー最適化(SIMP)で2026-09-05に実測した。4題材 × 解像度3段(長辺40/56/72要素)を、密度フィルタ半径 `rmin_mm` を固定して回した結果:

- **チェッカーボード(隣接要素の離散ラプラシアン)は要素単位の半径で決まる。** 物理半径を据え置いて解像度を上げると実効半径が 1.5 → 2.10 → 2.70要素へ上がり、指標は単調に下がる。
- **しかし部材の物理的な細さは動かない。** 壁厚の5%点[mm]は、除外が中央を貫く題材で 0.693 → 1.013 → 0.678mm とほぼ横ばい。**物理半径を 3.99mm → 6.66mm にすると 2.383mm** になる。
- したがって「1要素幅の筋を消す」目的には**解像度ではなく物理半径**を上げるのが直接的。解像度を上げる価値は別にあり、同じ物理半径でより良い形が出る(コンプライアンス 0.56〜0.95倍)。
- 費用は長辺 40→56 で 2.5〜2.9倍、40→72 で 6.3〜9.8倍。

**「解像度を上げれば細い部材が表現できる」は半分しか正しくない** —— 表現はできるが、フィルタが許す最小部材幅は物理半径で決まるので、細くなるのは離散化の粒度だけである。
