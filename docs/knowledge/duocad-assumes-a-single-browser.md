2026-08-27、duocadは **同時編集(複数のブラウザ・複数の人が同じ文書を同時に編集すること)を
前提にしない**と本人が決定した。理由の明言は無い。コード調査 `docs/CODE_SURVEY_ACTIONS.md`
の項目1.4に対する二択(「排他制御を入れる」か「単一ブラウザ前提を明記してクローズ」か)で、
後者を選んだもの。

技術的な内容:

- WebSocketは複数接続へ状態を配信する作りだが、`Session` 全体を守る排他は無い。
- **形状が壊れることはない** —— 個々のverbの適用は同期処理でawaitを挟まない。乱れうるのは
  順序で、ある接続が `_push` のawaitで待っている間に別の接続の操作が先に処理される
  (単一イベントループ内のコマンド単位のインターリーブ)。結果として操作ログや選択状態が
  意図と違う順序で反映されうる。
- 前提を変えるなら `duocad/server.py` の `Server` へ排他を入れるのが先。

明記した場所(2箇所): `duocad/server.py` の `Server` クラスdocstring と
`README.md` §5「前提にしないこと」。commit 9fac6b7。
