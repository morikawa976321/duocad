# duocadの基準平面は深度で面に負ける(原点がモデルの中だと指せない)

2026-08-22、スケッチ開始を「起動 → 貼る先をクリック」の2手に統一した実装での実測。

- 基準3平面のピックは**解析交差**(`ray.intersectPlane` を3枚ぶん)で、描いているグリッドの
  線は当たり判定に使わない。範囲は原点まわり ±100mm(グリッドの描画範囲と同じ)。
- **面と平面はレイ距離が近い方が勝つ**(通常のオクルージョン。辺→面のような優先順位は
  付けない)。
- 結果として、**原点が大きなモデルの内側にあるとグリッドは1画素も指せない** ——
  実測: mATX PCケース(27部品)を読み込んだ状態では、±100mmの範囲が丸ごとケースの内側に
  入るため、どの画素からも面が先に当たる。パーツを隠すと指せるようになる。

実機検査(smoke)もこの通りに書いてあり、PCケースを扱う2本は「全非表示にしてから
グリッドを指す」手順になっている。**当たり判定の感触・視覚の作り込みは未着手**で、
本人が対話で詰める予定。
