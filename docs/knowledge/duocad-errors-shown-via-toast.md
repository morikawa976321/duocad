# duocadのエラーはすべてトーストで見せる

2026-08-22本人決定。トーストコンポーネントを用意し、**今後エラーはすべてこれを使って
人間に見せる**。契機は「非平面の面にスケッチを貼ろうとした」エラーの見せ方 —— クリック即適用の
UIでは、操作が拒まれたことがステータスバーの1行では気づけない。

クライアント側での先回り判定(平面かどうか等)はしない方針は維持 —— 判定はコアの1箇所、
UIは結果を見せるだけ。

**表示位置は右下**(2026-09-03本人指示で右上から変更。「AIパネル(右サイドバー)とかぶらない位置」という条件つき)。`Toast.svelte` の `.toasts` を `bottom: 12px`・`flex-direction: column-reverse`(配列先頭=最新の札がコーナー側に来る)にし、右オフセット `calc(var(--sidebar-w) + 16px)`(AIパネルを避ける機構そのもの)は維持。
