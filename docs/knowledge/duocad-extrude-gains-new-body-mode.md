本人の指示で、duocadの `extrude`(領域の押し出し)の `mode` に **`new`(新規ボディ)** を追加した。
種別は `join` / `cut` / `new` の3つになった。

それまで新しいボディが生まれる道は **`join` の「行き先が無ければ作る」という落ち方だけ**で、
既存のボディがいる文書では2つ目の板が作れなかった(`join` が黙って融合する)。ブラウザは
`body_id` を送れない仕様([[duocad-target-set-taken-only-from-selection]])なので、画面からは
逃げ道も無かった。README にも制限として明記されていた行が、この追加で解消済みになった。

実装で決めたこと(AI提案・本人の明言は無し):

- **`join` の従来の落ち方は残す**。保存済みの操作ログはその形で再生されるため。
- **`new` は `body_id` を受け付けない**(渡されたら ValueError)。行き先の無い操作に行き先が
  来たら取り違えであり、黙って無視すると「そのボディへ足したつもりが別ボディになっていた」が
  **形が増えるぶん失敗に見えないまま通る**。`mode` を既定で埋めない既存の理由と同じ形。
- 再生(replay/redo)の分岐も `join` とは別にした。同じIDのボディが既にいたら ValueError。

関連: [[duocad-verb-single-declaration]](verbのメタ情報は `catalog.py` の単一宣言が正なので、
MCPのスキーマとWSの表は自動で追随した)
