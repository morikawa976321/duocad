# duocad: ヘッダ最上段は「どのファイル」と「書けているか」だけ

本人指示(2026-08-27)。最上段は
`ファイル(左サイドバー開閉ボタン) / ファイル名 / 保存済みか` の3つになった。

## 出すもの

- **ファイル名は常時表示**にする(それまでは未保存のとき名前欄が「(未保存)」に化けていた)。
  名前が無い文書は「(無題)」
- **保存済み/未保存**を新しい札として置く。位置はファイル名の右

## 外したもの(と理由。理由は本人が言ったものだけ)

- **アプリ名「duocad」** — 理由の明言は無い
- **接続状態** — 常時表示をやめ、**操作したときに接続が無ければ、その瞬間に右上トーストで
  知らせる**形へ。相手はバックエンド(WebSocket。文書を持つPythonプロセス)
- **部品数** — 「ブラウザを見ればわかる」
- **操作数** — 「数はユーザーからしたら重要ではない」
- **プレビュー中の印** — 「プレビュー表示がいらないような設計を目指そう」
