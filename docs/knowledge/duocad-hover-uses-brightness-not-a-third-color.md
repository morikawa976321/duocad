duocadのホバー強調(クリックすれば選択されるものの事前強調)は、**新しい色を足さず
明度を上げて**伝える、と本人が決定。

**未選択の部分だけでなく、選択済みの部分にも同じ明度アップを適用する。**
本人明言の理由: **そのほうがルールが単純になる**(「ホバーしているものは明るくなる」の
1行で済み、選択状態との組み合わせを列挙しなくてよい)。

結果として色の軸は2つに分かれる —— **色相が「誰の選択か」(user=橙 / proposed=水色)、
明度が「今カーソルの下にあるか」**を表す。色を足すと、SelectionPanel廃止後に
提案と確定を伝える唯一の手段である3Dの色の区別が3つに増えてしまう。

同じ手を先に使った例: [[duocad-boundary-color-tokens-raised]](境界の視認性を
色の追加でなく明度で解決した)。
