# duocad: 既定状態は「見ているだけ」

本人の判断: **既定コマンドが常時起動しているのは問題**であり、**何も操作のない、見ているだけの
状態をデフォルト状態にする**。あわせて**既定状態では「中断」を非表示にする**。

これは **2026-08-22時点の逆の決定を覆したもの**である。当時は「明示的な『起動』の1手を挟まない
(面を選ぶ→数値→Enter の4手に1手足すと退行になる)」として押し出しを既定に構えさせていた。
**押し出しが1手増えるのは承知のうえの帰結**。

**画面に何かを足して既定に据えるのではない** — 通常モードは「どのコマンドも起動していない」
状態を既定にする(スケッチモードは領域をクリックで選ぶために「選ぶ」が既定のまま)。
2026-08-27にAIが代案として出した「通常モードにも『選ぶ』コマンドを新設して既定にする」は、
ツールバーのボタンが増えるため本人が却下した。

出所は [[duocad-show-only-what-is-needed]]。常設の表示を減らす向きは
[[duocad-no-standing-indicators]] と同じ。
