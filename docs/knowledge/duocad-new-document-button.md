本人の要望「duocadに新規ファイルを開くボタンが欲しい」により、ファイルパネルへ**「新規」
ボタン**(`new_document`)を足した。理由の明言は無い。

**それまで空の文書から始める手段はアプリの再起動しか無かった** — 「開く」は
`models/` の既存ファイルを一覧から指す操作なので、まだ何も保存していない状態へは戻れなかった。

実装で決めたこと(AI提案・本人の明言は無し):

- **確認ダイアログを挟まない**。一覧のクリック1つで別の文書へ移れる(＝保存していない編集が
  消える)のに、空の文書へ移るときだけ確認を挟むと挙動が割れる。既存の
  [[duocad-save-location-fixed-folder]] 系の作法(開く・上書きとも無確認)に揃えた。
- **AIには開けない**(`mcp=False`)。今の文書を丸ごと捨ててundoでも戻せない操作なので、
  捨てる判断は人がする。保存・開く・一覧と同じ扱い。
- 差し替えの後始末(キャッシュ・版・土台の下限)は `open_document` と共通の1関数へ寄せた。
  2箇所に分かれると片方だけ古い形状のキャッシュを残す経路ができる。

関連: [[duocad-project-switch-by-close-open]](複数プロジェクトは「閉じて開く」で切り替える、
という判断。空へ戻る手段がこれで揃った)
