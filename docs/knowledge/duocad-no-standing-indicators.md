# duocad: 常設の指標を置かない

ヘッダの札を4つ一度に外したとき(2026-08-27)の本人の言い分。**ボタンではなく「表示」の側の
方針**である点が既存の指針と違う:

- **実物を見れば分かるものに札を作らない** — 部品数について「ブラウザを見ればわかる」
- **人の判断に使わない数は出さない** — 操作数について「数はユーザーからしたら重要ではない」
- **札で補わないと伝わらない見え方は、見え方の側を直す** — プレビュー中の印について
  「プレビュー表示がいらないような設計を目指そう」
- **状態は常時光らせず、人の手が要る瞬間に言う** — 接続状態は、操作したのに送れなかった
  そのときにトーストで出す

向きは [[duocad-ui-interaction-principles]](実物クリックできるものにボタンを作らない/
verb→target→howの順序統一/省けるクリックは徹底的に省く)と同じ。
