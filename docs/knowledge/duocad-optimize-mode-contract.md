# duocad 形状最適化モードの決定

通常モード・スケッチモードに加えて**第3のモード「形状最適化」**を作る。本人が決めたこと:

- **入り方はスケッチと同じ作法** —— 「形状最適化」ボタンで入る。
- **verbは4つ**: 保持ソリッド選択 / 除外ソリッド選択 / 面への拘束追加 / 面への荷重追加。設計空間のverbは作らない（[[topopt-needs-no-design-space-input]]）。
- **操作の流れは「集合代入」** —— verbを起動すると**既にその役割が付いている対象が選択状態になって現れ**、クリックで付け外しし、決定で確定する。したがって**解除専用のverbは要らない**（verbの中で外して決定すれば消える）。
- **排他は先勝ち** —— すでに一方の役割が付いているソリッドに、もう一方を割り当てようとしたら失敗する。移すには「元の役割で外す→新しい役割で付ける」の2手。
- **保持ソリッド・除外ソリッドは操作ログ(JSON)に保存する。** ボディの参照は `body_id`（`body-{uuid}` で安定）なので、面の添字のような不安定さは無い。
- **色は選択が勝つ** —— 保持=緑・除外=赤だが、選択されているあいだはハイライト色になり役割の色は見えなくなる。それでよい。
- **拘束と荷重の見せ方はAIに一任**（「あとから修正するのは安い」）。
- **最適化エンジンとの接続はこの段階でやらない** —— 実行verbは作らない。

AI側で決めたこと（本人が「任せる」としたもの・実装上の必然）:

- **選択種別 `body` を新設する。** 現行の選択種別は face/edge/vertex/region だけでソリッドを丸ごと指せない。「クリックしたボディの面を全部選択集合に入れる」案は、1ボディ2835面のPCケースのような文書で選択集合が数百件に膨れるので採らない。
- **面の参照（拘束・荷重）には添字だけでなく重心・法線・面積の指紋を一緒に保存する。** ただし**照合に使うのは面積と法線だけ**（2026-08-31改訂。経緯は [[face-fingerprint-flags-a-plain-translation]]）。 再オープンは操作ログの再生が決定的なので安全だが、後から形を変えると添字が黙って別の面を指す。指紋を照合して**合わなければ使わずにエラーを出す**（壊れないようにするのではなく、壊れたと気づけるようにする）。
- **v1では1文書につき荷重は1種類**（集合代入なので選ばれた面すべてが同じ大きさ・向きを共有する）。複数の荷重ケースが要ると分かった時点で拡張する。
