# duocadのプロジェクト切替は当面「閉じて開く」

2026-08-23、duocadで複数プロジェクトを扱う方法として、**当面は「閉じて開く」で切り替える**と
本人が決定した（理由の明言は無し）。並行編集（複数プロジェクトを同時に開いた状態にすること）は
当面やらない。

## 同時に見送った案

検討にかけたのは3つで、いずれも当面は採らない:

1. **プロジェクトごとに別プロセス** — `--port` / `--http-port` が既にあり、ページは
   `duocad-config.json` から自分のWS URLを取るので、2本目を別ポートで立てるだけで
   独立したプロジェクトが手に入る（コード変更ゼロ）。AI会話も文書ごとに分かれる
2. **サーバを複数文書対応にして、ブラウザのタブごとに1文書**
3. **1タブ内に複数プロジェクトを同時に持つ（アプリ内タブ）** — 2の作業に加えて
   アプリ内タブUIが要る

## 前提として確かめた事実

いまのduocadは1プロセス=1 `Session`=1 `Document` で、WebSocketの状態更新は全接続へ
broadcastされる。そのため**同じURLを2タブ開いても同じ文書が映るだけで並行編集にならず**、
片方で `open_document` するともう片方も切り替わる。この構造は「人とAIが同じ選択集合を触る」
という企画の核心と同じものなので、broadcastを消すと交互操作が壊れる。
