# duocad: 形状変更の確定後は選択を全リセット

2026-08-20、本人が確定。「形を変える操作(verb確定・set_parameter・undo/redo)の後、選択は常に空」を
統一契約とし、参照失効への3つの対症療法(extrude_faceの `after_face_index` による面の選び直し/
fillet・chamfer後の辺選択解除/領域の面積・重心ハッシュによる変化検知、App.svelteに計約90行)を廃止する。

**「失効した参照と後継を返す契約」案はAIが提案したが本人がより単純なリセット案を選んだ**。
後継契約は連続性が本当に必要なverbが現れてから作る(先取りしない)。

**境界**:
- 失敗したverb(形が変わっていない)はリセットしない — 「失敗する半径では選択が保持されたまま戻る」は維持
- 可視性切替・選択操作・保存/書き出しもリセットしない(形を変えないため)
- 許容した代償: 連続押し出しの再クリック1回(Fusion360も確定後に選択が消える挙動)、
  パラメータ打ち直しで選択が消える、AI提案が間に形状変更を挟むと消える(述語の再実行は安い)
- これで解決するのは選択レイヤーのみ。操作ログ再生側の添字再解決(履歴L3/L4・由来マップ)は
  別問題として「痛みが出てから」のまま

移動系verb(`move_sketch_entities`/`move_body`)も例外にしない — 実装者判断で入った例外を2026-08-31に本人が却下した([[duocad-move-verbs-keep-the-selection]])。
