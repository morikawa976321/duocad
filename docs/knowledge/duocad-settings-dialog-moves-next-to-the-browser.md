duocadの設定ダイアログは画面右上(`position: fixed; top: 64px; right: 16px`)に出していたが、
**右上はビューキューブの居場所でもある**。キューブはビューポートの右上アンカー
(`viewCubeRect` = 右端から余白12px・一辺144px)なので、**AIサイドバーを閉じてビューポートが
右へ伸びると、キューブがダイアログの下へ入る** —— 2026-09-04の実測で**キューブの70%が
覆われていた**(サイドバーが開いているときは0%なので、開いて確認している限り気づかない)。

同日に[[duocad-settings-dialog-goes-non-modal]]でキューブを操作できるようにした直後だったので、
**置き場所をビューポート左上のブラウザ(`BrowserPanel`)のすぐ右へ移すと本人が決めた**。

実装上の要点:

- **`position: fixed` をやめ、`.stage` の中で `position: absolute` にする**。`.stage` は
  `position: relative` でビューポートとブラウザを持つ入れ物なので、**左右のサイドバーを
  開閉してもブラウザとの隣接が保たれる**(fixedのまま左からの距離を決め打ちすると、
  ファイル一覧を畳んだ日にずれる)。実測: サイドバー4通りすべてでブラウザの右10px・
  キューブとの重なり0%。
- **ブラウザの幅を `--browser-panel-w` として `styles.css` の `:root` へ移し、両者で共有する。**
  直値で持つと、片方だけ動かした日に重なるか妙な隙間が空く。
- **`position: absolute` はフローの外なのでビューポートの寸法＝カメラのアスペクトに触らない**
  (ブラウザ・Toastと同じ扱い)。移動前後で acceptance の `frameAll` の広がりが完全に同一
  (45度=380.1px / 30度=372.9px)であることで裏取りした —— **「大きさを持たないはず」を
  数値で確かめる手段がこれ**である。

**一般化**: ビューポートの隅にアンカーした描画物(ビューキューブ)と、画面にfixedで置いたDOMは、
**サイドバーの開閉で相対位置が変わる**。片方はビューポート基準・もう片方はウィンドウ基準なので、
「いま重なっていない」は何も保証しない。**重なりの検査はサイドバーの開閉を変えて行うこと。**
