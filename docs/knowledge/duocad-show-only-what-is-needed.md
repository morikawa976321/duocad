# duocad: その瞬間に要るものだけを出す

本人が制定したduocadの設計方針。原文:

> ユーザーがその瞬間必要とするものを過不足なく表示し、余計なものを出さない

出し分けは3段:

1. **明確に必要なものは出す** — 例: 通常モードにフィレットは必須
2. **明確に必要でないものは出さない** — 例: スケッチモードにフィレットは要らない
3. **使うかもしれないし使わないかもしれないものは、認知負荷を高めないように注意して配置するか、
   ユーザーが表示・非表示を切り替えられるようにする** — 例: 保存関連エリアやブラウザは開閉可能

**「モード」が出し分けの主軸である**点が既存の指針との違い: 同じ要素でも、通常モードとスケッチ
モードで必要かどうかが変わり、要らない側では**画面から消す**(無効化して置いておくのではない)。

本人が制定と同時に下した判定: **右サイドバーにスケッチ専用のエリアが常時出ているのは
この方針に反する**(スケッチモードでないときスケッチパネルは2段目に当たる)。

向きは [[duocad-ui-interaction-principles]]・[[duocad-no-standing-indicators]] と同じで、
[[duocad-low-frequency-settings-in-a-modal]] の線引き(作業中に切り替えるものはその場のパネル、
一度決めたら触らないものは設定モーダル)は3段目の具体化にあたる。
