# スケッチを動かしても既存ソリッドは追従しない(許容済み)

## 事実(2026-08-30実測)

`duocad/duocad/view.py:345-347` を見る限り、`set_parameter` で値が変わったときに再計算されるのは**スケッチ自身の描画・領域キャッシュだけ**で、**そのスケッチを既にextrudeして作ったソリッド(Body)を自動追従させる仕組みはコード上どこにも無い**。duocadには現状、スケッチ→フィーチャーの依存関係を追って再計算する「パラメトリック履歴ツリー」的な仕組みが無い。

## 判断（本人）

[[duocad-move-verb-split-sketch-and-body]] の move_sketch_entities で、既にextrude済みのスケッチ図形の点/辺を動かしても、対応するソリッドは追従せず、見た目上スケッチの線とソリッドがズレる。これは新規のリスクではなく、既存の `set_parameter`(廃止予定のパラメータパネルが使っていたverb)でも既に起きていた性質と同じであり、本人が許容した。

## 波及

将来「寸法調整」や「パラメトリックな再計算」を作る際は、この非連動性そのものを解消するかどうかが論点になる。現時点では解消しない前提で進めてよい。
