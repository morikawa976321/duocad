# スケッチパラメータパネルを廃止し、直接選択でのスケッチ修正へ置き換える

## 判断（本人）

duocad右サイドバーのスケッチパラメータパネル(`SketchPanel.svelte`。各図形のx0/y0/cx/cy/radius/width/height等を数値入力できるUI)を廃止する。位置の打ち直しは、マウスでの直接選択+move verbに置き換える。

## マウス操作の再配置

- 中ボタンドラッグ = パン(画面移動。three.js `OrbitControls` の既定のまま、変更不要)
- 右ドラッグ = カメラ回転(現状は左ドラッグに割り当たっている`OrbitControls`既定を右へ移す)
- 左ドラッグ = ウィンドウ選択(新規実装。矩形に**完全包含**されたものだけを選択対象にする。ドラッグの方向は問わない — 左右どちらへ引いても同じ判定でよい、と本人が明言)

## 選択修飾キーの統一

現状は Shift+クリック=選択に追加、Ctrl+クリック=選択から除外、という別機能(`duocad/web/src/viewport.ts:2426-2430`)だったが、これを**ShiftとCtrlのどちらも「既存の選択を消さずにトグルする(選択済みなら外す、未選択なら足す)」という同一機能に統一する**。理由(本人明言): 「間違えたらもう一回クリックすればいいので、除外専用の機能は実質無意味」。無修飾クリックは常に「選択を置き換え(既存を全部消して1つだけ選ぶ)」のまま変更しない。

## 関連

実装は [[duocad-move-verb-split-sketch-and-body]] とセットで、move verbが機能するようになってからパネルを削除する順序を守ること(先にパネルだけ消すと編集不能な期間ができる)。
