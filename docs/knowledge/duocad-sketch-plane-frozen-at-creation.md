# duocadの面参照スケッチは作成時点で姿勢を固定する

**本人の判断（2026-08-30）**: duocadで既存ソリッドの面に貼ったスケッチは、**作成時点の平面姿勢
（origin/u/v/normal）をスケッチ自身へ焼き付け、以後そのボディに何が起きても参照し直さない**。

**明言された理由**: 同じ状況（直方体の上面にスケッチ → 上面が完全に丸まる大きさのフィレットを
後から適用し、参照元の面の面積を0にする）をFusion 360の実機で再現したところ、**スケッチは元の
高さ・向きのまま残った**。つまり後続操作からの独立が正しい設計だと実機で確認できたため。

**同時に不採用にしたもの**: 面の同一性をprovenance（重心一致など）で追跡し続ける方式。
実機挙動から不要と判明した。

作成**より前**の履歴に対するパラメータ編集には従来どおり追随する（`rebuild()` が履歴を頭から
再生するとき、スケッチ作成verbがその時点の形状から姿勢を解き直すため）。壊れていたのは
「作成**後**の同じボディへの操作が既存スケッチの姿勢を巻き込む」経路だけだった。
