# duocadのスケッチ開始は「起動→クリック」の2手に統一する

2026-08-22、本人決定。

**選択**: スケッチ作成の操作を、対象が基準平面(XY/XZ/YZ)でも任意の面でも
**「スケッチボタンを押す → 対象をクリック」の2手**に統一する。Enterによる確定は挟まない。

**理由**: 対象の指し方が2つ(サイドバーの平面ボタン / 面を選んでからボタン)あり、
しかも面の経路は「面をクリックする」と「選択した面を使うと言う」で同じことを2回言っていた。
指し方を**ポインティング1つ**に寄せると重複が消え、基準平面と任意の面が同じ操作になる。

**含意**: 基準平面の3枚がビューポートのピック対象になる(今は装飾で、raycasterに渡す配列に
入っていない)。ボタンで平面を指す経路は無くす —— 残すと2つの指し方が戻る。
