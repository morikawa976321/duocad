# duocad UI監査(2026-08-22)の論点7件への裁定

2026-08-23本人決定。監査レポート本体は本人指示で削除済み(reports履歴 bf58ca6 の親から復元可)。

1. **スケッチパネルの領域一覧 — 領域一覧エリアごと削除**。「冗長」。描画中に領域を選ぶには
   Escが1手要るようになるが、それを受け入れる。[[duocad-intentional-duplications]] の
   「一覧クリック(トグル) vs 3Dクリック(置換)」の重複は対象ごと消滅(同ノートに撤回を追記済み)
2. **パーツ一覧のpick列(左チェック)と「選択したものだけ表示」— 削除**。各パーツは
   表示/非表示のチェック1つだけ持つ。理由: **duocadは10や20の複数パーツを扱えるほど
   リッチな状態ではなく、現段階で考える必要のない懸念**(スコープ判断。全表示/全非表示は
   指示の範囲外なので残す)
3. **指針②(verb→target→how)の適用範囲 — パネル内の直接編集(set_parameter・set_visible・
   選択集合の編集)は対象外と明記**する
4. **「押し出す」「領域を押し出す」の2ボタン — 現状維持(問題視しない)**。ボタン押下後は
   verb→target→howそのものであり、verbが対象種別を含意するのは「丸める=辺」と同じ
5. **押し出しは両モードに表示し、選択可能対象だけ変える**: スケッチモードでは領域、
   通常モードではスケッチ(領域)も面も選択できるようにする。通常モードの領域ピックを
   実装する(監査の違反1件=「通常モードの領域を押し出すがtargetを取れない」の解)
6. **入力欄のCtrl+Z — バグとして修正、Enterの規律に寄せる**(INPUT/TEXTAREA除外)
7. **履歴の行クリックで一括undo — 見送り**(コアの機能追加になるため。v1受入後に再判断)

2の理由は個別UIを超えて再利用可能: **現段階のduocadは複数パーツ運用を最適化しない**。
