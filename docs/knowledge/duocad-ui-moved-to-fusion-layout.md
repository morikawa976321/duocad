# duocad: 画面配置をFusion 360に寄せる

## 判断(本人・2026-08-23)

> duocadのUIをFusion360に寄せる。
> (1) ツールに保存済みのファイル一覧を左サイドバーに表示。左サイドバーはトグルできる。
> (2) viewport左上にモデル、スケッチ、コンストラクションをツリー形状で表示する。
> しかし現時点では、モデルとスケッチの2種のみを分けて表示すればいい。
> ツリー化とコンストラクション追加は将来の発展。

## 実装で決まったこと

- **ファイル一覧は右サイドバーから左サイドバーへ移った**。左サイドバーの中身は
  `FilesPanel.svelte` 1枚だけで、ヘッダの「ファイル」ボタンで開閉する。
  開閉の状態はコアに持たせない(モデルの状態ではないので操作ログにも残さない)。
  **2026-08-23 19:22〜2026-08-26の間はツールバーへ統合されていたが
  ([[duocad-files-panel-selection-panel-verdict]])、2026-08-26に本人が
  左サイドバーへの復元を決定し、この配置(左サイドバー)が再び正になった。**
- **旧「パーツ一覧」(`PartsPanel.svelte`)は消え、`BrowserPanel.svelte` になった**。
  ビューポートの左上に `position: absolute` で浮き、「モデル」(ボディと可視性)と
  「スケッチ」の2区分をフラットに並べる。可視性の切り替えはここが持つ。
- **区分の見出しだけ先に立ててある**。入れ子のツリー化とコンストラクションを足すときに
  一覧の作り直しにならないようにするため。
