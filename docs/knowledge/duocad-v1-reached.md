# duocad v1 に到達した（2026-08-14）

**v1の定義**（2026-08-11本人決定）: いま実装済みのverbすべてを、人間とAIの両方が満足に使える状態。

- **19操作 × 人間/AI が 19/19**。テスト **534件緑**（対話セッションで独立に再実行して確認）
- **交互操作が実機で通った**（この企画の差別化点）: AIが述語 `parallel_to Y` で辺**34本**を提案 →
  画面に提案色（水色・確定は橙）で出る → 人が1本クリックして `origin` が `user` へ遷移 →
  AIが読み直して `fillet(1.5)` → **面 10→13**
- 受入は**独立に2回**通し、体積・面数・書き出しバイト数まで一致
- 大きいモデル（27部品2835面）で押し出し1往復 **1,250ms**（分解前は約5秒）、差分配信で送信量7.8%
