# 実機検査で画素はコマンドをまたげない(duocad)

2026-08-23に実測。duocadのツールバーは起動中のコマンドの引数を出すので、
**コマンドを移るとビューポートの高さが変わる**(実測 636px → 669.5px)。射影は寸法に依存するため、
**あるコマンドで測った画素を別のコマンドで押すと違う場所を押す**。

「同じ場所が、コマンドAでは領域・コマンドBでは面になる」型の検査はこれで書けない。
解は**画素ではなく世界座標を持ち越し、押す直前に射影し直す**こと。duocadでは
`window.__duocad.projectSketchPoint(u, v, sketchId)` がその穴で(2026-08-23に
`sketchId` を任意引数で足した)、スケッチ座標を持ち越せば通常モードでも同じ点を指し直せる。

同じ理由で、**1つのコマンドの中でも引数が1つ埋まると文言が変わって寸法が動く**ので、
射影はクリックの直前に毎回やり直す。
