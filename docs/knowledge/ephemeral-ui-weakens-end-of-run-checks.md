# 消えるUIへ移すと「最後に一度だけ見る検査」が黙って弱くなる

2026-08-22、duocadのエラー表示をステータスバーからトーストへ移したときに踏んだ。

`smoke-files.mjs` は走行の最後に一度だけ「画面にエラーが出ていないか」を見ていた。
**通知欄は消えない**ので、その1回で走行全体を覆えていた。表示先を8秒で消えるトーストへ
移すと、同じコードが**同じように緑を出したまま**、途中で出て消えたエラーを拾わなくなる。
赤くならないので移した側は気づかない。

対処: 表示は消してよいが、**消えない控えを検査用に別途残す**(duocadでは
`App.svelte` の `errorLog` → `window.__duocad.errors`)。今まさに出ている札の文言は
DOM(`#toasts`)を見て、走行全体の有無は控えを見る、と読む先を分ける。

一般化: **表示の寿命を縮める変更は、その表示に依存している検査の網の目を粗くする。**
表示先を変えるときは「この文言を見ている検査は、いつ見に来るのか」を先に数える。
