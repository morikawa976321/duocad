# 面の指紋の照合は面積と法線だけで行う

duocadの形状最適化の条件で、面の参照に**面積・法線・重心**を焼き込むと決めた
([[duocad-optimize-mode-contract]])。実装して分かった帰結:

**重心を世界座標で持つので、`move_body`(平行移動)でも指紋が合わなくなる。** 平行移動は
面の添字を変えない(形は作り直されず位置だけ差し替わる)ので、指した面は**同じ面のまま**で
ある。それでも重心が動くため条件が「使えない」側へ回り、部品の位置を詰めるたびに拘束・
荷重の付け直しが要った。

**決定(2026-08-31・本人)**: 照合から重心を外し、**面積と法線だけ**で見る。重心は記録は
続ける(不一致になったとき何が起きたかを示すため)。理由は3つ:

- 面積と法線は**平行移動で不変**なので、誤検出が消える。duocadにボディを回すverbは無く、
  `move_body` は dx/dy/dz だけなので、法線が変わる操作は形状変更だけである。
- 照合には**添字の一致も要る**ので、誤って通るには「添字も法線も面積も一致する別の面」が
  必要で、重心を落とした分の弱まりは小さい。
- 本来の狙い(添字が別の面を指すようになった)は**添字の側で先に不一致になる**ことが多い。

実装 duocad `dbedb6b`。テストの題材は `move_body` から辺のフィレットへ替えた —— 実測で
面1は同じ面のまま面積400→360(面積で捕まる)、面2は法線(0,1,0)→(0,0,-1)(添字が別の面へ
移った)と、どちらも重心なしで捕まるため。平行移動で外れないことは
`test_moving_a_body_does_not_invalidate_its_face_conditions` が固定している。
