# 決め打ちの微小ずらしは守りにならない。決定的なやり直しにする

幾何アルゴリズムの縮退(レイが頂点や辺をちょうど貫く等)を避けるために、標本点を微小量だけ
ずらすのはよくある手だが、**ずらし量が1つの固定値だと守りにならない**。その値にちょうど
合った位置に頂点が来る入力(または格子)を作れば必ず縮退させられる。

実例(duocad `probe_topopt/voxelize.py`、2026-08-31): レイをセル中心から要素サイズの
1e-4 だけずらしていたが、QAが「円錐の頂点にその既定のずらし量を合わせた格子」を渡して
再現させた。**自分では「ずらしは効いている」と実測して確認していた**(ずらし無しでは全解像度で
落ちることを確かめていた)が、それは**既定値が効く入力しか試していなかった**という意味でしかない。

対処: ずらし量を**決定的な列**にして、縮退を検知したら次の候補でやり直す。全部だめだった
ときだけ例外にする。乱数を使えば同じことができるが**決定性が失われる**ので使わない
(倍率を素数にすると、ある倍率で当たった位置が別の倍率で当たり直しにくい)。

一般化: **「微小ずらしで回避した」と書いたら、その値に合わせた反例が作れないかを疑う。**
回避策が1点の定数に依存しているなら、それは守りではなく「たまたま当たっていない」だけ。
