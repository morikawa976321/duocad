`hanger_bar_attachment` を**製品経路の塊**(`build_reference` → `derive_from_reference`)で
回すと、保持ソリッドが結果から落ちる病理が再現する。**原因は更新則でも制約でもなく、
塊の導出そのもの。**

## 実測(要素 3.993mm・材料 70,634.5mm^3・k=2.0・12反復)

塊 6,361要素の連結成分が**6近傍で6個** `[74, 6205, 2, 4, 2, 74]`:

| | 6近傍の成分 | 荷重と同成分 |
|---|---|---|
| 拘束面11 | 6(74要素) | **No** |
| 拘束面3 | 1(74要素) | **No** |
| 拘束面19 | 2(6205要素) | Yes |
| 荷重面31 | 2 | Yes |
| 保持#1(x -35.9〜-20.0) | 1 | **No** |
| 保持#4(x 20.0〜35.9) | 6 | **No** |

**18/26近傍では成分2個 `[6353, 8]` で全部つながる。** つまり2枚の拘束面とその保持円盤は、
本体と**辺・頂点でしか接していない島**である。ボクセルFEAは節点を共有すれば力が伝わるので
解は落ちず、`mesh.remove_islands`(面接続で見る側)が黙って消す。

## なぜ導出が通ってしまうか

`design_space.assert_load_path` は `fixed_labels` と `load_labels` の**共通成分が1つでも
あれば合格**にする。`corridor_length` はその述語で二分探索するので、**回廊は拘束面が1枚
繋がった時点で伸びるのをやめる。** 残りの拘束面は「無条件に OR する条件要素」として
塊には入るが、本体へ繋ぐ材料は順位から落ちている。

## MMA でも反力制約でも治らない(実測)

同じ塊で `oc` / `mma` / `mma + reaction_min=0.10` を回して、**3つとも同じ**:

- 保持#1・#3・#4 の `alive_ratio` が 0.000(結果メッシュから消える)
- 反力は 0.820/0.821/1.958(面11/面3/面19)で**制約は最初から満たされている**

**材料を置けない場所(塊の外)には、どんな更新則も制約も材料を置けない。** 反力制約は
ε をいくら上げても、幾何が固定された塊の上では失敗を返すだけになる。

なお面11と面3の 0.82 は**互いに打ち消し合う偶力**(y成分 +0.80/+0.80 に対し面19が -1.60)で、
荷重(-z)をほとんど運んでいない。**`fraction` の大きさだけ見ると「3枚とも効いている」と
誤読する。**

## 保持ソリッドは4つとも条件面が乗っている

面とアンカーの重なりを実測した対応(3.993mm):

| 保持 | 位置 | 乗っている条件面 |
|---|---|---|
| #1 | x -35.9〜-20.0 / z +50.8〜+66.7 | 拘束3 |
| #2 | x -16〜16 / y -217〜-181 | 荷重31 |
| #3 | x -8.0〜8.0 / z -69.0〜-53.1 | **拘束19**(反力 1.958 で最大) |
| #4 | x +20.0〜+35.9 / z +50.8〜+66.7 | 拘束11 |

**「条件が何も乗っていない保持ソリッド」は無い。** #1/#4 の死因は孤島で確定しているが、
**#3 の死因は未確定** —— 塊では本体と同成分にいる。有力な仮説は「拘束19 のアンカーは
74要素で y 3層に広がるのに保持#3 は y 1層だけなので、板側の層に取り付けば反力の条件は
満たせて、裏へ張り出した12要素だけが取り残される」だが**未測定**。

## 本番の作業解像度(2.412mm)でも再現する(2026-09-11)

参照 run 1878.3秒・箱 1,096,894要素(2026-09-09 の記録と一致)・回廊 6,197・塊 11,166要素。
**塊の連結成分は6個 `[11080, 2, 1, 1, 1, 81]` で、拘束面10 が81要素の孤島にいる。**
そのまま OC を40反復回すと(1443.3秒):

- 拘束面10 の反力が **厳密に 0.0**、他の2枚が 1.610 / 1.592
- **拘束面10 が乗っている保持#4 だけが `alive_ratio` 0.000**(他の3つは 1.000)

**塊が切れる → その面が荷重を1つも受け持たない → その保持ソリッドがメッシュから消える**、が
1本につながった。

**回廊の不足は解像度が上がるほど広がる**: 「全条件を繋ぐ最小の本数」は 3.993mm で 7,412
(いまの回廊の 1.16倍)だが、**2.412mm では 40,046(6.5倍)**。細かい格子ほど同じ隙間を埋める
のに要るセル数が増える —— **粗い格子での「ほぼ足りている」は本番解像度の根拠にならない。**

なお 2026-09-11 16:43 に `models/hanger_bar_attachment.json`(**git 管理外**)の拘束面が
差し替わっており(平らな面 175.9mm² → 側面 65.3mm²)、3.993mm の実測は旧設定・2.412mm は
新設定である。**機序は両方で同じだが、落ちる枚数は違う**(旧2枚 / 新1枚)。
