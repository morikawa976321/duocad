# 密度場をガウシアンで均してから marching cubes を切る(段0)

duocadのトポロジー最適化で、marching cubesの出力に中周波(k≈0.25〜0.5、周期が要素サイズの4〜8倍)の
うねりが残り、Taubin平滑化(λ=0.5・μ=−0.53)をかけても目立ったままだった(2026-09-05、本人が画像で確認。
輪郭のシルエットで気づいた)。

原因は伝達関数 `f(k)=(1-λk)(1-μk)` の計算で判明: 30反復後、k=1(階段状ファセット・高周波)は0.03%まで
落ちるのに、k=0.25は76%・k=0.5は21%残る。**メッシュ側の低域通過は高周波を消すのが得意で、中周波には
反復数を増やしても効率が悪い。**

**対策**: 密度場を規則格子の上でガウシアン(`scipy.ndimage.gaussian_filter`)で均してから marching cubes で
等値面を切る(`duocad/topopt/mesh.py` の `smooth_density`。段0、marching cubes の前)。三角形が作られる前に
うねりを消すので、marching cubes の不規則な頂点間隔に由来する病理(一様重みラプラシアンが密な側へ引っ張る)も
避けられる。ρのコピーに対して行うので最適化の答え(コンプライアンス・安全率)は変わらない。既定 σ=1要素。
保持ソリッド・除外ソリッド・設計空間の外は平滑化の後に ρ=1/0 へ塗り直して保護する。

## 副作用1: 保護されていない薄い部材を食う

**SIMPが自分で作った細いリブ・薄肉は保護されない。** `design_space.CASES` の4題材を `max_iter=40` で最適化し、
同じρから平滑化オン/オフの2本のメッシュを作って比較(σ=1要素):

- `bracket`/`branching`(比較的太い部材主体)は見た目の差が微妙。
- **`plate`(極端なアスペクト比)/`tilted`(除外の穴を持つ)は差が非常に大きい。** `plate` は1枚だった傾斜面の
  リブ群が複数の細い枝へ裂けて穴が空いた。`tilted` は除外トンネルの縁にあった薄い膜状の材料が消えた。

**「見た目が滑らかになる」ではなく、薄い部材が両側から食われて構造(トポロジー)そのものが変わりうる。**
σ=1要素は本人が未検証のまま決め打ちした値で、薄肉設計ではσを下げる調整が要る可能性がある(未検証)。
スクリーンショット: `duocad/probe_topopt/screenshots/smooth_compare/`(`plate_iso.png` / `tilted_zoom.png`)。

## 副作用2: 「等値0.5の面が囲む体積 ≒ sum(rho)」の近似が緩む

`check_mesh.py` 検査2はこの近似で marching cubes 直後のメッシュのまともさを見ており、平滑化前は数%以内
(閾値5%)だった。SIMPの密度場は元から完全な二値ではなく(密度フィルタの遷移域)、ガウシアンがその非対称性を
広げるらしく、**σ=1要素でも誤差が 3.42% → 8.21%、σ=2 では 32.5%**(片持ち梁35×14×14・15反復)。
閾値は 5% → 12% へ緩めた。緩めても level取り違え・半セルずれのような本物のバグ(実測30%超)は捕まえられる
ことを確かめてから決めた。**密度場をぼかす処理を挟むなら、体積と sum(rho) の一致検査の閾値は緩める必要がある。**

## 副作用3: 保持スパイクが浮島除去で消える

`mesh.py` は密度場を `remove_islands`(二値化した場の最大連結成分だけを残す)に通してから marching cubes へ
渡す。保持マスクでρ=1に塗り直した領域でも、**本体と1層の境界だけで接していると、境界の1層自体は保持マスクの
外(平滑化されただけ)なので、極端なσではその1層の物理密度が0.5を割り込み**、保持スパイクが孤立成分になって
`remove_islands` が丸ごと消す。`check_mesh.py` 検査10で実際に踏んだ(σ=3.0)。対策は保持マスクを本体の内側から
数要素分重ねて配置すること。σ=1では起きにくいが、保持ソリッドが薄い/本体との接触が細い実際の設計でも
原理的に同じ壊れ方をしうる。
