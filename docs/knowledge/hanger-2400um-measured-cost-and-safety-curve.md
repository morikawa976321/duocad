# hanger 2.4mm の費用と安全率の曲線(2026-09-09実測)

`models/hanger_bar_attachment.json` / 要素 2.408mm / 案1の箱 1,096,894要素 / 容量 15,307,281mm^3 / この機械(14スレッド・34GB)。既定の導出は連続値保持(k=2.0)。

## 1反復あたりの秒数(組立 約98秒を除く)

| 材料量[mm^3] | 秒/反復 |
|---|---|
| 8.419e6(塊=箱) | 136.5 |
| 4.220e6 | 68.8 |
| 2.121e6 | 52.8 |
| 1.071e6 | 44.2 |
| 5.463e5 | 37.9 |
| 2.839e5 | 40.5 |
| 1.526e5 | 35.4 |
| 8.704e4 | 33.6 |

**塊が小さくなっても34秒あたりで頭打ちになる。** 材料量を半分にしても費用は2〜3割しか下がらない。「要素数^1.30」で外挿すると小さい側で2倍近く外す(実測36.8分に対し予想21分)。床がある理由は未確認だが、連立方程式と多重格子の階層が**塊ではなく格子全体**(78×138×109)の上に組まれているためと見られる。

**峰メモリ 26.1GB。** 事前に単発で測ったときは22.4GBだったので、探索を通すと3.7GB増える。参照run(10反復・箱いっぱい)+上端評価(40反復)で **7,256秒 = 2.02時間**。

## 安全率の曲線(目標2.0)

| 材料量[mm^3] | 最小安全率 | 前の点からの倍率 |
|---|---|---|
| 8.419e6 | 650.19 | — |
| 4.220e6 | 435.21 | 0.669 |
| 2.121e6 | 284.14 | 0.653 |
| 1.071e6 | 185.18 | 0.652 |
| 5.463e5 | 106.53 | 0.575 |
| 2.839e5 | **13.48** | **0.127** |
| 1.526e5 | 6.71 | 0.498 |
| 8.704e4 | 3.18 | 0.474 |

**単調ではあるが傾きが大きく揺れる**(halvingあたり0.127〜0.669)。**2点から外挿して交差点を当てようとすると必ず外す** — 実際 650→435 の2点から「答えは範囲の下端より2桁下」と読んだが、実際の交差は 5.4e4〜8.7e4mm^3(容量の0.35〜0.57%)だった。代表応力が「ρ>=0.5 の要素の上位99.5%点」で、位相が変わると跳ぶためと見られる。この端から端までの探索は材料量が小さい側で残差検算に落ちた → [[safety-search-dies-on-residual-failure-at-low-material]]。
