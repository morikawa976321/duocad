`hanger_test` を**製品経路**(`build_reference` → `derive_from_reference`)で
**要素2.412mm・材料 70,634.5mm^3**(= `hanger_bar_attachment` が病理を出した量)で回した:

```
参照 run  466.9秒  箱 322,384  回廊 2,104  参照材料 361,888mm^3
塊        10,068要素  連結成分5個 [10062, 2, 1, 1, 2]  ← はぐれは合計6セル
          拘束面3枚と荷重面がすべて同じ成分
OC 40反復 424.1秒  反力 0.972/0.972/1.929  保持4つとも alive 1.000
```

**病理は出ない。**

## 機序 —— `taken / 参照の rho>=0.5` で決まる

| | 参照の材料 | 候補の材料 | `taken` | rho>=0.5 | 比 |
|---|---|---|---|---|---|
| `hanger_bar_attachment` | 87,752要素分 | 5,062 | 10,123 | 87,086 | **11.6%** |
| `hanger_test` | 25,780要素分 | 5,034 | 10,068 | 約25,600(推定) | **約39%** |

参照の材料は `REFERENCE_MATERIAL_RATIO`(0.08) × **箱の容量**なので、**箱が大きいほど参照が
太る**。`hanger_bar_attachment` の箱は 3.4倍大きく、同じ材料量で切ると**ずっと浅い等値面**に
なる。**11.6% では砕け、39% では持ちこたえる。**

## 帰結

**病理の引き金は「外接直方体に空きが多いこと」であり、これは現実の部品では普通の状態である。**
`hanger_test` は部品を密集させて箱を 3.4倍小さくした検証用モデルなので、**構造上この病理を
出せない。**

**2026-09-10 の「検証用の実物モデルは `hanger_test` を使う」という決定は、この病理には
適用できない** —— 速度のための決定が検出力をゼロにする場面である。**塊の導出に関する回帰は
`hanger_bar_attachment` でしか止められない**(箱 1,096,894要素 / 参照 run 31分 / 評価1回
24〜73分)。

`hanger_test` は `p`(塊の大きさの摘み)を振るような**比較の計測**には引き続き使える
(3.4倍安い)。**使ってはいけないのは「病理が直ったか」の判定だけ。**
