離散点(格子節点)に載った量が空間的に一様かを検査するとき、面を格子状のビンに切って
「ビンごとの合計 vs 真の面積」で比べると、**ビン境界を跨ぐ点1個の出入りがそのまま誤差になる**。
実測(duocad probe_topopt の面アンカー): 3要素幅のビン(1ビンあたり約9節点)で
±27% のばらつきが出て、正しい実装と明らかに間違った実装(面積重みを外した等分)が
**区別できなかった**。

直し方: **ガウス核(σ = 2要素)で平滑化し、同じ核で平滑化した真の分布と比べる。**
分子と分母で縁の効果と曲率の効果が相殺し、残るのは「配り方の偏り」だけになる。
同じ題材で、正しい実装 0.5〜0.6% / 等分の対照 3.4〜3.5% と**6倍離れた**。

副産物の作法: **わざと壊した対照(ここでは面積重みを外した等分)を同じ検査に掛けて、
実際に落ちることまで受入検査に含める。** 閾値が緩すぎて何も検査していない状態を防げる。
実際、最初に選んだ題材(円筒・要素サイズを粗く)では対照が 1.03% しか出ず、
閾値 1.5% を下回った —— **その題材ではその検査は効いていなかった**と分かった。
