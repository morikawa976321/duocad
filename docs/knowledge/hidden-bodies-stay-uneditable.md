# 隠したボディは変更もできない(承認・現状維持)

2026-08-20、本人が承認。duocadの `fillet` / `chamfer` / `extrude`(領域)は、対象ボディを
選択の外(既定=アクティブボディ)から解決するため、**確定選択が生きたまま対象ボディだけ
人に隠されると黙って変更していた**。同日これを塞ぎ、対象ボディが非表示なら拒否するようにした。

副作用として「ボディを隠したまま、そこへ意図的に材料を足す」操作ができなくなる。
本人はこれを承認し**現状維持**と決定。

**根拠**: 「**可視性は見た目の設定ではなく、何を指せるかの定義**」という既存の原則の
素直な延長である(PCケース27部品でピック失敗率63%の原因が「手前の部品が奥の面を隠していた」
ことだった件)。この使い方では隠すのは「今いじらないもの」なので、隠したものを変更できない
のは例外ではない。引っかかる場面(視界を塞ぐベースプレートに融合したい等)でも
**手数が1つ増えるだけで、しかもエラーで理由が出る** —— 従来は黙って変わっていた。

**先に緩めない**。煩わしければ `join` モードだけ後から緩める余地がある。静かな事故のほうが高くつく。
