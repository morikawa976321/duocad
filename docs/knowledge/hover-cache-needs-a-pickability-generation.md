「クリックしたら何が取れるか」をホバーで先に見せる機能で、**毎フレームのレイキャストを
省くために「ポインタ位置+カメラ位置+カメラ姿勢」を鍵にしてキャッシュした**。
これは**不足**である。

**当たるものは、ポインタも視点も動かないまま変わる**:

- コマンドを解除してゲートが閉じた(領域・辺・基準平面が指せなくなる)
- 逆にコマンドを起動してゲートが開いた
- 選択が変わって新しいマーカーが出た(duocadでは頂点マーカーが面より先に取られる)
- プレビューで本物のボディを隠した / 戻した
- ビューポートの寸法が変わった([[viewport-resize-silently-changes-what-a-click-grabs]])

いずれの場合も**明るいままの古い予告が「クリックすれば取れる」と嘘をつく**。予告と結果の
一致だけがこの機能の価値なので、これは機能そのものの否定になる。

**対処**: 「何が指せるか」を変える側が増やす**世代番号**を持ち、キャッシュの鍵へ混ぜる。
ゲート・可視性・マーカーの増減・寸法変更のすべてがその番号を増やす。加えて、
**無効化は参照を捨てるだけでなく材質を戻すところまでやる**(捨てるだけだと、次の解決が
「なし」のときに誰も戻さない)。

**この穴は自分では見つからず、QA(cursor / gpt-5.6-terra-xhigh)が指摘した。**
実装者は「省略の条件」を書いた本人なので、その条件が不足している場面を思いつけない。
変異検査(世代番号を鍵から抜く)で、指摘どおり検査が赤になることを確認済み。
