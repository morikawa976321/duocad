duocad の probe_topopt で、保持ソリッド・除外ソリッド・拘束面・荷重面の4条件だけから設計空間
(塊)を導出する経路を作り、導出ロジックを**条件の点群の外接直方体 + 余白(最長辺 × 比率)**
(案1)にして実測した。合成の4条件・要素サイズ固定 3.635mm・60反復。

**案1は「塊が答えを含む」ことを保証できない。** 材料の総体積を固定した比較で、最適化が置いた
材料のうち塊の壁に接している割合は 余白比率 0.10 で 34.2%、0.25 で 8.9%、0.40 で 3.3%、
0.50 でも 3.3% で下げ止まる。壁に接している＝その部分の形を決めているのが荷重と拘束ではなく
**箱の壁**である。余白をいくら広げても 0 にならない。

**姿勢依存も残る。** 同じ部品を z 軸まわりに 30° 回すだけで塊が 1.38 倍(6988 → 9652 要素)、
材料が 1.34 倍になる。しかも**単調ではない** —— 余白が「最長辺 × 比率」なので 45° では最長辺
自体が縮んで余白も縮み、45°(1.20 倍)より 30° のほうが悪い。「45° が最悪」と決めつけて測ると
見落とす。

**既定を 0.25 にした根拠は検査ではなく実測にある。** 受入検査は「保持が塊に入るか」しか見て
おらず、**余白比率 0.00 でも全部緑になる**(壊れ始めるのは -0.05 で、負側にしか崖が無い)。
検査で既定値の安全性を担保することはできていない。

これは後続の案5(粗く1回回して膨らませる)と比べるためのベースラインとして作ったもので、
比較の基準線がこの数字になる。**2026-09-04に案5を既定に採用した**(案5は 0°→30° で 1.01倍。

粗い段へ渡す材料量の実測に使う([[coarse-stage-voxel-volume-is-several-times-the-true-volume]])。関連: [[topopt-needs-no-design-space-input]] /
