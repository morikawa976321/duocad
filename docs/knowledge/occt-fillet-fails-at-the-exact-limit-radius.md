# 面積を厳密に0にする丸めはOCCTでは作れない

実測（2026-08-30・OCP 7.9）:

- 20mm立方体の上面4辺をフィレット: r=9.99 は成功して上面が 0.02mm 角の微小平面として残る。
  **r=10.0（限界値ちょうど）は `IsDone()=False`** で失敗する。
- 20×10×20 の直方体の上面の長辺2本: r=4.999 は成功（微小平面が残る）、**r=5.0 は失敗**。
- 面取りも同じ: 距離4.99は成功、5.0は `IsDone()=False`。4辺・距離10.0 は
  `IsDone()=True` だが `BRepCheck` が invalid を返す。

つまり**限界未満では常に微小な平面が残り、限界ちょうどでは操作自体が通らない**ので、
「参照していた面の面積が完全に0になる」状況を丸め・面取りで作ることはできない。
回帰テストでその状況が要るときは**切削（対象面より大きい領域で切り下げる）で作る**。

関連: `tests/test_fillet.py` のdocstringが記録している「r=10.0は失敗するのに r=10.5 は成功する
（半径に対して単調ですらない）」も同じ性質の一部。
