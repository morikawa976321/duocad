# OCCTの点分類器は材料内部の孤立点をOUTと誤判定することがある

`BRepClass3d_SolidClassifier` は内部でレイを飛ばして内外を決めるので、**特定の点からだけ
レイが面の縁を舐める**と誤判定する。実測(duocad `probe_topopt` stage1、2026-08-31、
`shelf_attachment_7.step`・231面):

- 点 `(89.059, −57.750, 439.899)` を `OUT` と答えたが、
  `BRepExtrema_DistShapeShape` で測ったB-rep表面までの厳密な距離は **2.0139 mm**。
  つまり**どの面からも2mm離れた材料の内部**。
- 同じ直線上を 0.1mm 刻みで ±3mm 掃くと `OUT` はこの1点だけで前後は全部 `IN`。
  ±0.0001mm ずらした点も `OUT`、±0.1mm ずらすと全点 `IN`。有限の広がりを持つ空洞では
  ありえない形をしている。
- 発生率は格子の要素中心3,819点中1点(0.026%)。

**神託(参照実装)として使うときの作法**: 不一致が出たら実装を疑う前に、
`BRepExtrema_DistShapeShape` でその点から表面までの距離を測り、周囲を掃いて孤立点か
どうかを見る。**誤りは偽陽性の側にしか出ない**(神託が誤ると、実装が正しくても「不一致」と
数えられるだけ)ので、受入検査は不一致0件を要求する厳しいままでよく、落ちたときに
人が調べればよい。
