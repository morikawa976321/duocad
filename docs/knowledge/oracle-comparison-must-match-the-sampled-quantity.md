# 神託との照合は「高速経路が決めている量」と揃える

厳密な参照実装(神託)と高速経路を突き合わせるとき、**比べる量がずれていると、実装が
完全に正しくても不一致が出る**。

実例(duocad `probe_topopt` stage1、2026-08-31): ボクセル化の検証で、バウンディングボックス内の
無作為な点を `BRepClass3d_SolidClassifier` に食わせ、その点を含む**要素の占有**と比べた。
高速経路が決めているのは**要素の中心**の内外なので、点が中心から最大で半要素離れている以上、
点と中心が表面をまたげば必ず食い違う。**不一致率 4.9%** が出たが、これは実装の欠陥ではなく
照合設計の欠陥だった。**要素の中心を神託に食わせる**ように直したら不一致は 0件になった
(合成6形状23,475件 / 実物STEP 3,895件、いずれも0)。

一般化: 離散化した高速経路を検証するときは「どの点で標本化しているか」を先に決め、
神託にも**同じ点**を問う。そのうえで、離散化そのものが曖昧な帯(表面から要素サイズの数%)を
両者から除き、**除いた件数も出す**(除外で不一致を隠していないことを見せるため)。
