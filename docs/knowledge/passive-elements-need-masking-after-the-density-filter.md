トポロジー最適化(SIMP)で「設計空間の外」「保持領域」をパッシブ要素として扱うとき、
教科書的な実装(Sigmund の88行系)は**設計変数 `x` をクランプするだけ**である。
これだと密度フィルタが境界を越えて平均するので、**物理密度 `x_phys` は設計空間の外でも
0にならない**。duocad の probe_topopt で実測: フィルタ半径 `rmin=1.5` で、設計空間の
すぐ外の要素が `ρ=0.29` になった。marching cubes はそれをそのまま形にするので、
**CADの設計空間からはみ出した形**が出てくる(体積制約は満たしたまま)。

直し方: 物理密度を**フィルタの後で上書き**する(`x_phys[void]=0` / `x_phys[solid]=1`)。
そのとき感度も同じマスクで刈る(`dcn = filter(dc * live / hs)`)。パッシブ要素の
物理密度は定数なので、その要素への感度は連鎖律上ちょうど0であり、
**近似ではなく上書き後の定義と厳密に一致する**。

あわせて必要になったこと:
- 体積制約は動かせる要素だけに掛ける(目標 = `volfrac × 可動要素数 + ρ=1固定の要素数`)。
  全要素で数えると、設計空間の外の空要素を「もう十分軽い」と数えて、
  設計空間の中がほとんど埋まったまま止まる。
- 空要素にしか接していない節点は拘束側へ回して系から外す。剛性 `emin=1e-9` でしか
  繋がっていない浮いた自由度を残すと K がほぼ特異になり、CG が収束しない。
