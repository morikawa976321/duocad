# 最小の実物(PCケースの脚)は現APIでは寸法まで作れない

duocad の v1 verb集合が揃った時点(2026-08-11)で、受入テストを自作の単純形状から実物へ戻す候補は2つあった —— **PCケースの脚(5面・最小)** と **積層プレート(74面・本命)**。

## 事実

- **脚は現APIでは寸法まで再現できない。** 脚の円錐は **半径方向4mm・軸方向22mm の非対称な面取り**であり、duocadの面取りverbは**距離を1つしか取らない(=45度固定)**。脚を受入対象にするなら、**面取りの角度指定を先に足す必要がある**。
- 積層プレートは、フィレット・面取り・円弧の3つを前倒しで実装した理由そのものである部品([[cad-v1-technical-decisions]] の v1.1)。

## 含意

**面数が少ない実物ほど実装が楽、ではない。** 5面の脚のほうが74面の積層プレートより先にAPIの拡張を要求する。面数は部品の難しさの指標にならず、**面の種別(どの曲面か・対称か)を見ないと受入対象の重さを見誤る**。

同じ型の誤りが [[full-cylinder-is-not-always-a-hole]] で既に起きている(面種別の内訳から部品の構成を読み違えた)。実物を受入テストに据えるときは、面数ではなく面種別と対称性を先に確認すること。
