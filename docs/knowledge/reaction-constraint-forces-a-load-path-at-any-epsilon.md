# 反力の下限制約はどんなεでも荷重経路を1本作る(2026-09-11実測)

duocadのSIMPに「各拘束面が荷重のε倍以上を受け持つ」下限制約を入れ、εを振った実測(合成題材40x8x8・両端の壁を固定し片方の壁の3要素先に荷重・材料15%・40反復・MMA)。入れた動機は実物モデルで取付点(保持ソリッド)が浮き島になって消えたこと([[hanger-test-is-the-verification-model]]の限界の節)。

- **制約が無いと遠い壁の反力は4.5e-11**(厳密にゼロ)。構造最適化は荷重を運ばない材料を置かないので、その取付点は形から消える。
- **εを掛けると毎回きっかり境界に乗る**: 0.02→0.0200 / 0.05→0.0500 / 0.10→0.1000 / 0.20→0.2001 / 0.35→0.3501 / 0.50→0.5000 / 0.70→0.7014(超過は要求に対する相対で4.6e-05〜2.1e-03)。
- したがって**「取付点が結果に残る最小のε」は存在しない** — 0より大きければ経路は1本できる。εが決めるのは「残るかどうか」ではなく「どれだけ受け持つか」である。
- **代償はεに強く効く**。同じ題材のコンプライアンス悪化率はε=0.02で+234%、0.10で+1116%、0.50で+20169%。この題材が極端(遠い壁は37要素先・材料15%)なので絶対値は持ち越せないが、**下限は繋げるためのものであって荷重を配り直すためのものではない**。

制約が不活性でも費用は掛かる → [[inactive-reaction-constraint-still-costs-2-4x]]。fractionの読み方 → [[reaction-magnitudes-do-not-sum-to-the-applied-load]]。
