# 反力制約の随伴はグループ数ぶん解く(2026-09-11)

反力制約(各取付点が荷重のε倍以上を受け持つ)の随伴を何本解くかの判断(duocad topopt)。

**「ΣR = −Fがあるからグループ数−1本でよい」は、制約が反力の大きさ `|R_i|` のときは成り立たない。** 一定なのは合力**ベクトル**の和であって大きさの和ではない([[reaction-magnitudes-do-not-sum-to-the-applied-load]])。`d|R_i|/dρ = v̂_i · dv_i/dρ` を最後の1本について他から作るには、各グループの**3成分ヤコビアン**(3(n−1)本の随伴)が要る。n=3なら6 > 3で、素直にn本解くほうが安い。

n−1本で済むのは、制約を**荷重方向への射影**(線形汎関数)にしたときだけ。その場合は横向きにしか反力を持たない取付点が「受け持ちゼロ」に見えるので、取付要求の表現としては劣る。

費用の下げ方は本数を減らすことではなく、**順問題と随伴で同じ K_ff と前処理を共有すること**(多重格子のsetupは1反復に1回のまま、増えるのはCGの反復ぶんだけ)。それでも不活性な制約で2.36倍になる → [[inactive-reaction-constraint-still-costs-2-4x]]。
