[[rho-rank-selection-m0-must-not-exceed-target]] の続き。順位付けに使う場を3つ比べた
(hanger・5.333mm・案1で40反復・正解は同じ材料量で案1を回した ρ>=0.5)。

## ひずみエネルギー u_e^T k0 u_e は使えない

| 順位の場 | M0=1.0e6 → M=1.0e6(同じrun) の被覆 |
|---|---|
| ρ | 100%(k=1.25) |
| ひずみエネルギー | **8.72%(k=1.25) / 19.56%(k=3.0)** |

**自分自身の構造すら取り出せない。** 理由は最適性条件そのもの —— 収束した解では solid 内の
ひずみエネルギー密度はほぼ一様で、単位剛性の u^T k0 u は **void で最大**になる
(emin 媒質が巨大に変形するため)。上位から取ると void を先に取る。

**ρ^p を掛けた真の感度にしても救われない**: void は 0 になるが、今度は solid 内が一様になる。
**感度系の場は飽和の向きが変わるだけで、順位付けには原理的に使えない。**

## 距離での同点割りは効く(細い M0 限定)

「距離(ρ>=0.5 からのユークリッド距離)を主キー、ρ を副キー」にすると:

| M0 → M | ρのみ (k=1.25/1.5) | ρ+距離 (k=1.25/1.5) |
|---|---|---|
| 1.0e6 → 8.387e6 | 87.03 / 94.14 | **97.66 / 99.88** |
| 1.6e6 → 8.387e6 | 93.90 / 96.58 | **98.14 / 99.91** |
| 8.4e6 → 1.0e6 | 3.95 / 4.28 | 3.95 / 4.28(変わらず) |

太い M0 で効かないのは、ρ>=0.5 が箱を埋めていて距離場がほぼ 0 だから。
**距離は細い M0 だけを助ける** —— M0 を細い側に倒す理由がもう一つ増える。

**この順位付けは案5の膨張そのもの**(構造集合をまず取り、そこから同心に膨らませる)であり、
膨張量が定数 `COARSE_DILATE_MM` ではなく k から決まる形になる。**定数が1つ消える。**

## この組み合わせの実測値

M0=1.6e6(容量の10.5%)・ρ+距離・k=1.5 で、材料量 1.0e6〜8.4e6 の全域で被覆 99.91〜100%。
同じ M=1.0e6 で今の案5(粗20)は **93.27%・箱比12.9%**、こちらは **100%・箱比約10%**。
