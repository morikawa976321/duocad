**「いったんrel_tolを8%にしよう。これで2回減る」「rel_tolは今は固定値でいい。直接定数を
0.08にするだけでいい」**(2026-09-09)。

## 決めたこと

- `duocad/topopt/safety_loop.py` の `DEFAULT_REL_TOL` を **0.02 → 0.08**。**定数を書き換える
  だけ**で、引数で渡す口は作らない(`OptimizeOptions` に `rel_tol` は無く、`optimize_run.run`
  も `solve_for_safety_factor` へ渡していない。**その配線は今回作らない**)。

## 理由

**評価回数を2回減らすため。** 二分探索は1評価ごとに区間を半分にするので
`log2(0.08/0.02) = 2`。

**8% という値そのものに技術的な根拠は無い。** これは欠落ではなく事実である ——
`docs/TOPOPT.md` にもそう書く。既存の `rel_tol=0.02` の論拠(「2%より細かく詰めても
ボクセルの量子化と密度フィルタの目減りに埋もれる」)は**これ以上細かくしない理由=下限**の
話であり、緩める根拠に転用してはならない([[ai-fabricates-rationale-for-arbitrary-choices]])。

## 承知している代償

停止条件が `(hi-lo)/hi <= rel_tol` なので、**返る材料量は真の最小より最大8%重くなりうる**
(停止条件からの帰結であって実測ではない)。安全率は目標以上のままなので形は使える。
この設定で出した結果を「最小材料の解」として扱わないこと。
