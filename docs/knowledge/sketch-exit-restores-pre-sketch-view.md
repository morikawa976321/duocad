duocadで**スケッチを抜けたときに視点が寄ったまま残る**件について、本人が4案から
**「抜けたら入る前の視点へ戻す」**を選んだ。

退けた案:

- 抜けたら**全体が入る視点**へ戻す(`frameToContent`)
- **「全体」ボタンを戻す**(`7363c76` が「欲しくなればボタンを足すだけで戻せる」と書いていた)
- **直さない**(実機検査は緑で、実害はフック呼び出し3箇所だけだった)

前提: `lookAtSketch` は描いている図形の大きさに寄るのに `sketch-exit` はカメラを戻さないため、
半径4mmの円を描いて抜けると40mmの板が画面の外に残っていた。視点を全体へ戻すボタンは
2026-08-23の下段バー削除([[duocad-ui-moved-to-fusion-layout]] の周辺)で落としてあり、人に残る手は
手動のオービット/ズームだけだった。
