# 未平滑化メッシュの肉厚プロキシは「薄すぎる」方向に偏る

3Dプリントの薄肉検出でよく使う近似(各頂点について、法線がほぼ逆向き(内積が閾値未満)な
最近傍点との距離を取り、その最小値を局所肉厚とする)を、marching cubes直後(平滑化前)の
階段状メッシュに適用すると、**実際の部材厚みより明確に薄い値が出る**。原因は階段の1段ごとの
微小な凹凸が「近接して逆向きの法線を持つ点のペア」を過剰に作り出すため(真の薄肉ではなく
描画の局所ノイズを拾ってしまう)。

duocad `probe_topopt`(SIMPトポロジー最適化 40×16×16・volfrac0.3の片持ち梁)で実測:

| | 最小肉厚(近似値) |
|---|---|
| marching cubes直後(平滑化前) | 0.147 |
| Taubin平滑化後(λ=0.5, μ=-0.53, 30反復) | 0.628(**4.27倍**) |

平滑化するとこのノイズが消えるため、**肉厚の近似値はむしろ増えるのが正常**。
「平滑化が部材を食っていないか」を機械検査したい場合、この前提を踏まえて
「平滑化後 ≥ 平滑化前 × 閾値」という向きの不等号で見る必要がある
(逆向き、つまり平滑化で厚みが不自然に「増えすぎ」を警戒する設計は的外れ)。
なお同じ実装で反復回数だけ1000まで増やすと比は0.945まで下がった(過剰な平滑化による
実際の縮退は検出できる)。
