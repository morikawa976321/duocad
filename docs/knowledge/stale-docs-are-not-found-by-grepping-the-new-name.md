duocad で `BRepBndLib::Add` を `AddOptimal` へ差し替えたとき、`grep AddOptimal` では
見つからないのに**嘘になった記述**が2種類あった:

1. **捨てた側の名前で書かれている記述** —— 「ガードは `_shape_bbox_trimmed` へ移した」。
   これは `grep _shape_bbox_trimmed` で出る。
2. **速さの根拠として置いてあった実測値** —— 「`False` は実物STEP(231面)で0.003秒」。
   `Add` の測定値だが、文中に `Add` の語が無い。**差し替えで実測が3桁変わったのに、
   grep のどの語にも引っかからない。**

したがって、実装の差し替えでドキュメントを掃くときは
**「新しい名前」ではなく「捨てた側の名前」と「その節に書いてある数値の根拠」**で探す。
数値は「何を測ったものか」を書いておくと、差し替えのときに掃ける
(逆に書いていないと、誰も直せないまま嘘が残る)。
