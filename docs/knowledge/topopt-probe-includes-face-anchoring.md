# 面アンカーはプローブ段階でやる

duocadへのトポロジー最適化統合の前に、**境界条件をCAD面に紐づける処理（面アンカー）までプローブで済ませる**と本人が決めた。代替案（荷重・拘束を「この直方体内の節点」という座標ボックスで指定し、面アンカーは後回し）は採らない。

面アンカーとは、ボクセル化するその瞬間に `CAD面の添字 → 格子節点集合 + 節点ごとの担当面積` の対応表を1回作って持っておく処理。**ボクセルの側から境界を取り直してはならない**（ボクセル表面は階段状で真の面から最大半要素ずれるため、斜面・曲面で荷重の向きと面積が歪み、階段の角に偽の応力集中が出る）。担当面積の重み付けは必須で、これが無いと解像度を変えたときに総荷重が変わるか分布が黙って変わる。
