# 分断された設計空間はSIMPを素通りする

probe_topopt で実測(2026-09-04、`design_space.severed_conditions`、長辺22要素・60反復)。
除外ソリッドの壁で拘束面と荷重面を断ち切った塊を、連結性の確認だけ迂回して最適化に通した。
**6配置(0°/30° × volfrac 0.15/0.30/0.50)のうち4配置が、例外も警告も出さずに60反復を走り切り、
STLまで出た。**

- 出てくる形は**拘束側と荷重側が別々に浮いた**もの。ρ>0.5 の材料は3〜4個の島に割れ、
  拘束側の島と荷重側の島は一度も同じ成分に入らない。
- 体積制約は満たす(達成 volfrac 0.187 / 0.326)。**利用者が見る数字はどれも正常に見える。**
- コンプライアンスは参照(つながっている系)の約40万倍(3.33 に対し 1.57e6)で、60反復かけて
  0.0014% しか下がらない。**しかし利用者はコンプライアンスを見ない。**
- 残り2配置(0° / volfrac 0.30・0.50)は1反復目で `ZeroDivisionError: float division by zero`
  (`simp.py` の OC 更新の体積二分法)。**文面には設計空間も連結性も出てこない。**

## なぜ SIMP 側のガードが作動しないか

`simp` には「拘束不足なら残差検算で落とす」ガードがあるが、**空要素も剛性の下限 `emin`
(既定 1e-9)を持つ**ので、荷重側の島は emin の要素越しに固定節点へぶら下がる。K は特異に
ならず残差検算を通る(max|u| = 1.58e6 でも通る)。`emin` を 1e-12 まで下げると初めて作動する
(残差 2.9e-05 > 1e-06)。**つまりこの経路は emin の大きさ次第で黙る。**

## 帰結

塊(設計空間)の分断は、**塊を組み立てる側でしか安く確実に検出できない**。最適化の後段
(`mesh.remove_islands` 等)は出力の後処理であって、塊の不備は直せない —— 実測では島が残った
まま STL になっている。この実測を根拠に `design_space.derive` へ 6近傍の連結性ガードを入れた
(2026-09-04、taskbox `20260903-2235`)。

利用者は塊を見ない([[topopt-needs-no-design-space-input]])ので、
**この失敗は利用者側からは永久に観測できない。**
