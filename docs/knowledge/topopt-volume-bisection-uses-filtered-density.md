# 体積の二分探索はフィルタ後の密度で判定する

密度フィルタを使うSIMP(トポロジー最適化)で、OC法のラグランジュ乗数を二分探索するとき、
**体積の判定対象を設計変数 `x` にするか、フィルタ後の物理密度 `xPhys = conv(x)/Hs` に
するかで結果が変わる**。

フィルタは領域外を0とみなして正規化するので、**境界付近では `x` の平均と `xPhys` の平均が
一致しない**。`x` の総和で判定すると、制約は `x` に対して満たされても、実際に評価される
`xPhys` の体積分率は目標から外れる。

`xPhys` の総和で判定すると(二分探索の中で毎回フィルタを掛け直す)、最終体積分率が
**目標 0.3 に対して相対誤差 +0.0000%** で乗った(duocad `probe_topopt` の実測)。
88-line SIMP(`top88`)の密度フィルタ経路も同じことをしている。

含意: 「体積分率が目標±1%以内」を受入条件に置くなら、この1点だけで合否が決まる。
