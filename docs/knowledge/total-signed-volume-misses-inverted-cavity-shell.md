# 総符号付き体積では「空洞の殻だけの反転」を見抜けない

閉じた三角形メッシュの向きが外向きに揃っているかを「発散定理で出した**総**符号付き体積が
正か」で判定すると、**内部空洞の殻だけを裏返した入力**を通してしまう。

実測(duocad `probe_topopt/voxelize.py`、2026-08-31): 40³の箱に20³の空洞を空けた中空の箱。

- 健全: 外殻 +64,000 / 空洞の殻 −8,000 → 総和 **+56,000**(正)
- 空洞の殻だけ反転: 外殻 +64,000 / 空洞の殻 **+8,000** → 総和 **+72,000**(やはり正)

有向辺の対の検査も通る(各殻の中では向きが揃っているため)。結果、**空洞が材料として
埋まった格子**が黙って返る(実測で 56,000 mm³ が 64,000 mm³ になった)。

正しい判定は**連結成分(殻)ごと**に見ること。殻の符号付き体積の符号は、その殻が
**他の殻いくつの内側にあるか**の偶奇で決まる —— 深さが偶数(外殻)なら正、奇数(空洞)なら負。
入れ子の深さは、その殻の頂点1つを取って他の殻それぞれに対しレイの巻き数を数えれば出る
(殻の数は普通ひと桁なので、総当たりで十分速い)。
