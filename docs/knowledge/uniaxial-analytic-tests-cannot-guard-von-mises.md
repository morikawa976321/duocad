duocad probe_topopt の応力検査で変異検査をしたときに出た。von Mises の式のせん断項の
係数を **3 → 1** に変える変異は、

- 一様な棒の単軸引張(σ = F/A と厳密一致)
- 片持ち梁の曲げ(σ = M·c/I への収束)

の**どちらも通り抜ける**。どちらも単軸応力状態でせん断成分が 0 だからである。
落ちたのは「階段状境界の代表値が細分で動かない」という間接的な検査1件だけで、
何が壊れたのかは出力から読み取れなかった。

対処: **定義そのものを見る2件を別に置く** —— 純せん断 `[0,0,0,τ,0,0]` の von Mises が
`sqrt(3)·τ`、静水圧 `[p,p,p,0,0,0]` が 0。これで変異は直接落ちる。

一般化: **解析解との比較は「その解析解が通る応力状態」しか守らない。** 合成量(von Mises・
主応力・相当ひずみ)は、解析解の検査とは別に**定義単体の検査**を持たせること。
