# ビューポートの寸法が変わると、クリックが掴むものが黙って入れ替わる

## 実測(duocad・2026-08-23)

UIからパネルを1枚外してビューポートが縦に伸びただけで、実機検査
`web/scripts/smoke-features.mjs` の「XY基準平面にスケッチを作る」が、
**基準平面ではなく手前の板の面を掴む**ようになった。既知の
[[duocad-base-planes-lose-to-solids-by-depth]](平面と面はレイ距離で競う)の
再発だが、今回は**寸法が変わったことがきっかけ**である点が新しい。

## 厄介なのは表面化の仕方

掴み間違えても**その場では何も起きない**。スケッチは正常に作られ、図形も正常に
置かれる —— ただし平面が違うので座標系が違う。落ちるのは数手あとの
「押し出しで切り取る」で、しかも文言は
`cut did not change the shape`(形が変わらなかった)であって、
平面の話は一言も出てこない。**原因と症状が数手ぶん離れる**。

## 教訓

3Dビューの自動検査で「操作は通ったが結果がおかしい」が出たら、
**画面の寸法を変える変更が直前に入っていないかを最初に疑う**。
差分がUIのレイアウトだけでも、掴むものは変わりうる。
