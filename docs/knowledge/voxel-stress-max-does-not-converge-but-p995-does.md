duocad probe_topopt の応力後処理(`stress.py` / `check_stress.py` [4])で測った。
上端が45度で下がって幅が半分になる板を引っ張り、細い側の公称応力 F/A に対する倍率で見る。
3段の細分:

| 格子 | 素の max | ρ>=0.5 の max | 99.5パーセンタイル |
|---|---|---|---|
| 24×16×2 | 12.92x | 1.538x | **1.324x** |
| 48×32×4 | 26.32x | 1.862x | **1.289x** |
| 72×48×6 | 39.72x | 2.089x | **1.304x** |

- **素の max は収束しない**(ρ≈0 の空要素が支配する)。
- **ρ で絞ってもなお max は単調に増える**(+35.8%)。階段の角は細分しても角のままで、
  応力は下がらない。**これは実在の応力集中ではなく離散化の産物**。
- **99.5% 点だけが動かない**(振れ幅 2.7%)。しかも公称応力より 30% 高いので、
  本当の応力集中(断面変化)は捨てていない。

帰結: **ボクセルFEAの上で安全率を出すなら、代表応力を max にしてはいけない。**
max を採ると解像度を上げるほど安全率が下がり続け、収束しない量で合否を決めることになる。
これは [[safety-factor-goes-outside-the-optimizer]] が応力制約の定式化を採らない4つ目の理由
(「応力は最大値を見る量なので階段に最も敏感」)を数字で確かめたものでもある。

**2026-09-04追記(検査の梯子を縮めた)**: 検証の1周を速くするため `check_stress.py` [4] の
梯子を 16×8×2 / 32×16×4 / 48×24×6 へ落とした(24.2秒 → 3.7秒)。結論は同じで、
素の max 8.63 → 17.70 → 26.46倍、ρ≥0.5 の max 1.276 → 1.527 → 1.707倍、
99.5% 点 1.251 / 1.263 / 1.256(振れ幅 1.0%)。**12×8×2 まで落とすと 99.5% 点の振れ幅が
6.8% になり「同じ細分で動かない(5%以内)」が成り立たなくなる** —— そこが下限。

同じ機序の偽の集中: [[face-to-node-anchoring-loses-faces-smaller-than-the-cell]]

## ρ の閾値が下げるのは「代表値」であって「素の max」ではない(2026-09-04実測)

代表応力の規則は「ρ>=0.5 に絞る」+「99.5パーセンタイル」の2段。着手時の見込みは「ρ の低い要素が素の max を支配するので
閾値で落ちる」だったが、**プリセット 20×10×10 の SIMP 出力では外れた**:

- 素の max = ρ>=0.5 の max = 153.5 MPa。最大応力の要素は **ρ=1.0 の荷重直下(点荷重の特異点)**にあり、ρ の閾値では動かない。
- ただし von Mises 上位10要素のうち8つは ρ≈1e-6〜1e-9 の要素だった。
- **閾値を外すと採用する代表値(99.5%点)が 85.77 → 115.4 MPa(1.346倍)に上がる。**

「max が変わらないなら閾値は要らない」と読むと誤る。閾値が max にも効くのは、空要素が材料に直接隣接する形
(設計空間の外を `void_mask` で固定した経路・階段状境界)のほうで、そこでは上の表のとおり素の max が代表値の 9.8〜30.5倍になる。
点荷重の特異点については [[attaching-nodes-to-small-faces-would-not-fix-it]]。
