# ズーム直後のホバー読みは時々落ちる

duocad の実機smokeで、**同じ視点・同じ座標なのに通ったり落ちたりする**判定を作ってしまった。
原因はズームが可変解像度の測り直し(`set_view_resolution`)を起こし、返ってきた状態で
スケッチの折れ線(`handleLines`)が作り直されること —— その最中に読むと、指せるものが
一瞬入れ替わったところを見る。

対処は2つ:

1. **視点を動かした後は `__duocad.stateEpoch` が止まるまで待つ**(rAFを数フレーム待つだけでは
   足りない。サーバ往復が絡むため)。
2. **ホバーの読みは null なら数フレーム置いて読み直す**(最大3回)。
   **当たり側だけが救われる非対称な待ち**にすること —— 外れ側(「取れないはずの画素」)は
   何度読んでも null なので、判定は緩まない。retryで判定を緩めない設計はここが分かれ目。
