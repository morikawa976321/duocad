## 5. 最小幅の確認(平滑化の前後。`final_shapes_09.py` の `fine_width`)

**対照**として元のボクセルマスクを半格子へ単純に細分した形でも同じ数え方をしたところ、4形すべてで s=2m の損失は0(測定の検算)。損失の割合が小さくなる最大の立方の一辺は、解析者が置いたしきい値(0.1%・1%。**未校正**)で読んだ値で、列そのもの(下表)を一次の根拠とする。

| S1 | 7.54 | 3.8mm 0.03% / 5.0mm 0.08% / 6.3mm 0.17% / 7.5mm 0.33% | 7.54 | 5.03 |
| S1c | 7.54 | 3.8mm 0.07% / 5.0mm 0.17% / 6.3mm 0.46% / 7.5mm 1.28% | 6.28 | 3.77 |
| S2 | 11.98 | 9.0mm 2.21% / 10.0mm 3.25% / 11.0mm 11.1% / 12.0mm 39.9% | 4.99 | 2.00 |
| S3 | 10.99 | 7.7mm 0.40% / 8.8mm 0.60% / 9.9mm 1.18% / 11.0mm 1.86% | 8.79 | 4.40 |

- 小型2形は要求6mmに近い立方で 0.5%未満(S1c 6.3mm: 0.46%、S1 0.17%)。hangerは要求10mm付近の立方でS2が3.25%、S3が約1.2〜1.9%。S2の実現幅約12mm立方では材料の約4割がopeningで失われる。ただし、この値から部材の断面厚さが11mm未満になったとは断定できない。2026-10-07の[段階別解析](../TOPOPT_FINAL_WIDTH_117.md)で、表面生成による角の丸めと測定格子の影響を確認した。S2の表中「10.0mm」は厳密には9.98695mmで、要求10mmよりわずかに小さい。
- opening は角・接合部の丸めでも損失を出すので、損失の全部が「要求幅の違反」ではない。ただし、探索が守った最小幅(ボクセル)が平滑化後の形で保たれる保証は無い。製品の合否は平滑化前のボクセルの最小幅で、平滑化後のメッシュの幅は検査していない。
- 最小幅の適用範囲(`min_width`)の保持セル免除は、半格子でも同じ領域を免除した。

## 6. 保持・荷重面・支持面の確認

- **平滑化メッシュ単独(足し戻しなし)**: 同格子へ再占有化すると、保持セルが S2: 10個・S3: 12個欠け、荷重面または固定面の節点が材料から外れる(S2: 固定面10の1節点・荷重面31の1節点、S3: 荷重面31の6節点)。FEMの条件確認が通らず解析できなかった。小型は最終形で条件確認が通る。
- **保持セルを足し戻した近似**(最終ブーリアンの「保持のfuse」の代用): 条件確認が通り、FEMが成立した(4節)。
- **除外**: hangerの平滑化メッシュは除外ボディに 503 mm³(S2)・1,386 mm³(S3)侵入し、除外のみのcutで単一ソリッドのまま取り除ける(3節)。除外との侵入は最終形で除かれる設計だが、最終形が成立しないので、最終形での除外の遵守は未確認。
- 最終形が成立した小型2形では、最終CADの水密・単一ソリッド・自己交差0を `inspect_solid` と最終メッシュ検査(float32の頂点一致・縮退・自己交差)で確認した。

## 7. 採用判断への含意・限界・未検証

**この文書だけでは製品変更を採用できない。**

- 完成形の検証が成立したのは小型の1条件(dilution 300N・2.5mm・最小幅6mm)の2形だけ。**hangerは製品の最終形を作れない**ので、完成形(最終CAD)での確認は0形。粗格子の再解析で代用していない(4節は最終形ではない近似であることを明記した)。
- 最終CADの応力の細格子での確認は未実施(FEM予算4回に収まらない。局所ピークは特異点で格子とともに増える=02)。S1・S1cの最終メッシュは `09_work/*_final_mesh.npz` に保存してあり、細格子の再解析の入力にできる。
- 最小幅は、平滑化後に要求幅を保つとは言えない(5節)。hangerで特に顕著。製品の判定(ボクセル)と完成形の判定が食い違う。
- M5b目標・M3は、保存形と同じく再占有化でも不合格のまま。**製品SFゲートだけを満たす形**で、局所の応力の目標を満たす形ではない。
- 限界: 1条件・1形(小型)、各1形(hanger)。S3のcutの体積の不整合は原因未特定。再占有化は中心サンプリングで境界の位置を最大半セル動かす。

`deferred_by_user_deadline`(合格として扱わない): 最終CADの細分格子FEM・hangerの最終ブーリアンの修正(薄い破片への対処)と修正後の再検証・`F0500_h2.2_w5`・`F1000_h2.2_w5` の最終形の再解析・小型の複数条件/同ゲートの追試。
