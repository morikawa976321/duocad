# アプリ内 optimized の解析

## 対象と来歴

2026-09-14にローカルアプリから読み取った `hanger_bar_attachment.json` 内の
`optimized`（body-95ff8a6b9c4e、revision 14）。内部形式はmesh。
保存済み `models/hanger_bar_attachment.json` にはこのボディが含まれていなかったため、
初期状態配信を `state.json` に保存し、座標を17桁のASCII STLに書き出して検査した。
アプリの文書、ボディ、可視性、最適化ロジックは変更していない。

取得メッシュは以前の `../hanger_status_snapshot.json` のoptimizedと描画頂点・三角形が完全一致。
今回取得した状態に計算時の格子サイズは記録されていないため、2.4mmで実行した結果であることは
このデータだけでは確認できない。ディレクトリ名は依頼内容に基づく。
アプリ内の現在の保持・除外リストは空だった。
検査条件は保存済み元JSONの保持4個・除外8個を使用。
CADの操作履歴（結果追加前）とパラメータは以前のスナップショットと一致する。


| 条件 | スクリプト判定 |

| 除外 | UNKNOWN |

境界辺、非多様体辺・頂点、向きの矛盾、縮退面、重複面はいずれも0。

18組は穴の数ではなく、OCCTが検出した辺・面などの干渉ペア数。

## 保持欠損の独立した証拠

出力メッシュ全体の外接直方体からさえはみ出す保持CADは、出力に含まれ得ない。
各保持CADからこの直方体を引く検査で、次の残存体積を得た。
これは欠損の下限であり、欠損総量ではない。

| 保持部 | 出力外接箱からはみ出す体積 mm³ |
|---|---:|
| 大きいリング（末尾7） | 23.779529 |
| 取付部（末尾1） | 35.355517 |
| 取付部（末尾2） | 35.355517 |
| 取付部（末尾3） | 35.355517 |
| 合計 | 129.846080 |

3取付部の元CADはY=0まで存在するが、メッシュ全体のY最大値は-0.1815057895 mm。
全4保持ボディで欠損があることは、この必要条件の検査だけで確定する。
厳密な有限精度の留保は判定器と同じ。詳細は `preserve_bbox_witness.json`。

## 目視確認

`overview.png` の斜視・側面・端面・保持CAD重ね合わせ、および `closeup_1.png` を直接確認した。
画像は実際の三角形座標を投影・陰影描画したもので、形状の補間や修復はしていない。
オレンジは元保持CADの半透明表示。半透明画像自体を厳密な包含判定には用いない。

- 大きなリングと3取付部は認識でき、主要な枝はつながって見える。独立した大きな島は見当たらない。
- 上側取付部へ向かう枝には細い部分があり、取付部の根元に針状の薄い突起が見える。
- 自己干渉18組はその突起付近に集中する。関与する辺・面の外接範囲は
  X=-20.46554〜-20.40584、Y=-44.97015〜-40.96551、Z=72.29591〜72.52816 mm。
  これは関与面の範囲であって、肉厚の測定値ではない。
- 画像では小さい局所的な潰れだが、有効なソリッドとしての扱いを妨げている。
- 強度や最小肉厚の合格は、この画像から判断しない。

## 次に調べること

実際の結果を生成した同じ密度場から、平滑化直前・直後のメッシュを保存して自己干渉箇所を比較する。
これにより表面抽出で既に潰れているのか、平滑化で潰れるのかを独立に判定する。
保持CADの厳密な保存は別に検証する。保持ボクセルを1にする処理だけでは、今回の欠損を防げていない。
今回は解析までとし、最適化処理の変更は実施していない。
